# MISSION.md — 这套课为什么存在

## 一句话使命

把 `G:\project\ieeexplore` 里 **255 篇论文的本地语料库**，变成一条**能真正读完的阅读路径**——
不是清单，不是摘要合集，而是**逐篇读过正文之后**写出来的、面向零基础读者的精读课程。

## 学习者背景（初始设定）

- 想系统进入 SLAM / 机器人感知方向，但面对 255 篇论文不知道该从哪读起。
- 读术语密度高的专业文档会吃力，需要**先讲人话、再上术语**。
- 希望看到**原文插图**，并且插图要被解释清楚"这张图在说明什么"。
- 希望有练习与自测，能从"读完一页"走到"形成自己的知识结构"。

## 五条不可妥协的原则

1. **绝不凭标题推测论文内容。** 每一句技术判断都必须来自正文，能指回出处。
2. **主动修正 OCR 错误。** PDF 转 Markdown 会认错希腊字母、上下标、连字符、连字；教给用户的必须是正确知识，并且在课里说明修正了什么。
3. **插图来自原文。** 用真实存在的图片文件、真实的图注；每张图都要解释"怎么看"。没有关键原图时**不要硬塞**。
4. **通俗优先。** 先讲人话（生活类比），再上术语；术语首次出现必须解释。
5. **诚实记录勘误。** 发现路线图/文件名/元数据有错，公开修正并记录，不掩饰。

## 追问也是课程的一部分（不是聊天）

学习者在读课的过程中随时会冒出疑问。**这些疑问的解答必须落回 HTML**，而不是留在对话里消失：

- **小疑问**（术语、公式某一补、某张图看不懂、原文自相矛盾）→
  **就地插进那一节课的对应位置**，用 `qa-patch` 折叠块（默认展开），
  先给结论再给依据，并注明论文小节号。
- **大疑问**（独立成题、需要推导、跨课对比、一次问多个）→
  **独立成页，放进 `qa/` 目录**（`qa/qa-<源课号>-<主题>.html`），开门见山回答，问题本身当小节标题。
  **答疑页不占用主线课号**——主线永远是 0001、0002、0003…，答疑页按"源自哪一节课"命名与归档。

两处必须**双向互链**：源课在卡住的位置留一个跳转补丁，答疑页顶部再给一条"回到原位置"的链接。

具体规则（含 HTML 片段、插入位置选择、catalog 如何更新）见项目 skill
`.workbuddy/skills/slam-paper-course/SKILL.md` 第 9 节。每次答疑都要在
`learning-records/` 留一条记录。
