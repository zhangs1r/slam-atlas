9. 后端与优化（阶段 B）

中文英文 / 缩写一句话解释课次
联合最优Jointly optimalBA 的定义核心：结构与相机参数同时达到最优，而不是各自最优再拼。0018
独立模型法Independent model methods先做局部重建再合并、不把内部结构回传。BA 与它正相反。0018
重投影误差Reprojection error把三维点投到图像上、与实测像素位置之差。视觉 BA 的残差就是它。0018 / 0027
规范自由度Gauge freedom坐标系整体变换不改变几何——所以正规方程天然欠定，必须固定一个 gauge。这就是"协方差没有绝对含义"的根源。0019
S 变换S-transform沿 gauge 轨道把结果推到另一种 gauge 的变换。0019
失望矩阵Dispersion matrix用 Hessian 的逆刻画不确定性的嵌套椭球；注意 $H^{-1}$ 总是稠密，无论 $H$ 多稀疏。0019
总分布Total distribution把内点与外点建成一个分布，让 ML 估计天然鲁棒——原文认为这比"先把外点剔掉"更正确。0019
Schur 补Schur complement分块矩阵消元的产物 $\bar D=D-CA^{-1}B$。在 BA 里用来消掉结构参数、留下约化相机系统。0019
约化相机系统Reduced camera system只含相机参数的正规方程。成立前提：结构子矩阵块对角，所以能按点独立求和、不需要真求逆。0019 / 0027
填充Fill-in稀疏矩阵分解时新产生的非零元。变量排序的唯一目的就是压住它——而全局最小化是 NP-complete。0019
最小度 / 反向 Cuthill-McKee / 嵌套剖分Minimum degree / RCM / Nested dissection三类常用的变量排序启发式：自底向上、适合链状、自顶向下递归切分。0019
图-可嵌入最小二乘Graph-embeddable least squaresg²o 的统一视角：节点＝待优化变量，边＝两节点之间的成对观测。SLAM 与 BA 都落在这一类里。0021
块结构＝邻接矩阵Block structure = adjacency matrixH 的非零块模式就是图的邻接矩阵——所以非零块数与边数同阶，天然稀疏。0021
符号分解复用Symbolic decomposition reuseH 的稀疏模式在迭代中恒定，所以第一次算出的符号分解可以一直复用。0021
直接法 / 迭代法求解器Direct (Cholesky) / Iterative (PCG)两组正交的选择：直接法稳但吃内存，迭代法省但收敛依赖初值。没有万能的求解器。0021
点簇Point cluster把"同一特征上的所有点"压成一个 $4\times4$ 对称矩阵。刚体变换与合并都退化成矩阵乘法/加法，于是复杂度与点数无关。0022
特征消元Feature elimination点云 BA 里用特征值/特征向量把平面或边缘参数闭式解出再代回，只剩位姿待优化。0022
NEESNormalized Estimation Error Squared检验估计量"一致性"的指标：归一化后贴近 1 才叫一致。比"精度高"更严格——它要求系统知道自己错多少。0022 / 0029
点云库PCL点云处理的标准件仓库（filters / features / segmentation / registration / surface 等九块）。激光论文里的 ICP / GICP / NDT 基线多来自它。0023
感知处理图PPG / nodelet把感知任务拆成可连接的积木；nodelet 让它们同进程多线程运行、避免点云序列化开销。0023
近似最近邻FLANN / ANNPCL 底层的 k-NN 用近似算法。为什么激光 SLAM 后来需要"能动态插入删除"的树，正是从这个"近似"开始的。0023
