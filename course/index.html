课程总览

SlamAtlas

这里不是"把 255 篇论文平铺成一条清单"，而是先分馆、再按语料库阶段分块、再把每篇论文拆成一节或几节可读的课。每一句技术判断都来自论文正文，插图直接用原文插图——不做标题推测。🙂

📚 快速跳转

先看分馆，再看来源块。每一块对应一个语料库阶段。

🗺️ 255 篇全量阅读路线图交互版
怎么本地打开：本课程页里的插图直接引用项目的 md/images/，所以请从项目根目录起服务，而不是从 course/ 起服务。在 G:\project\ieeexplore 下执行
python -m http.server 8000
然后访问 http://localhost:8000/course/index.html。

📚 课程馆

先按「馆」管理来源，再在馆内维护具体阶段块。以后新增阶段（B 打地基、C 视觉主干、D 激光主干……）时，只需要在 data/course-catalog.js 里追加一个 collection 和对应的课条目即可。读完一节后点一下卡片右上角的完成按钮，进度会记住。

🏷️ 按关键词快速筛选课程（点标签进入搜索）
