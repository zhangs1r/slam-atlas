第十季学习记录：基础零件 · 四族零件（0186–0198）

对应课程：第 0186 – 0198 节（语料库阶段 J，11 篇论文；本季 13 节课，39 张具象自绘图、46 张原文图） 记录日期：2026-09-21

一、这一季跟前九季有什么根本不同

前九季是一条纵向的路，其中第八季和第九季是两次横切—— 但它们横切的时候，切的还是 SLAM 自己的东西（第八季拆假设、第九季讲尺子）。

这一季是第四种季型，而且是最特殊的一种：11 篇论文里，没有一篇讲 SLAM。

它们是：GoogLeNet、ResNet、ResNeXt、FCN、YOLO、Mask R-CNN、Focal Loss、Swin、PVT、 一篇三维检测综述、一篇激光雷达硬件。全是计算机视觉与深度学习的通用零件。

那它们凭什么进这门课？因为前八季的论文里到处在引用它们。 读者读 SLAM 论文时会反复看到「我们用 ResNet-18 当骨干」「Mask R-CNN 检测动态物体」 「语义分割结果作为先验」这类句子——但从没人解释过这些词是什么。

所以本季的性质是补名词：把读者读论文时跳过去的那些词，一个个补上。

这也决定了本季与前九季最大的一点不同：它补的是阅读能力本身。

★ 全季的暗线（一句话）：语义前端 195 毫秒一帧约等于 5 帧每秒，而 SLAM 要实时。 本季所有零件的落地摩擦都在这条线上。而且零件是不完美的——

  • FCN 承认会把救生衣当成人；
  • YOLO 承认小物体成堆会漏，且定位误差是第一大错源；
  • Mask R-CNN 被 SLAM 论文抱怨边界不精 + 跑不到帧率（DynaSLAM 引了它 195 ms/图）；
  • Focal Loss 承认 hinge loss 与朴素交叉熵都训不起来。

把四条摆在一起，就能看懂一件事：第八季那些「语义 + 几何双保险」的设计， 正是被这些缺陷逼出来的。 这是本季与第八季最重要的连接点。

三、技术核心：两处最反直觉的地方

3.1 ResNet 的「退化」（0188）

现象：56 层的训练误差居然比 20 层更高。这反直觉——不是过拟合，是连训练集都学不好。

更要紧的一点：ResNet 的问题不是梯度消失。梯度问题已经被 BatchNorm 与更好的初始化 基本解决了；剩下的坑是退化。这个区分不作对，读者会把 ResNet 理解成「又一个梯度技巧」。

解法：一条绕过两层的短接箭头，y = F(x) + x。 讲法是「别让层去学答案，只让它们学答案与输入的差；实在没得学，把权重推成 0 就是恒等映射，也很容易」。

3.2 Focal Loss 的调制因子（0193，全季最抽象）

这是全季最不友好的一篇：没有图片输出，只有一个公式。

诊断：单阶段检测器打不过两阶段，真正病因是正负样本极度不平衡—— 一张图里九成以上的候选框是背景，损失函数被大量「一眼就对」的样本淹没。

解法：FL = -α(1-p_t)^γ log(p_t)，给已分对的样本乘一张折扣券。

把人话讲透的关键是给数字（这一条本季起了决定作用）：

  • 样本已经分对（p_t ≈ 1）时 (1-p_t)^γ ≈ 0，它的损失几乎被忽略；
  • 一个 p_t = 0.9 的容易样本，在 γ = 2 时权重被压到 0.01，是原来的百分之一；
  • 原文用 γ = 2、α = 0.25，而且两者必须联动（α = 0.10 时 AP 掉到 0）。

另配一张天平图（上千个一眼就对 vs 寥寥几个难分）与一张折扣券曲线 （横轴 p_t、纵轴 (1-p_t)^γ，画 γ = 0/1/2/5 四条）。 曲线上的点全部用真实公式算，不靠手感画。

四、11 篇各自的看点

4.1 骨架线（0187–0189、0194）

这条线的主线一句：每一次进步都是在算力预算不变的前提下，「更深或更强」的换法。 VGG/ResNet 把深度这一维榨干 → ResNeXt 发现深度宽度边际递减，另开基数这一维 → Swin/PVT 干脆换掉卷积算子本身。

一条暗线必须写进去：这条线真正的粘合剂是恒等映射/残差连接。 ResNet 把它确立为可训练深网络的前提；ResNeXt 用它做对照实验证明「B 牌来自聚合变换而非残差」； Swin 每个 block 是 MSA+残差 与 MLP+残差；PVT 沿用标准 Transformer block 的残差结构。 读者应当把「残差」理解为贯穿这五篇的公共零件，而不是 ResNet 的专属发明。

各篇的记忆锚： - GoogLeNet：一层里同时看三个尺度，再用 1×1 先把通道压瘦——于是加宽加深不涨价。 - ResNet：别让层去学答案，只让它们学答案与输入的差。 - ResNeXt：同一份算力，与其多叠几层、多铺几通道，不如把一次大卷积切成 32 份互不通信的小卷积并联。 - Swin：注意力只在自己那扇窗里算（线性成本），但下一层把窗户整体挪半格（接上跨窗信息）。 - PVT v1：把 CNN 的金字塔照搬进 Transformer；K/V 再压一刀，显存就够用了。

4.2 检测与分割（0190–0193）

★ 三个词的区别（全批最重要的一张图）：一张图里有两只挨在一起的猫。 - 目标检测（YOLO）返回两个框 + cat, cat——知道有两只，但不知道边界； - 语义分割（FCN）返回一张图，所有猫像素涂成同一色、两只连成一片——分不出个体 （原文原话：semantic segmentation 是"without differentiating object instances"）； - 实例分割（Mask R-CNN）返回两张独立掩码——既知边界、又知个体。

数学上的分野：语义分割是每个像素做多分类（per-pixel softmax，类间互相竞争）； Mask R-CNN 的实例掩码是每个类各出一张二值图（per-pixel sigmoid，类间不竞争）。 这一条正是 Mask R-CNN 那 +5.5 AP 的来源。

Mask R-CNN 的两个重点（RoIAlign 的篇幅不能少于第三条分支）： - 第三条并列的掩码分支，它本身就是一个小 FCN（回链 0190）； - RoIAlign 把 RoIPool 的量化取整换成双线性插值，在 stride 32 时带来 +7.3 mask AP / +10.5 mask AP75（约 50% 相对提升）—— 这是全季最好的「工程小细节有多值钱」的案例。

4.3 两端外围（0195–0197）

LiDAR 硬件（0195）只讲两环： ① 测距就是测时间（R = cτ/2）——要分辨 1 厘米，需分辨出 0.067 纳秒； ② 所以每个点自带一个独立的、互不相同的时刻戳。 后面「一圈 0.1 秒量级 → 同一帧里先扫到和后扫到的点在不同位置采 → 运动畸变」 属于第四季，只用一小段桥接过去，并明确标注那是我们自己的分析。

三维检测综述（0196–0197）的分类是两根轴，不是一根： - 第一轴 = 谁给的数据（LiDAR / Camera / Multi-modal）； - 第二轴 = 点云塞进什么容器（Point / Grid(Voxels·Pillars·BEV) / Point-Voxel / Range）。 - 常见的「点 / 体素 / BEV / 多模态融合」四条其实跨了两根轴（前三属第 3 章的四种表示， 多模态属第 5 章）。分类树画歪就是因为没分清这一点。

核心那张图：同一辆真实汽车的点云，三图并排——直接在用点 / 装进体素小方块 / 从天上往下压成 BEV，每图标出保留了什么、丢掉了什么。 这三图与 SLAM 里「地图怎么存」是同一个问题。

五、关于「晦涩抽象处要配具象图」（本轮学习者特别强调）

本季的抽象点与往年不同：前几季抽象在算法机制，本季抽象在两个地方—— ① 网络结构（残差、分组卷积、窗口注意力，都是看不见摸不着的张量操作）； ② 损失函数（Focal Loss 没有任何视觉输出，是对新手最不友好的一种论文）。

所以本季把抽象变具象的任务比往年更重，规范里放了一张 「抽象概念 → 该画什么具象图」的对照表（20 条），并把其中几条标成视觉锚点不可替换：

抽象概念 具象锚点（不可替换）
全连接层 vs 全卷积 两图并排：左「压成一个向量」、右「输出同尺寸热力图」
YOLO 的网格 真实街景图叠 7×7 网格，标出「每格只管中心落在它里面的物体」

公式的「人话翻译」本季有两种写法： - 网络结构类要给「形状账」——通道数与空间尺寸怎么变，用具体数字走一遍； - 损失函数类必须给一个样本的具体权重——没有数字的损失函数讲解等于没讲。

七、本季的诚实标注（★ 这是本季最要紧的一节）

7.1 三处清单与正文不符（本季新抓到的第 17–19 处）

① ★★★ 第 17 处：清单标「VGG（2015）」，正文其实是 GoogLeNet / Inception。 一级标题是 Going Deeper with Convolutions，作者是 Google 的 Szegedy 等， Abstract 明写「architecture codenamed Inception … called GoogLeNet, a 22 layers deep network」。 而且语料库里根本没有 VGG 的一手论文（全库仅在 2017_SemanticFusion 里被引到一次）。

但是——VGG 在本语料库的被引量远高于 GoogLeNet： 96 篇论文提到 VGG（其中 VGG-16 出现在 25 篇里），而 GoogLeNet/Inception 只有 22 篇。 读者读 SLAM 论文时见到的是 VGG-16 backbone。

处理范式（0187）：主线讲 GoogLeNet（有一手正文，数字可引用）； 开一个「前置补丁：VGG 是谁」小段；VGG 的一切数字标「转引」（共 24 处）， 绝不写「VGG 论文里说……」；并把这次清单失误本身写成教学点—— 连课程清单都会把两个经典网络记混，读者更不能凭名字猜内容。

② ★★ 第 18 处：清单标「PVTv2（2021）」，正文其实是 PVT v1。 真实标题是 Pyramid Vision Transformer: A Versatile Backbone for Dense Prediction without Convolutions——清单漏掉了结尾的五个词，于是把 v1 当成了 v2。 PVTv2 不在语料库里（证据：v1 正文自己写着「we recently propose a solution PVTv2 [66]」， 参考文献 [66] 是 arXiv 2106.13797），所以它的线性 SRA / 卷积前馈 / 重叠 patch embedding 一个字都没进课。 并如实写出 PVT 的「标题张力」：v1 拿「免卷积」当招牌，续作 v2 又把卷积加回来—— 「免卷积」不是终局。不替它圆场。

③ ★ 第 19 处：三维检测综述是 A Comprehensive Survey（不是 Review）， 本地 stem 被截断成 …_A_Comprehens；且全文 0 次出现 SLAM—— 任何「本篇指出与 SLAM 的关系」的说法都是伪造，只能写成「我们的分析」。

7.2 三处「原文没有、绝对不许补」的红线（0195）

LiDAR 硬件那篇： - 没有最大测距 / 扫描频率 / 功耗的任何数值（只有 Fig.2 的定性阴影区与 power-hungry 这个形容词）； - 没有 MPE 数值或激光安全等级； - 没有运动畸变（grep distortion 命中 0）、没有 TDC（命中 0）。

所以 0195 只讲两环，运动畸变只用一小段桥接到第四季，并标注「原文没讲，是我们的分析」。 （本课还顺手讨论了一个典型的污染风险：搜索引擎上前三条就能查到扫描频率与功耗， 很容易顺手写进去——但那样就把「别处的数字」冒充成「本篇的结论」了。）

7.3 两处「零引用」必须据实写

  • Focal Loss 在本语料库零正面引用（255 篇里没有一篇 SLAM 论文正面引用它， 唯一实质引用来自那篇 2023 年三维检测综述）。正确讲法是： 「它是一个被隐式使用的零件——SLAM 论文里那些 YOLO 检测器训练时都在用它这一族损失， 但 SLAM 论文只引 YOLO，不引它的损失。」不编造更多证据。
  • PVT 在本语料库零实引（所有 grep 命中都是 3DPVT、Swing 这类假阳性）。 写它的「SLAM 相关性」只能走 PVT→Swin（concurrent work，Swin 参考文献 [60] 即 PVT） → 地点识别/回环检测 的推断链，且必须显式标注这是推断。

7.4 OCR 损坏的处理

  • YOLO 的损失公式（式 3）在转换出的 Markdown 里已严重损坏（出现 λ_such、 求和上下限写成 i=0 to ∞、指示函数被替换）→ 不直接引用， 改用按正文文字重建的版本，并在公式框上方显式标注损坏与订正来源。
  • 0195 的 11-m / 250-m / 0.18 m CMOS 是 μ 上标被 OCR 丢掉， 按 11 μm / 250 μm / 0.18 μm 判读，文中显式标注「这是判读，不是原文字面」。
  • 另修掉 0189 原文的 OCR 断词（hat → 它与）。
  • 骨架线 4 篇的至少一张表被 MinerU 严重串行（ResNet Table 4/5/6、ResNeXt Table 5、 Swin Table 2/3/5、PVT Table 1–2）→ 引用纪律： 凡涉及「某模型某列某值」的句子都要能指回正文句子，而不是表格单元格。
