第三季学习记录：视觉主干（0040–0072，全季 33 节）

对应课程：第 0040 – 0072 节（语料库阶段 C，视觉主干，共 42 篇；全季 33 节课，89 张具象自绘图） 这一季的定位是把前两季的零件组装成一台真的能跑的机器，并且每个抽象概念都配一张具象自绘图。

一、这一季还清的第三笔债：悬念④「提取 vs 不提取特征」

第一季第 0006 课（LiDAR 里程计综述）提出这个疑问，第二季第 0022 课只给了一个中间态。 第四季的 0046–0050 把整条摆动史走完了：

站 系统 用什么像素 误差在哪度量 为什么走到这一步
1 DTAM（0046） 全部像素 灰度 不用特征点也能建稠密地图；代价是必须 GPU
2 LSD-SLAM（0047） 只取梯度大的像素（半稠密） 灰度 全稠密太贵；而边缘恰恰是信息最多的地方
3 DSO（0048） 约 2000 个均匀分布的点（含弱纹理） 灰度 干脆回到稀疏，但补上光度标定；CPU 实时
4 VI-DSO（0049） 同 DSO 灰度 + 惯性 用 IMU 补上单目缺的尺度
5 SVO（0050） 每帧只跟 120 个 patch；只在关键帧提特征 先灰度、后重投影 把速度推到几百帧

摆动背后的技术裁决（0048 那篇的噪声实验）： 作者人为加两类噪声，看谁先垮。结论一句话——直接法怕几何噪声（卷帘快门、标定不准），间接法怕光度噪声。 原文还给了一个很漂亮的解释：过去的相机是"为人类观看而造"的（几何差、卷帘快门），所以间接法占优； 如今相机开始"为机器视觉而造"（全局快门、精密镜头），直接法才得以发挥全部潜力。

所以"提取 vs 不提取"这个问题本身问错了。 正确问法是：我的相机好不好、场景光变不变、算力够不够。

二、这一季最重要的一个新概念：四象限坐标系（0048）

以前我把"直接法"和"稠密法"当同义词用，这是错的。原文明确说这是两个正交的轴：

间接（算在像素位置上） 直接（算在灰度上）
稀疏 monoSLAM / PTAM / ORB-SLAM DSO
稠密 稠密光流 + 平滑正则 DTAM / LSD-SLAM

DSO 就是"直接但不稠密"的反例——它用的点甚至比 ORB-SLAM 还少（约 2000 个），但误差完全算在灰度上。 这个坐标系一旦建立，之后看到任何一篇视觉 SLAM 论文都能立刻定位。

三、这一季的新规矩：抽象的公式必须配"具象"自绘图

我在第 0040 课里给这一季立了一条新规矩：凡是晦涩抽象、原文又没有好图的地方，都自己画一张具象的图。 "具象"的标准是：画得出真实的房间、相机、桌子、卫星、行人，就绝不画抽象的点线方块。

本批 14 节课一共画了 42 张自绘图，几处我自己觉得最有用的是：

四、这一季新学到的、前两季完全没提的东西

1. t 分布，不是 Huber（0051）

DVO-SLAM 的鲁棒核用的是 t 分布（二变量），不是 Huber。 这一条值得单独记，因为二手资料很容易替它补 Huber——而"不许替原文补东西"正是这套课的一条铁律。 （同类前例：BA 2000 综述没有 Huber/Tukey、PCL 2011 没有任何性能数字、预积分 2017 没有 EuRoC。）

2. 一个指标两个用途：熵比（0051）

DVO-SLAM 用权重分布熵的比值这一个量，同时干两件事： ① 判断当前帧该不该选为新关键帧；② 判断是否发生了回环。 这种"一个物理量承担两个语义"的设计很罕见，也很优雅。

3. 测地邻域，而不是随机采样（0052）

回环候选不能从历史上随机抽帧——那样连出来的"约束"在物理上不可达（要穿墙）。 正确做法是只从沿轨迹相邻的帧里选，也就是用测地距离而不是欧氏距离。

4. 稠密地图与图优化回环有一个结构性矛盾（0052）

完成一次大回环后，位姿虽然被拉正了，但深度图是按旧位姿"烘焙"进体素里的，所以地图出现重影，只能整张重建。 这个矛盾解释了为什么后面 RTAB-Map 要走"记忆管理 + 局部网格"这条路。

5. 边缘化会把线性化点钉死（0049、0053）

这是第二季第 0032 课"先验只在小范围有效"的量化版： 普通边缘化在压缩旧状态时，等于把当时那批变量的线性化点固定住。如果新信息（如 IMU）要求它们大幅改变，先验就会把系统拉偏。 VI-DSO 的解法是同时维护三个先验、按尺度区间接力；DM-VIO 的解法是延迟边缘化（留一个位姿图而不是立刻压缩）。

6. 双目如何一步解决尺度（0044）

ORB-SLAM2 用一条双目基线直接给出绝对尺度，还带来两个副产品： ① 特征匹配只需要在两张图之间做（而不是三张）；② 小运动时漂移更小。 但代价是：远点的视差太小、深度不可信——所以远点几乎不清除，因为它们的方向仍然有用。

八、把第六节那六个疑问逐条销账

当时的疑问 在哪一节答的 一句话答案
1. VINS-Mono 的联合初始化具体怎么解？ 0057 四步「松对齐」：纯视觉 SfM 给形状 → 陀螺与视觉的旋转差标定偏置 → 线性最小二乘一次解出速度/重力/尺度 → 在切平面上迭代细化重力
2. FEJ 到底在防什么？ 0061 防「过度自信」：线性化点如果一直更新，滤波器报告的协方差会越缩越小，而真实误差没变小
3. 延迟边缘化与动态边缘化差在哪？ 0063 动态边缘化只处理一维尺度；延迟边缘化是再维护一张晚 100 帧删帧的因子图，于是能撤销部分边缘化、能回溯注入 IMU 信息
4. 学习先验能不能跟传统后端真正合流？ 0054 / 0055 / 0056 能，但要换思路：不要让网络给答案，让它给一个可优化的低维流形，再交给标准因子图
5. 走出室内之后怎么办？ 0065 / 0066 / 0067 两把尺子：伪距（米级，但要跟接收机钟差一起估）+ 载波相位（刻度极细，但有个整周未知数）

九、第二批新学到的、前两季完全没提的东西

做融合的算术（0054） - 逆方差加权：两个深度估计按「谁的不确定度小就多听谁」融合。同一套公式，两种情形——几何观测可靠时听几何，不可靠时（白墙）结果自然偏向 CNN。手算过：σ 从 0.40 降到 0.24。 - 一个纠正：我一度以为原文给了「33.99% → 55.75% → 64.52%」的精度阶梯，逐行核对后确认原文没有这三个数字。教训还是那条：引用的数字必须能查证。

把「表示」重新设计（0055 / 0056） - code：把一张深度图表示成 128 个数 + 图像的可微函数。关键在于线性解码器——因为 D=D0+J(I)c 里 J 只依赖图像，可以每个关键帧只算一次；非线性的话求一次导最贵要 1 秒。 - proximity 参数化 p=a/(d+a)：近处像深度、远处像逆深度。曲线上的点我都验算过。 - 340 ms 里只有 16 ms 是网络（0056）：其余全花在用 tf.gradients 算雅可比。这条打破了我"深度学习所以慢"的直觉——真正的瓶颈往往是「向模型要梯度的方式」。

滤波派的两件兵器（0059 / 0061） - robocentric：把坐标原点绑在自己身上，消掉「绝对位置」这个会无限增长的量，改善数值行为与一致性。 - QR 分解降维：一个多层 patch 特征产生 256 个强度误差，直接进 EKF 会算不动；QR 之后变成 2×2 + 2×1。注意这是等价变换，不是抽样。 - 一个诚实的失效模式（0059）：速度一发散，滤波器就把特征距离推向无穷远来自保，结果让速度更没得救——正反馈。 - FEJ（0061）：把线性化点钉在第一次估计上。它的价值是「不许滤波器变得更自信」。

边缘化的第三种玩法（0063） - 我们在第二季见过「Schur 补成先验」（0032），在本季见过「动态边缘化」（0049）；DM-VIO 的延迟边缘化是第三种：留一张慢 100 帧的副本，主图照常删、副本留着以便回溯。开销仅 0.8%。

冷启动（0057 / 0064） - 第二季悬念⑤的完整答案有两个版本：VINS-Mono 是「视觉先动起来，再松对齐」；纯惯性初始化是「只有 IMU 也能把重力与尺度解出来」。 - 直觉是：加速度计测的是「重力 + 运动加速度」的合成，重力是其中那个固定的成分，用一段时间的读数做优化就能把它分离出来。

室外（0065 / 0066） - 多路径/NLOS：卫星信号被楼挡住、从墙面反射绕过来，伪距凭空多出一段。这是城市峡谷里定位崩掉的主因。 - 相位模糊度：接收机只知道自己在波上的小数位置，不知道是第几个整周。这是载波相位必须付的代价。 - 三处常见误传被纠正：GNSS 实测是 10 Hz 不是 1 Hz；P³-VINS 原文没给任何具体波长数值；GVINS 只说 robust norm 重加权、没指明用哪种核。

十、第三季三条主线的总收束

主线一：单目尺度不可观（六站，本季走完） 用 sim(3) 显式估（LSD-SLAM）→ 干脆不管（DSO）→ 用 IMU 补（VI-DSO / VINS-Mono）→ 换双目或 RGB-D（ORB-SLAM2 / RTAB-Map）→ 借学习先验（CNN-SLAM）→ 最后用惯性从根上补上（0064 只靠 IMU 就能定重力与尺度）。 结论：尺度问题没有在「单目」框架内被解决，而是被「多一种传感器」补上的。

主线二：架构的分工演化 MonoSLAM（全塞一个状态向量）→ PTAM（跟踪/建图分家）→ ORB-SLAM（三线程）→ ORB-SLAM3（多地图）→ VINS-Mono（按频率分三档输出）。 规律没变：每一次进步都是把一件不该放在同一节奏里的事拆出去。

主线三：滤波 vs 优化（本季补齐） - 优化派的命门是稀疏性 → 所以 VINS-Mono 要费力气做选择性边缘化。 - 滤波派的命门是一致性 → 所以 ROVIO 要选 robocentric、OpenVINS 要 FEJ。 - 两派在 2015–2022 年间逐渐互相吸收：DM-VIO 用位姿图（优化工具）救单目 VIO，Basalt 用 NFR 把历史压成因子。
