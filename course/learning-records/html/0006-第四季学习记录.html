第四季学习记录：激光主干（0073–0094，全季 22 节）

对应课程：第 0073 – 0094 节（语料库阶段 D，激光主干，共 32 篇；22 节课，86 张原图 + 50 张具象自绘图） 读这一季之前的状态：第一季建立了坐标系，第二季打好了数学地基，第三季把视觉那台机器拆完了。

一、这一季到底在回答什么

前四季读下来，有一个规律越来越清楚：每一季都在回答上一季留下的一个问题。

  • 第一季问「这个领域有什么」；
  • 第二季问「支撑这些方法的最小二乘、因子图、预积分到底怎么算」；
  • 第三季问「把这些零件装成一台机器，会长什么样」；
  • 第四季问的是：把相机换成激光雷达，那台机器会变成什么样？

答案是：机器的大形状没变，但有两个零件被彻底换掉了。

① 「用什么信息」变了——相机给的是二维像素，激光直接给三维点。尺度问题消失了，但多出来一个「一帧扫描需要时间」的运动畸变问题。 ② 「数据怎么装」变了——像素不会无限增长，但地图会。于是「用什么数据结构装一棵一直在长的地图」变成了这一季的核心矛盾。

二、四条主线（这一季的骨架）

主线一：提特征 → 不提特征（第二回合）

第三季 0046–0050 讲过视觉侧的完整摆动史。这一季是同一场辩论在激光侧的第二回合，而且终点更极端：

课次 系统 立场
0074 LOAM 提特征（角点 + 平面点），其余全丢
0075 LeGO-LOAM 仍然提，但先分割去噪、再按地面/非地面分两路
0076 NDT-LOAM 前端不提（用加权 NDT），后端仍提
0083 FAST-LIO 仍然提，但换成滤波
0084 FAST-LIO2 彻底不提——所有原始点都用

一个关键的理解：视觉侧要「减少」像素，因为像素弱、多、贵；激光侧要「全都要」，因为三维点本身就是干净的几何量，而「挑特征」这个动作在树木、草丛、非重复扫描上会主动丢掉有用信息。

主线二：数据结构（本季还的那笔债）

课次 结构 插入 删除 并行
0074 静态 k-d 树 整体重建 不支持 差
0084 ikd-Tree 增量 O(logn) 懒惰删除 + box-wise 双线程重建
0085 iVox（体素哈希） O(1) LRU 淘汰 天然并行

这笔债的完整链条：第一季 0006 课第一次提到「ikd-Tree 是 FAST-LIO2 的关键」→ 第二季 0022 课明确写「本文走的是自适应体素化路线，ikd-Tree 是另一条路线，我们留到阶段 D」→ 第三季 0023 课（PCL）把问题立起来：「为什么激光 SLAM 后来需要一棵能动态插入删除的树？」→ 本季 0074 讲了 LOAM「每 sweep 重建一次地图 k-d 树」这个具体开销 → 0084 正面回答。

ikd-Tree 的四件事（第 0084 课）： 1. 点插入 + 树上下采样——新点进来时同一小格里只留离中心最近的； 2. 懒惰删除——删除只打标记，物理删除推迟到重建时； 3. 部分重建——只重建违反平衡准则的那棵子树（书架歪了只扶歪的那一层）； 4. 双线程并行重建 + operation logger——主线程继续跑里程计，后台重建期间的新请求先排队、重建完重放。

一个跨季的呼应：这个「哈希 + 稀疏」的招式，这一季在三个战场都出现过——第二季 0034 的 Voxel Hashing、第三季 0038 的 Instant NGP 多分辨率哈希、本季 0085 的 iVox。

主线三：退化与鲁棒

课次 系统 应对方式
0075 LeGO-LOAM 地面单独约束 3 个自由度
0076 EKF-LOAM 自适应协方差：特征越少越不信激光
0090 COIN-LIO 用反射强度当「照片」做直接法
0090 固态强度篇 用反射强度突变当「线特征」
0090 LI-Init 补上被跳过的初始化
0091 Switch-SLAM 切换 scan-to-map 的初值来源

本季最重要的一个概念澄清：退化不是「数据变少了」，而是「数据里缺少某些方向上的信息」。 均质隧道里激光照样测到成千上万个点，但每一段都一样，所以「我在起点」与「我前进了 10 米」都能解释同一帧数据——数学上表现为 Hessian 在某些方向的特征值趋于零。

主线四：地图与回环

  • 地图表示的第四条路：SuMa++（0082）的面片地图——每个面片自带位置、朝向、大小，还能挂语义标签。它与第二季 0033–0035 的 TSDF 系、第三季 0062 的网格地图、0071 的神经隐式共同构成「地图表示的四条路」。
  • 回环的两条路线（0092）：几何搜索（Cartographer 的分支定界，不靠描述子）与外观检索（BoW3D 的 3D 词袋，描述子是 LinK3D）。
  • 旋转平移不变的地点识别（0093）：RING++ 的 Gram 矩阵——它比的不是「点的坐标」，而是「点与点之间的关系」，所以机器人怎么转、怎么平移，这张表都一样。

三、本季新学到的、前三季完全没提的东西

运动畸变（0074） - 机械旋转激光转一圈要 0.1 秒，这 0.1 秒里车已经开了——于是同一帧里不同时刻采到的点，根本不在同一个坐标系里。 - LOAM 的解法是用一个假设换一个起点：假设 0.1 秒内速度恒定，然后按时间比例线性插值把每个点搬回它被采到的那一刻。 - 这个假设的适用范围很窄（只要求 0.1 秒内成立），所以它大多数时候好用；运动剧烈变化时需要 IMU 介入。

地面只约束三个自由度（0075） - 无限大的平地能约束：竖直平移、横滚、俯仰。 - 约束不到：前后左右平移、航向——因为平地是均匀的，怎么滑都还是同一块平地。 - 这个结论不是拍脑袋定的，是从几何推出来的；LeGO-LOAM 的「两步优化」正建立在这个分工上。

新卡尔曼增益公式（0083） - 旧形式要求逆的矩阵大小 = 测量维度（上千个特征点 → 上千阶）。 - 新形式要求逆的矩阵大小 = 状态维度（18 维）。 - 同一个问题换个写法，要算逆的矩阵就从上千阶降到 18 阶——这就是 FAST-LIO 能实时融合 1200 个以上特征点的全部原因。这与第二季 0019 的 Schur 消元是同一个思想：换个消元顺序，把大矩阵变小。

逐点更新（0086） - 帧级更新：把一帧 0.1 秒内采的点都「摞」到扫描末端那一个位姿上，中间的点被拉弯。 - 逐点更新：每个点在其真实采样时刻就更新一次状态，帧内运动畸变自然消失，带宽可以推到极高（Point-LIO 的 4–8 kHz）。

反射强度（0090） - 激光返回的第二个通道：除了「有多远」，还有「有多亮」。 - 同样是「用强度」，两种用法完全不同：COIN-LIO 把它投影成图像做直接法的 5×5 patch 光度误差（适合大尺度几何退化，但需要高分辨率旋转式激光）；固态强度篇把它的局部突变当「线特征」做点-线配准（适合固态激光的小视场退化，但时间效率不及 FAST-LIO2）。

初始化（0090） - 第二季 0029/0030 讲预积分时，原文明确没有初始化章节；第三季 0057（VINS-Mono 四步松对齐）与 0064（纯惯性初始化）给了视觉侧的答案；本季 0090 的 LI-Init 是激光侧的答案。 - 它做的事：互相关定时间偏移 → 统一优化外参旋转 → 加速度约束估平移/重力/零偏。前提是必须有充分激励（运动不够就初始化不了）。

4D 雷达（0094） - 输出的每个点带「距离 + 方位 + 仰角 + 多普勒速度」。 - 代价：点比激光稀疏得多、噪声大、还有鬼影（玻璃幕墙多次反射产生的虚假目标）。 - 收益：不怕雨雪雾、成本更低、还额外给速度。第一季 0007 课讲过的 FMCW 测多普勒，在这里是同一件事的自然延伸。

五、留给阶段 E（多传感器融合）的疑问

  1. 激光 + 视觉 + 惯性的「三合一」到底怎么耦合？ 本季 0076 的 EKF-LOAM 与 0091 的 Switch-SLAM 都只是「两个传感器互相兜底」，还没到真正三者同时进一个优化。第三季 0065/0066 的 GNSS 是另一种外部信息。
  2. 激光与视觉的「退化互补性」有多强？ 本季反复见到「激光在长走廊失效」，而视觉在无纹理处失效——这两个失效场景是不是正好互补？如果是，那融合的收益就有理论下界。
  3. 时间同步与外参标定：本季 0090 的 LI-Init 解决了激光-IMU 的初始化，但三传感器的时空对齐还没看到。
  4. 4D 雷达 + 视觉 + IMU 会不会成为恶劣天气下的组合方案？

六、以及留给阶段 F / G 的

  • 3DGS 的「自适应密度控制」：第一季 0015 课明确说那篇综述只引用未展开，本季没碰。
  • 神经隐式 SLAM 怎么把 NeRF 塞进在线循环：第二季 0036–0039 是离线表示，第三季 0071 讲了两种组合方式，但真正的在线闭环在阶段 F。
  • 「提取 vs 不提取特征」的第三回合：本季 0084 走到了「不提」，但学习式前端（用网络提特征）是另一条路——阶段 G。

七、一句话总结这一季

它把「怎么用一堆三维点算清自己在哪」这件事，从 2017 年讲到了 2024 年；而这一路上最重要的转折点，是一个反问：「我们为什么要挑特征？」
