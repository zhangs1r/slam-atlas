设计取舍（下次可复用）

  1. "补零件 → 逐式拆解 → 手算 → FAQ → 自测" 是应对"我很久没碰数学"类追问的固定骨架。 零件不进正文而是集中放在第 1 节，学习者可以按需回查，不必在公式中间被术语打断。
  2. 每一节都配一张自绘图（共 7 张，纯内联 SVG，不引外部库）： - 图 1 候选轨迹打分图（房间 + 三条轨迹 + 分数条） - 图 2 三个同学量同一张桌子（解释"量测独立"） - 图 3 论文 Fig. 3 的简化因子图（保留原图蓝/绿配色约定） - 图 4 高斯钟形曲线 + Ω 的胖瘦对照（两条曲线为真实计算的高斯折线， e=1 m 处标注 13.5% = exp(−2)，可核对） - 图 5 山峰 ↔ 山谷（max 翻 min，峰顶与谷底同横坐标） - 图 6 弹簧平衡图（细长弹簧 vs 粗短弹簧 + 两根等长"拉力"色条） - 图 7 三种权重下估计值的滑动对照（13.2 / 12.0 / 10.8） 所有图的解释文字都放在 <figcaption> 里（图内只留最短标签），并统一给 「这张图在画什么 / 怎么看这张图 / 要记住的一句话」三段。 曲线上的数值点用 Python 按公式算好再写进 <polyline>（脚本见 _tmp/gen_poly.py）， 不凭手感画。
  3. 数值算例必须能验算。13.2 m 这个数满足 ∑ωk(x−zk)=0（两边拉力都是 3.2）， 学习者可以用纸笔复核；钟形曲线的 13.5% 也对应 exp(−2)。不要给无法复核的"看起来很像"的数。
  4. 诚实标注"教学用假数字"：第 2 节那张候选取值表（0.80 / 0.10 / 0.40 等）是我们为演示乘法编的， 不是论文数值，课里已显式写明。
  5. SVG 里不写 class 属性（只写内联 fill/stroke），既避免与课程样式表打架， 也避免第 11 节第 ⑥ 项的"未定义类"误报。

顺手核出的两处原文细节（重要）

  1. 原文 (4) 式省略了先验项。 原文第 II-A 节在 (4) 式前一段写了 "assume that the prior can be written as p(𝒳)∝exp(−12‖h0(𝒳)−z0‖Ω02)"， (4) 式第一行也确实是 argmin−log(p(𝒳)∏kp(zk∣𝒳k))， 但最终那行求和只从 k=1 到 m，没有显式写出先验项。 这不是错误、是排版省略，但如果不点明，学习者会觉得"第 0002 课说先验可丢，怎么先验就再也不见了"。 已在答疑页第 5 节用 callout 给出完整形式。
  2. OCR 错误 4 处（已在答疑页第 7 节末尾集中说明）： argmax 下标 χ → 应为花体 𝒳；(2) 式多一个右括号； squared <sub>2</sub>-norm → 应为 squared ℓ₂-norm（ℓ 被吃）；ex p ( - ...) → exp 被断字。

方法论收获

"我看不懂这几行公式"这类追问，本质不是"公式难"，而是"零件缺"。 如果只把公式再讲一遍（换个说法重抄一遍），学习者下次还是卡； 正确做法是先列出他缺的那几个零件（本例 5 个），再让公式变成"零件的组装说明书"。 判断零件清单的方法：逐式追问"这一步用了什么性质"——用到的每个性质就是一个零件。 另配两条： ① 能验算的数值算例比三页推导更能让人产生"我懂了"的感觉，所以这类答疑页必须有一节"手算到底"； ② 答疑页不要混进课程主线——它是"哪里不懂点哪里"的旁支， 一旦混进编号序列，主线进度、课时统计、后续开课都会被牵连（本次即为真实教训）。
