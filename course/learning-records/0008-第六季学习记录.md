## 一、这一季到底在争什么

前五季问的都是**「位姿怎么算」**。这一季换了一个更前面的问题：

> **场景本身，到底存在哪？**

两条答案，本质上是一对反义词：

| | 显式 | 隐式 |
|---|---|---|
| 场景存成什么 | 一堆**明码标价的几何元素**（点、体素、面片、平面、椭球） | 一堆**权重**（网络参数、特征网格里的数） |
| 想删掉一个东西 | 直接删——它就在那儿 | 不知道从哪删：改一处，全世界都跟着动 |
| 想看清楚细节 | 加更多元素，内存跟着涨 | 把网络做大 / 分辨率调高，训练变慢 |
| 「画出来」这一步 | 要有明确的投影与合成规则 | 网络本身就负责回答「这个方向看过去是什么颜色」 |

**这一季的有趣之处在于：它走了一圈又回到了显式。**

iMAP 把地图塞进网络（最激进）→ NICE-SLAM 拆成特征网格（把一部分信息搬回网格）→ Vox-Fusion / ESLAM 用八叉树与平面省内存（网格变稀疏、变平面）→ Point-SLAM 把特征挂到点云上（回到点！）→ **3DGS 干脆回到「一堆椭球」**。而这一圈不是白走的：**3DGS 保留了这条线上最值钱的那个零件——可微渲染**。

## 二、两笔挂了五季的债，这一季还清了

这是本季最值得记的一件事。两笔债都不是「后来有人随便说说」，而是**第一季自己写在账上的**：

### 债① 「3DGS 综述只引用、未展开『自适应密度控制』」（第一季 0015 课写下）

**第 0116 课连本带利还清。** 而且核实的过程抓到一处**方向反了的常见误传**——我自己的初稿就写错了：

| | 条件 | 动作 | 体积怎么变 |
|---|---|---|---|
| **克隆 clone** | **欠重建**（高斯太小，盖不住这块几何） | 复制一个**同样大**的高斯，沿位置梯度推一步 | 变大 |
| **切分 split** | **过度重建**（一个大高斯糊住了一小块几何） | 一分为二，各自尺度**除以 1.6** | 不变 |

关键判据是**「高斯相对于它要盖的几何是太大还是太小」**——不是「高斯数量多不多」。另有一条容易被忽略但很关键的机制：**周期性把所有高斯的不透明度重置到接近 0**，让「占着位置却没在干活」的高斯被淘汰、重新参与竞争。

（这条的教训我单列在下面第四节。）

### 债② 「隐式地图方法在大尺度户外的有效性尚未被证明」（第一季 0010 课写下）

**第 0111 课与 0121 课给出正面证据。**

- **0111 PIN-SLAM**：把地图做成「可形变的神经点云」，回环来了就**把点整体拉过去**，而不是重训网络；里程计与回环齐备——这是第一个**完整**的隐式 SLAM，而且能跑两万帧级别的序列（激光侧）。
- **0121 Splat-SLAM**：纯 RGB、带回环、全局优化（高斯侧）。

**但这里要诚实**：这两条证据都是「特定条件下成立」，还谈不上「隐式方法已经全面适用于大尺度户外」。我在课里把它写成「**这条判断第一次被正面回应**」，而不是「已经被推翻」——因为**未被证明 ≠ 已被证否**，反过来也一样。

## 三、本季最反直觉的三个认识

### ① 回环发生时，真正被改动的东西比想象的浅

我原本以为「隐式地图要回环，就得重训网络」。**本季六篇读下来，结论几乎一致相反**：

> **不动 MLP 权重，只动显式锚点（点、子图、控制点），加一个跟着走的小 MLP。**

原因很直白：MLP 权重是**全局纠缠**的——调一个数，整个场景都变。而点、子图这些「锚点」是**局部的、可以整体搬运**的。所以 Loopy-SLAM 用点基 submap + 位姿图，PIN-SLAM 用可形变神经点，GO-SLAM 用全局优化 + 即时重建。

**这就是「改动落在哪一层」的问题**——本季第 0110 课专门用一张三层结构图讲它。

### ② 稠密表示碰上动态物体，代价比稀疏时大得多

第三季 0068 课讲动态环境时，代价是「**几个特征点被污染**」。到了稠密/隐式表示，代价升级成「**地图上长出一整块根本不存在的几何**」——因为它不筛点，它是「把每个像素/每个体素都拟合上」。

所以第 0114 课我把这一句当成题眼：**「静态假设一旦破，稠密地图长出的不是几个坏点，而是整块幽灵。」**

而 0121 的 WildGS-SLAM 给了本季最漂亮的一招：**用 DINOv2 特征的「不确定度」当『这东西可能不是真的』的信号**——不需要深度、不需要语义标签、不需要分割网络。它的思路是：同一处在几帧之间特征对不上 → 说明这里要么在动、要么不真。

### ③ 「逐场景优化」这件事，终于有人正面挑战了

3DGS 与它的一大批后续，都是「**一个场景优化一遍**」——这其实是第二季 0027 课 COLMAP「离线 SfM 逐场景优化」那条老路的延续。

**第 0124 课的 GPS-Gaussian 问的是：能不能不优化？** 答案是能：一次前向推理直接出可渲染的高斯。**但边界很窄**——它只在人体上验证过，而且不是 SLAM。我在课里如实写成了「这是『泛化』这条不成熟环节的一个回应，但远不是通用解」。

## 四、被纠正的六处错误假设（这一季最多）

精读 agent 和逐句核实一共纠正了我**六处**：

| # | 我原本以为 | 正文实际是 | 影响 |
|---|---|---|---|
| 1 | 欠重建 → split，过度重建 → clone | **反了**：欠重建 → **clone**，过度重建 → **split** | 还债课的核心方向，必须对 |
| 2 | 隐式/神经地图回环会重训 MLP 权重 | **不动 MLP，只动显式锚点 + 小 MLP** | 影响整组「回环怎么改」的叙事 |
| 3 | NeRF-SLAM / NeRF-LOAM 有回环 | **都没有回环**（已用 grep 验证） | 避免替论文编功能 |
| 4 | Orbeez-SLAM 是动态环境方法 | 是**静态世界**的实时隐式 SLAM | 影响它在模块里的定位 |
| 5 | OVD-SLAM 用开放词汇检测（标题写 OVD） | **实际只用 YOLOv5 语义分割** | 典型的「标题不可信」案例 |
| 6 | GS-IR 的法向来自 SDF 蒸馏 | 来自**深度梯度**；SuGaR 也不是独立 SDF 网络，而是从密度导出 | 避免张冠李戴 |

**这六条里，第 1、2、5 条属于同一类：叙事顺滑的版本 ≠ 正文的版本。** 我在写作简报里已经养成习惯写一句「若与正文不符请指出」，这一季它救了六次。

## 五、三条主线的本季进展

### 主线一：「地图里存什么」——这条最长线索的第五次换血

第二季 `0033` TSDF（每格一个标量距离）→ `0034` Voxel Hashing（体素块 + 哈希）→ 第四季 `0084` ikd-Tree（能增量插入删除的树）→ 第五季 `0100`（**存拟合好的平面**）→ **本季：网络权重 → 多层级特征网格 → 八叉树 → 特征平面 → 点上的特征 → 椭球**。

本季给这条线补上了两个以前没出现过的维度：
- **「信息存哪」可以分层**（显式锚点 + 隐式特征）；
- **「表示」与「渲染」可以合流**（第五季 0098 的高斯地图本身就是可渲染的；本季 0116–0121 把这件事做成了完整的 SLAM）。

### 主线二：「提取 vs 不提取特征」——本季出现第三回合的苗头

第一回合在视觉（第三季 0046–0050：DTAM → LSD-SLAM → DSO → SVO），第二回合在激光（第四季 0074 → 0084：LOAM 提特征 → FAST-LIO2 彻底不提）。

**本季是「换一个层面重问」**：不再问「要不要提特征」，而是问「**要不要显式地存几何**」——iMAP 连点都不存，3DGS 存成椭球，SuGaR 又把椭球压回表面抽网格。**这三步的摆动，与前面两回合是同一种张力的不同表现。**

### 主线三：一致性从「数学保证」变成「学出来的东西」

第二季 `0022` 的 NEES、第三季 `0061` 的 FEJ，都是在**用数学手段保证估计量一致**。本季 0113 的 NeurAR 换了一条路：**让网络自己报「我有多不确定」**，再用这个置信度过滤不可信区域、指导下一步看哪里。

**这是第一季 0011 课承认的六个不成熟环节里「概率化 / 置信度」那一条的一个具体回应**——但要注意，它是「学出来的不确定性」，与 NEES 那种有统计保证的检验不是一回事。

## 六、留给后面阶段的疑问

1. **语义建图到底能不能定量评估？** 第一季 `0012` 课写过「语义建图质量无法定量评估，只能用定位精度作 proxy」。本季 0120（SNI-SLAM）与 0123（LangSplat）都在建语义地图，但**评价方式依然是间接的**。这条债还没还。
2. **高斯怎么压到机载？** 0125 把显存砍了 96%，但那是在桌面 GPU 上的实验。第五季 `0119` Photo-SLAM 明确面向 Jetson，本季 0125 的内存压缩是它的续集——**两者的交集（嵌入式 + 压缩 + SLAM）还没有人做完整**。
3. **隐式表示的失败模式怎么诊断？** 第一季 `0010` 课提到过、本季第二季 `0037` 也引用过 NeRF 作者自己的话：「体素与网格能推理出『渲染质量会在哪里退步』，但把场景编码进网络权重之后，**这些问题变得无法分析**」。本季读到的所有工作，**都还没有回答这个问题**。
4. **「提特征 vs 不提特征」的第三回合什么时候来？** 本季只是在「要不要显式存几何」这个层面上摆动了一次。真正把学习式描述子塞进完整 SLAM 的这一支（阶段 G），还没读。
5. **回环时「可移动的那一层」有没有理论边界？** 本季的答案（动锚点、不动权重）是工程上成立的，但**没人回答「什么样的信息必须存在不可动的那一层」**。
