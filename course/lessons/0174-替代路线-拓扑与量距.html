替代路线：拓扑与量距

前面六节都在想办法「筛掉假回环」。有没有可能干脆换一条路，让它无从产生？🛣️ 这一节看两条绕行路线。

本节目标

读完你应该能：说清「拓扑建图」与「量距定位」各自绕开了什么；用带宽账解释 MR-TopoMap 通信降 84–90% 是怎么来的；如实说出 MR-TopoMap 的边界（它管探索与拓扑，不管全局一致的位姿图鲁棒解）；用自己的话讲清 UWB 为什么能不靠回环定出相对位置；把整块七节课的方法家族串成一张图。

和前面课程怎么接

★ 本节是 0168 那条「假回环铁律」（更早的根是 第七季 0140）的第三条出路：前六节的 PCM / GNC / ADMM 都是「正面把假的筛掉」，本节是「换一类观测量，让它根本没机会假」。★ 「拓扑」这个表示法回链 0163 Kimera 的 DSG 场景图——DSG 的 Layer 3「Places」就是地点节点，MR-TopoMap 的思路与它同源但更轻。★ UWB 量距是第五季 0095–0103 多传感器融合的地盘——把一种全新的传感器（无线测距）揉进 VIO，正是那一季讲过的「统一场景表示」问题的又一次翻版。★ 紧耦合因子图的写法回链 第二季位姿图与第三季 VIO。

1. 先说人话：与其解决难题，不如换一道题

前面六节课都在跟同一个敌人缠斗：假回环。0168 讲它为什么在多机里更致命，0169 讲用 GNC 让它自己退出，0170 讲用描述子提高匹配质量，0171 讲分布式版 GNC，0172 讲怎么少验证一点，0173 讲近场远场分开处理。它们的共同前提是：我们仍然要用「机间回环」这个工具，所以要学会分辨它的真假。

本节的两篇论文换了问法：为什么非要用回环不可？

  • MR-TopoMap（2022）：不追求在地图层面拼出一张全局一致的三维地图，而是让每台机器人只维护一张拓扑图——顶点是「地点」、边是「这两处连通」。机器人之间只交换新建的顶点和边，本地的密栅格地图压根不上路。既然不拼密地图，也就没有「缝歪两台地图」这回事。
  • VI-Range（2022）：不要回环，改用 UWB 无线测距——我不用认出「你去过哪」，我只要知道你此刻离我几米。距离是一个直接测出来的数，没有「认错地方」的余地。

两篇的共同点很漂亮：换掉观测量，而不是把观测量的错误筛得更狠。这是本块第三条出路。

2. 论文一：MR-TopoMap（2022）——通信受限下的拓扑探索

MR-TopoMap（Zhang 等，IEEE RA-L 2022）是一套通信受限多机探索框架。它的设计非常彻底：

  • 每台机器人本地跑 Cartographer 建占据栅格地图，但这张栅格只留在本地、永不外传；
  • 机器人从自己的视角里提炼出拓扑顶点：到了一个「新地点」就建一个顶点，顶点上挂一枚全景图像描述子（用来表达「这里长什么样」）；顶点之间用边表示连通；
  • 两台机器人偶遇时，只交换新建的顶点与边；靠比较描述子的内积找「同名地点」（相似度阈值 th = 0.75），找到就用一条相对位姿边把两张拓扑图接起来。

效果很直接：小规模场景通信 77.3 kB 对 493 kB（降 84%），大规模 135.3 kB 对 1403.7 kB（降 90%）；同时探索效率比 RRT / MMPF 提高 23%–77%（拓扑图天然适合「哪里还没去过」的决策）。实验既有 Gazebo 仿真，也有真机（Jetson Xavier NX）。

它甚至顺手解决了一个「假回环的轻量版」：如果一条候选匹配把两台机器人的图拼成了自相矛盾的样子，它就用多假设中值把离群的变换挤出去（下一节看图）。这是一种比 PCM / GNC 更土、但也更省算力的办法。

3. ★ 诚实说明：MR-TopoMap 不是完整的协同 SLAM 后端

这一节必须把边界说清楚，否则很容易高估它。MR-TopoMap 的定位是通信受限下的多机器人探索 + 拓扑建图框架，它不是一套完整的协同 SLAM 后端：

它管什么

探索决策（哪条路还没走过）、拓扑图的构建与合并、地点级别的数据关联（靠全景描述子）与误匹配剔除（多假设中值）。

它不管什么

全局一致的位姿图鲁棒解；跨机器人地图的尺度统一；稠密几何精度。原文自己也承认：拓扑图不含几何细节，长期大范围漂移未处理。

换句话说：它回答的是「大家去过哪些地方、彼此怎么连通」，而不是「把所有位姿在一张图上解到全局最优」。把它和 0168–0173 那些系统并列时，要清楚它们是两个不同层级的东西——前者是任务级 / 表示级的省通信，后者是后端优化级的鲁棒性。这个区别说清了，它的价值才看得准：在「带宽窄、机器人多、任务只是探索」的场景下，拓扑路线可能是最划算的选择。

$$ \hat{T} = \operatorname{median}\{\, T_1,\ T_2,\ \dots,\ T_k \,\} $$
输入：同一条候选匹配给出的若干组相对变换假设 T₁…T_k → 处理：逐分量取中位数 → 输出：一个被少数离群值拉不动的稳健变换估计

这句话在说什么：① 这个式子在算「从一堆互相不太一致的候选变换里，挑出一个代表」；② 为什么这样就能判对——和取平均不同，中位数只关心「排在中间的那个」，少数几个离谱的候选（比如一条错匹配算出来的变换）根本影响不到中间位置；③ 什么时候把某个观测当回事——它把每一条候选都当输入，但不给任何一条特别大的话语权；只要离群候选不到一半，估计就不会被带跑。这就是它比「加权平均」更能抗假回环的原因，也是它比 PCM（求最大团）更省算力的原因。

4. 论文二：VI-Range（2022）——用一条测距线代替回环

第二篇的脑洞更大：如果两台机器人之间能直接测出距离，为什么还要费力去「认出同一个地方」？这就是 VI-Range（Nguyen、Nguyen、Xie 等，IEEE RA-L 2022，NTU）的核心：给机器人装上 UWB（超宽带无线测距） 模块，测出两台机器人之间的距离，把这个距离当作观测量塞进视觉惯性优化里，从而不需要回环、也不需要轨迹重叠。

它叫「柔性（flexible）」正是因为这个：两台机器人可以各飞各的、从不在同一个地方出现，只要它们能互相测到距离，相对位姿就能被约束住。而且它很省——机器人之间只传邻机的里程计，不传图像、不传地图、不传描述子，是本块「传什么」光谱最右端的那一档。

技术上是两阶段：

  • RTE（长滑窗，约 10 秒）：用一个 4 自由度的随机游走漂移模型去精化两机之间的相对变换；距离残差写作「实测距离 − 预测距离」，还做了天线偏移的空间校准（因为 UWB 天线不装在机器人中心，差几厘米就够呛）;
  • VIRO（短滑窗，10 个关键帧）：把相机、IMU、UWB 三者紧耦合进同一个因子图里一起优化，让距离直接参与定位。

实验：两台四旋翼在 6 m × 6 m 室内飞行（VICON 做真值），整体 ATE 相比基线降低 26.2%，各组飞行的 ATE 在 0.04–0.13 m 之间；UWB 噪声标准差按 σ_r = 0.1 m 建模；计算耗时 VIRO 约 20.4 ms、RTE 约 10.9 ms，实时。论文还做了 N = 3、5 的仿真，但真机实验只有 N = 2——这一点要如实记住，别把它的可扩展性当成已验证的事实。

$$ E_{r} = \sum_{i} \bigl\|\, d_i - \bigl\| {}^{W}\!a_{12}\,p \,\bigr\| \,\bigr\|^{2}_{W_{r}} $$
输入：UWB 实测距离 dᵢ 与两机在世界系下的位置 p → 处理：把位置算成「预测距离」，与实测相减得残差，再按权重 W_r 加权 → 输出：这组距离观测带来的总误差

这句话在说什么：① 这个式子在算「我测到的距离，和你现在的位置算出来的距离，差了多远」；② 为什么这样就能判对——距离是直接测出来的物理量，没有「认错地方」的概念，所以残差小就意味着两台机器人的相对位置确实摆对了；③ 权重 / 标定什么时候把观测当回事——W_r 由距离测量噪声决定，而且原文做了空间校准（因为 UWB 天线不装在机器人几何中心，天线偏移 `a₁₂` 是必须补的），测距没做这个校准，误差会有几十厘米。补齐之后，这个残差就直接给两台机器人的相对位置提供了锚点。

$$ W_{d}^{j} = \Sigma_{drift}^{-1} + \bigl({}^{W}\!\hat{R}\bigr)\, W_{m}^{j}\, \bigl({}^{W}\!\hat{R}\bigr)^{\!\top} $$
输入：漂移协方差 Σ_drift 与运动补偿权重 W_m^j → 处理：用当前估计的姿态 R̂ 把机体系的权重旋转到世界系，再与漂移项相加 → 输出：综合权重 W_d^j

这句话在说什么：① 这个式子在算「这条距离观测该被信多少」；② 为什么这样就能判对——VIO 的漂移是有方向性的（沿轨迹方向漂得多、垂直方向漂得少），而运动补偿权重 W_m 会在机器人拐弯、加速的时候把这条约束说得更重；两片信息相加，权重就更贴合当下这一刻的真实不确定性；③ 权重什么时候把观测当回事——轨迹走得稳、运动平稳时，W_m 小、主要由漂移项说话；一旦做剧烈机动，W_m 变大，距离观测的话语权就被抬上来。这是「随运动状态动态调权」的典型做法，和固定核函数（0169 的 TLS）是两种哲学。

5. 两条路线怎么选：一场诚实的对照

把两篇放在一起看，它们其实在回答同一道题的两个不同答案：「如果带宽极度受限 / 环境极度缺少特征，我怎么让多机保持一致？」

对比项 MR-TopoMap（拓扑） VI-Range（量距）
绕开难题的方式不拼密地图，只拼拓扑不认地点，直接测距离
机间传什么新建的顶点（地点 + 全景描述子）与边仅邻机里程计（距离由 UWB 直接测）
额外硬件全景相机UWB 测距模块
抗假回环的手段多假设中值（挤掉离群变换）不需要——距离没有真假之分
代表数字通信降 84%–90%；探索效率 +23%–77%ATE 降 26.2%；飞行 ATE 0.04–0.13 m
主要局限不是完整协同 SLAM 后端；无几何细节；长期漂移未处理依赖 UWB 硬件与标定；真机只验证了 N = 2

一句话总结我们的判断（这是本课的归纳，不是原文自评）：拓扑路线是「任务层的省」——它把要共享的东西降到最低，适合探索型任务；量距路线是「感知层的换」——它引入一类全新的、不会真假混淆的观测量，适合有硬件条件、且机器人体积 / 功耗允许的场景。两条路都不解决「位姿图全局最优」这件事，因此它们是补充而不是替代：0168–0173 的那些鲁棒后端，在需要高精度全局一致的场合仍然不可少。

6. 本块收束：七节课其实是一条线

走到这里，多机协同块讲完了。把七节课按顺序串起来，你会发现它其实是一条非常干净的推理链：

  • 0168：先说清为什么难——多机一次假回环会同时毁掉两台机器人的地图，并交代「中心化 → 分布式 → 去中心化」三档主线与「传什么」的带宽光谱；
  • 0169：量出中心化的天花板（COVINS 12 台 / LAMP 2.0 地下 6 km），讲清它撞的三面墙，并第一次引出 GNC 渐进非凸；
  • 0170：把服务器拆掉，靠描述子当机间通用语言（Scan Context → LiDAR-Iris → DELIGHT），后端用分布式 Gauss-Seidel；
  • 0171：分布式还不够，还要出度量-语义网格，于是有了 D-GNC（GNC 初始化 + RBCD）与 LMO 网格变形；
  • 0172：把「省」推到极致——去中心化 + 稀疏化，用光谱优先化只挑最少的回环，带宽差出约 100×；
  • 0173：换一个场景（空中集群），把 decentralized 与 distributed 讲清楚，并提出近场 / 远场双模式与异步 ARock；
  • 0174（本节）：最后给出两条绕行路线——拓扑与量距，换掉观测量而非更狠地筛。

而所有方法都落在四个家族里：PCM 族（最大一致集，简单但漏真）、GNC 族（渐进非凸，在线且保真）、ADMM / ARock（把大问题拆成异步子问题）、替代路线（拓扑与量距，绕开关联）。

课后练习

  1. MR-TopoMap 的「通信降 84%–90%」是怎么算出来的？它省下的到底是什么？
    展开查看答案
    因为它根本不传本地那张占据栅格地图（只留在机器人本地），机器人之间只交换新建的拓扑顶点（地点 + 全景描述子）与边。小规模场景 77.3 kB 对 493 kB（降 84%），大规模 135.3 kB 对 1403.7 kB（降 90%）。省下的是「稠密几何信息」的传输量，代价是拓扑图不含几何细节。
  2. 为什么必须说明「MR-TopoMap 不是完整的协同 SLAM 后端」？它不管什么？
    展开查看答案
    因为它做的是「多机器人探索 + 拓扑建图」：管探索决策、拓扑构建与合并、地点级数据关联与误匹配剔除，但不做全局一致的位姿图鲁棒解、不做跨机器人尺度统一、不追求稠密几何精度（原文自述拓扑图不含几何细节、长期漂移未处理）。把它和 0168–0173 的系统并列时要说清这是不同层级的东西，否则会高估它。
  3. 「多变换中值」为什么能剔除误匹配？它的失效条件是什么？
    展开查看答案
    同一条候选匹配会给出多组相对变换假设，取逐分量中位数时只认「排在中间的那个」，少数离谱的离群变换影响不到中间位置，所以它比加权平均更抗假回环，也比求最大团（PCM）更省算力。失效条件：离群候选占到一半以上时，中位数本身就会被污染，稳健性不再成立。
  4. VI-Range 为什么能做到「两台机器人不要求轨迹重叠」？它为此付出了什么代价？
    展开查看答案
    因为它用 UWB 直接测出两机之间的距离，把距离当作观测量紧耦合进视觉惯性优化（RTE 长滑窗精化相对变换 + VIRO 短滑窗相机-IMU-UWB 紧耦合）。距离是直接测出的物理量，不需要「认出同一个地点」，所以不必轨迹重叠，两机之间也只需传邻机里程计。代价：必须携带 UWB 硬件，且要做天线偏移的空间校准（否则误差可达几十厘米）；真机实验只验证了 N = 2（N = 3、5 仅仿真）。
  5. 用一句话说明：本块的「正面路线」和「替代路线」分别在对什么问题作答？
    展开查看答案
    正面路线（PCM / GNC / ADMM）回答「怎么把假的机间关联甄别出来并剔除」；替代路线（拓扑 / 量距）回答「能不能换掉共享的表示或观测量，让假回环这件事根本不发生」。前者是优化层的鲁棒性，后者是表示层 / 感知层的取舍，两者互补而非互替。
