2. 两条路线的总对照

本季的全部张力，都能收进 0104 课那张"三种存法"的坐标系的左中右三格里。而十年之争的主战场，是中间那一格（隐式）与右边那一格（3D 高斯）。

3. 两笔债，结清了没有

债① ：3DGS 的「自适应密度控制」——结清

第一季 0015 课读的是 3D 高斯的综述，那份综述在讲"高斯怎么长出来、怎么删掉"时只是引用，没有展开。当时我在课上明确写了一句「留到阶段 F」。

0116 节把这一笔连本带利还了，而且答案比预想的更"接地气"：

触发条件

看视角空间位置梯度的平均幅度是否超过阈值（原文取 $0.0002$）。原文的观察是：欠重建与过度重建两种情况都会有大的梯度。

欠重建 → 克隆

小高斯盖不住小几何时，复制一个同样大小的，沿位置梯度方向推开。体积↑、数量↑。

过度重建 → 分裂

一个大 splat 糊住小块几何时，换成两个，尺度各除以 $1.6$。体积不变、数量↑。

周期重置不透明度

每 3000 次迭代把所有高斯的不透明度压回近零，让它们重新竞争——防止靠近相机的漂浮物失控增殖。

这一笔债的额外收获：它顺带回答了一个更根本的问题——"什么时候该加一个高斯"这件事并没有唯一答案。3DGS 原著靠梯度，SplaTAM 靠轮廓掩码，GS-SLAM 靠自适应增删（0118 节）。同一件事有三套启发式规则，说明它本质上还是个工程判断，而不是可以从第一原理推出来的定理。

债② ：「隐式方法在大尺度户外的有效性」——部分回答，但仍有余地

第一季 0010 课讲"建图三分类"时，我引用了当时的判断：隐式地图方法在大尺度户外的有效性尚未被证明。那句话在当时是诚实的——iMAP 那一代工作确实只在房间尺度验证过。

现在手里有了 2024–2025 年的证据。我的判断是：这条判断已经被显著削弱，但还没有被完全推翻。依据如下：

证据 支持"已被证明"的部分 仍留有余地的部分
PIN-SLAM（0111）
激光侧		 城区车行约 2 万帧激光、无 GNSS/IMU/轮速；KITTI 有回环序列 ATE RMSE 1.0 m（仅里程计是 3.2 m）。原文自称"首个面向大尺度环境的神经隐式激光里程计与建图方法"。 原文承认固定分辨率点、不用 IMU、语义不进里程计与回环。
PLGSLAM（0112）
RGB-D		 证明了大尺度室内（Apartment 多房间、>12000 帧）可行。 仍是室内 + RGB-D，且无严格回环（用局部到全局 BA 代替）。
Splat-SLAM（0121）
纯 RGB		 自称"首个纯 RGB、且带全局优化跟踪的 SLAM 系统"，含在线回环与每 20 个关键帧一次的全局 BA。 依赖 DROID-SLAM 的光流与单目深度先验；"大尺度"与自动驾驶那种公里级仍有距离。
反例：NeRF-LOAM（0112） ——（它的贡献是"隐式版增量激光里程计"） 无回环，且被 PIN-SLAM 实测为 4.43 s/帧（比 PIN-SLAM 慢约 30 倍）——说明同一方向上不同工作的完成度差别很大。

为什么我说"还没有被完全推翻"：① 上面这些证据各自都带着明确的限定条件（激光/室内/RGB-only 各占一角，而且都依赖某个外部模块提供位姿或光流）；② "大尺度"的口径在论文之间并不统一——两万帧的城区与自动驾驶动辄几十公里的连续行驶，不是同一个量级；③ 第一季那句话的严格表述是"有效性尚未被证明"，而"证明"在工程意义上需要的是跨场景、跨传感器、可复现的证据，目前还只有分散的正面案例。所以更准确的说法是：这条判断从"完全没有证据"变成了"有若干带条件的正面证据"——它被削弱了，但把它当作已解决，会掩盖那些限定条件。

4. 「地图里存什么」的完整谱系

这是本项目贯穿六季的最长一条线索，每一站都在同一个问题上换答案。这一季走到了它的两个极端。

5. 四条主线的收束

主线一 · 隐式 vs 显式

起点：第二季 0036–0039（离线的 NeRF / Instant NGP / Plenoxels，显式与隐式之争第一次出现）。
本季：0105–0109 把隐式推进到能在线用，0116–0126 把显式推进到能做 SLAM。
结论：没有赢家，两边都在往中间靠——隐式加显式外壳，显式学可微渲染。

主线二 · 地图里存什么

六次换血：TSDF → 体素块 → 可增量树 → 平面 → 函数权重 → 椭球。
规律：每次换血都是为了补一个具体短板（内存、增量、抗噪、可渲染），不是因为"新"。

主线三 · 位姿与地图的关系

第二–五季：位姿与地图是两件事——先估位姿，再把观测填进地图。
本季：两者互相推——渲染误差同时推动位姿与地图参数。这是范式级的改变，在 0117 MonoGS 一节讲得最清楚。

主线四 · 回环与全局一致

稀疏 SLAM 里：改位姿就够了（第四季 0078 因子图）。
稠密/隐式里：必须连地图本身一起改——要么让表示可形变（0111 PIN-SLAM 的弹性神经点），要么让高斯的均值随位姿非刚性更新（0121 Splat-SLAM）。

5.1 一个跨季的对照：同一件事，三种"分工"

"把地图与位姿分开算"还是"一起算"，这条线在六季里出现过三次，每次都换了一种解释方式：

课次 谁与谁一起算 代价
第二季 0019 / 0027 BA：相机位姿与三维点一起（用 Schur 消元把点消掉） 要利用稀疏性；点一消，回代能拿回来
第三季 0057 / 0058 VINS：位姿、速度、偏置、重力、尺度全在一个滑窗里 要选择性边缘化；特征点的"structureless"处理
本季 0117 / 0121 高斯 SLAM：位姿与每个高斯的参数一起被渲染误差推动 计算量大、要专门设计地图更新策略（Splat-SLAM 的"地图形变"）

看出规律了吗：三次都是"一起算更准，但要为计算量付出代价"。这条规律从第二季的 Schur 消元一路到本季的高斯参数联合优化，没变过——变的只是"被一起算的那些东西"叫什么。

6. 留给下一阶段的问题

每读完一季我留一份疑问清单。这一季留下的，基本都指向同一个方向：这个表示能不能变成"通用资产"？

  1. 学习式那一支到底走到哪了？本季只读了一篇 2020 年的 DeepV2D（可微 SfM 的起点）。而第一季 0011 课列出的"深度学习四分类"（模块化 / 联合 / 置信度 / 主动学习）与它承认的六个不成熟环节，在近几年的学习式工作里被解决到什么程度了？——指向阶段 G（学习式方法，31 篇）。
  2. 这些"好看的地图"最终服务于谁？本季很多工作止步于"渲染得好、重建得准"。但在真实机器人上，地图是用来做决策的——导航、抓取、探索。0123 节的 GaussianGrasper 是一个开始（语言高斯用于抓取），但那条路还很短。
  3. 动态与语义这两条支线会不会合流？本季的 WildGS-SLAM（0121）用特征不确定度避开语义标注，HUGS（0126）在城市级场景里做动静分离。两者的思路很不同，但目标一致——让地图知道"哪些东西会动、那些东西是什么"。
  4. 评测口径要不要统一？本季反复遇到"不好比"的问题：PIN-SLAM 的"大尺度"与 PLGSLAM 的"大尺度"不是一个量级；NeRF-LOAM 的 4.43 s/帧 与 PIN-SLAM 的 0.14 s/帧 差距巨大，但两者都自称"实时里程计与建图"。——指向阶段 I（数据集与评测，5 篇）。
  5. 显存这件事有没有根本解法？0125 节的内存压缩是"在现有框架里省"，但几百万个高斯这个量级本身是不是必需的？——这是本季最实际、也最没有定论的问题。

课后练习

  1. 用不超过 150 字，向一个没读过任何论文的人解释：为什么 3DGS 比 NeRF 快得多？必须提到"渲染一个像素要做什么"这个关键差别。
    展开查看答案

    NeRF 渲染一个像素，要沿那条光线取上百个点、每个点都跑一遍神经网络问"这里多密、什么颜色"，再累加。3DGS 不这么做：它场景里存的全是"椭球"，渲染时先把椭球投影到屏幕上变成一小片（这是纯几何运算，不用网络），再按深度顺序把这一小片叠上去。所以 NeRF 的瓶颈是"上百次网络查询"，而 3DGS 的瓶颈只是"排序 + 叠加"——后者在 GPU 上便宜得多。

  2. 本季的 3DGS 原著用"梯度大小"决定哪里该加高斯，SplaTAM 用"轮廓掩码"，GS-SLAM 用"自适应增删"。为什么同一件事会有三套不同的规则？这说明了什么？
    展开查看答案

    因为"哪里还没有被重建好"这件事本身没有一个可以直接测量的量，只能找代理信号：3DGS 认为"梯度大"说明这里没重建好（优化正试图移动它）；SplaTAM 认为"渲染出的剪影与真实前景对不上"说明这里缺高斯；GS-SLAM 从尺度与可靠性出发做增删。

    这说明"什么时候该加高斯"本质上是工程启发式，而不是能从第一原理推出的定理。这也解释了为什么本季 10 节高斯课几乎每节都在改这条规则——它是这类系统最活跃的改进点之一。

  3. 为什么"回环来了怎么改"这个问题，在稀疏 SLAM 里很简单（改位姿即可），在隐式/高斯地图里却很麻烦？本季分别有谁在处理它、怎么处理？
    展开查看答案

    为什么麻烦：稀疏 SLAM 的地图（点、路标）与位姿是分开存的，位姿改了，地图点可以不动（或只做一次整体变换）。而隐式地图的"内容"就藏在网络权重或特征网格里，改权重会牵动全局；高斯地图虽然"可指"，但几百万个椭球的位姿都得跟着改。

    谁在处理：① PIN-SLAM（0111）：把特征挂在"神经点"上，回环时这些点整体被刚体变换搬走（原文的"弹性/可形变"），而 MLP 解码器不用重训；② Loopy-SLAM（0110）：用点基 submap + 位姿图；③ Splat-SLAM（0121）：高斯的均值、尺度、旋转随关键帧位姿非刚性形变，并每隔 20 个关键帧做一次全局 BA。

    共同手法：都是"让表示本身可变形"——因为让网络权重"变形"太难，那就给地图加一层可动的显式锚点。

  4. 第一季 0010 课那句"隐式地图方法在大尺度户外的有效性尚未被证明"，本季给出的证据支持"已被证明"还是"仍未被证明"？请给出你的判断并说明依据。
    展开查看答案

    较准确的回答是"被显著削弱，但没有被完全推翻"。

    支持被证明的证据：PIN-SLAM 在城区车行约 2 万帧激光、无 GNSS/IMU 的条件下做到了全局一致（KITTI 有回环序列 ATE RMSE 1.0 m），并自称"首个面向大尺度环境的神经隐式激光里程计与建图方法"；PLGSLAM 证明了多房间的大尺度室内可行；Splat-SLAM 自称"首个纯 RGB 且带全局优化跟踪"的系统。

    仍留余地的部分：① 每条证据都带明确限定（分别是激光 / 室内 RGB-D / 依赖 DROID 光流）；② "大尺度"的口径不统一——两万帧城区与自动驾驶的连续几十公里不是一个量级；③ 反例 NeRF-LOAM 同样宣称大尺度激光隐式建图，却连回环都没有、且慢 30 倍，说明同方向工作的完成度差异很大。

    为什么这个回答方式很重要：把"被削弱"说成"已被证明"，会掩盖那些限定条件。项目里一直强调"原文没有的东西不许补"——同一把尺子也适用于我们自己的判断：判断要带着它的边界一起说。
