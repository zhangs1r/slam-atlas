SO-SLAM：对象级尺度与方向

不建稠密网格了，给每个物体套一个「椭球」就够了 🔮

🎯 主题：单目二次曲面对象 SLAM 的三类语义约束 👥 作者：Liao、Hu、Zhang 等 📅 2022 · SO-SLAM (IEEE RA-L)
椭球表示 对偶二次曲面 三类约束 初始化与朝向 对比与数字 局限

本节目标

读完你应能：① 说清 SO-SLAM 用「对偶二次曲面 Q*」怎么紧凑表示一个物体（9 自由度）；② 讲出它引入的三类语义空间约束——尺度比例、对称纹理、支撑平面——各自在约束什么；③ 说明单帧初始化与朝向优化如何利用这些约束；④ 对照 CubeSLAM 等，理解它在「单目对象级」上的改进与局限。

和前面课程怎么接

前面 0159–0163 的对象表示是「surfel / 体素 / 包围盒（DSG 的物体层）」——都偏稠密或轴对齐。0163 的 DSG 物体层用「位姿 + 包围盒」，本课换成更紧凑的椭球，是对象表示的另一条路线（和综述里的 CubeSLAM / QuadricSLAM 同族）。0166 的 2023 框架会进一步用 cube / quadric / cylinder 混合参数化，本课是这条「紧凑对象模型」线的先声。0147 的检测零件在这里变成 YOLOv3 出框。

1. 物体用「椭球」表示

稠密建图（0159–0162）给每个点都存信息，代价是内存和算力。SO-SLAM 走另一条极简路线：每个物体只用一个椭球套住——中心、朝向、大小都含在里面，几十个物体也只占几十个椭球参数。这比体素省得多，代价是丢了表面细节（你只知道「这里有个大致这么大、这么朝的物体」）。

2. 对偶二次曲面 Q*：9 自由度的紧凑物体

数学上，这个椭球叫对偶二次曲面（dual quadric）Q*。它用 9 个自由度同时编码物体的中心、朝向、占据空间，是一个对称矩阵表示的几何基元。建好之后，它会被放进位姿图当成一个节点，和相机的位姿节点一起做后端优化（用 Huber 核抗离群）。

注意它的「语义来源」很轻：用的是 YOLOv3 目标检测（每 5 帧取一次 bounding box），类别用来查一张尺度比例表（SemTable）——比如「已知这是椅子，椅子大概多高多宽」。它是实例级检测，不做逐像素语义，更不做稠密重建。

3. 三类语义空间约束

单目（只有一个相机、没有深度真值）下要从一个 2D 框恢复出 3D 椭球，是个病态问题——信息不够。SO-SLAM 的巧思是引入三类语义空间约束，把「物体长什么样、怎么摆」的先验补进来：

  • ① 尺度比例约束（Scale Proportional Constraint, SPC）：根据检测类别查 SemTable，知道「这类物体大致的长宽高比例 $r = [a/c,\; b/c]$」，约束椭球三轴不能乱长。
  • ② 对称纹理约束（Symmetrical Texture）：很多物体（杯子、瓶子）绕对称轴转一下看起来一样；用对称投影不变描述符（灰度 / BRIEF / 距离变换）约束物体的朝向。
  • ③ 支撑平面约束（Supporting Plane）：物体通常「放在地上 / 桌上」，用支撑面约束椭球底部的高度与姿态。

这三类约束和检测框的切线约束一起，构成一个可解的优化问题（LM 求解）。

4. 单帧初始化与朝向优化

单帧初始化：用检测框切线约束 $f_{bbox}$（Eq 2–4）+ 支撑平面约束 $f_{sup}$（Eq 5–8）+ 尺度比例约束 $f_{ssc}$（Eq 9–11）联立，LM 求解出初始椭球——只要一帧就能给物体一个合理初值，不必等它动起来。

朝向优化：靠对称纹理。关键工具是改进的三维距离变换（3D-DT）：对称物体在距离变换下有「投影不变」的性质，据此构造对称代价 $f_{sym}$（Eq 21–24），再做一轮 LM 优化，把椭球的朝向掰正。这是 SO-SLAM 相对同类方法（如 CubeSLAM）在「朝向准」上的主要增量。

5. 对比与数字

用 IoU（椭球和真值物体的重合度）衡量。平均 IoU：纯 SVD 基线只有 0.083，加一类约束的 Init1-1 为 0.163，加全语义先验的 InitP 达 0.218。在 ICL room2 上，CubeSLAM 0.33 vs 本文 InitP 0.484（本课更准）；但 Fr3_cabinet 上 CubeSLAM 0.46 vs 本文 0.345（略逊）。真实机器人（Turtlebot3 + Kinect）上，SVD 仅 0.005，本文 0.228——说明语义先验在真机上收益很大。

6. 局限

作者自陈两个主要局限：① 椭球假设对高度非椭圆物体不友好——长条形的扫帚、凹形的椅子，套个椭球会失真；② 支撑平面在实验中由人工标注真值给出，真机上需要额外的平面 SLAM 去提取，否则这条约束无从谈起。

另外它没有给系统级 FPS，单帧初始化与朝向优化属于离线 / 近实时级（LM 迭代）。和前面稠密路线比，它赢在「省、轻、直接给物体语义」，输在「没有几何细节、对形状敏感」。这也是 0166 的 2023 框架要用 cube / quadric / cylinder 混合、并对齐线来补「朝向」的原因。

互动判断

SO-SLAM 的对象表示和 0163 Kimera 的 DSG 物体层（包围盒）相比，主要差别是？

读完你应该能回答

  1. SO-SLAM 用「对偶二次曲面 Q*」怎么表示一个物体？它有几个自由度、各管什么？
  2. 单目下从 2D 框恢复 3D 椭球是病态的，SO-SLAM 靠哪三类语义约束补信息？各约束什么？
  3. 单帧初始化和朝向优化分别用了什么关键工具（提示：3D-DT）？
  4. InitP 的平均 IoU 是多少？和 CubeSLAM 比它赢在哪、输在哪？
  5. SO-SLAM 的椭球表示和 0163 DSG 的物体层（包围盒）各有什么利弊？
  1. 用生活类比解释「为什么单目下从 2D 框恢复 3D 椭球是病态问题，需要语义先验来救」。
    展开查看答案
    想象你隔着玻璃看一个纸箱，只看到一个长方形轮廓——它可能是近处的小盒，也可能是远处的大柜。这就是「深度不确定」的病态：同一个 2D 框对应无数种 3D 可能。SO-SLAM 的语义先验像「你认出那是椅子，而椅子通常高约 1 米、深约 0.6 米」——用 SemTable 的比例把无数可能砍到「就这一种合理大小」，问题才变得可解。尺度比例、对称、支撑面三约束都是这类「用常识收窄可能性」的招。
  2. 尺度比例约束 $r = [a/c,\; b/c]$ 这个表达式在约束什么？如果某类物体「又高又瘦」，$r$ 会怎么取值？
    展开查看答案
    $a,b,c$ 是椭球三个半轴长，$r=[a/c, b/c]$ 是「相对第三轴的比例」，约束的是三轴之间的相对长短，而非绝对大小（绝对大小由框的切线和深度决定）。对「又高又瘦」的物体，比如高对应轴 $a$、宽和深对应 $b,c$，则 $a/c$ 和 $a/b$ 都很大（远大于 1），SemTable 查到这个比例后，椭球就不会被初始化成一个接近球的东西，而是被拉成细高条。这就是尺度比例约束的物理意义。
  3. 为什么「对称纹理约束」能帮着定物体的朝向？举一个对称、一个非对称的物体说明。
    展开查看答案
    对称物体（如圆柱杯、花瓶）绕其对称轴旋转时，投影轮廓 / 纹理变化有「不变性」——SO-SLAM 用 3D-DT 距离变换抓住这种不变性，据此反推对称轴朝向，把椭球转正。非对称物体（如带把手的马克杯、椅子）本身不对称，对称约束用不上或很弱，朝向就只能靠别的线索（如支撑面法向、运动）去定，这也是为什么 SO-SLAM 对椅子这类非对称物体效果有时不如 CubeSLAM。
  4. SO-SLAM 用了 YOLOv3 每 5 帧检测一次。如果某个物体连续 10 帧没被检测到（被遮挡），它的椭球会怎样？这暴露了什么短板？
    展开查看答案
    SO-SLAM 靠检测框提供约束，一旦 10 帧没检测，那段时间就没有新的框切线 / 尺度约束喂进来，椭球只能靠后端位姿图「惯性」维持，若期间相机或物体有运动，椭球可能漂掉或形变失准。它不像 0161 EM-Fusion 那样有「存在概率 + 软关联」去平滑处理短暂消失。这暴露了「检测驱动」对象 SLAM 的通病：检测一断，对象就盲——也正是 0166 的框架要用统计检验做更鲁棒关联的理由之一。
