1. 先说一个语料勘误（必须如实写）

之所以要专门点出来，是因为它直接关系到「逐篇对比」的严谨性：我们不能假装有两篇不同的论文，然后给它们分别打分。遇到这种重复录入，诚实标注比假装没看见更重要。

2. 三条规模化路线：怎么把隐式 SLAM 做大

前面两课讲的是「回环怎么改隐式地图」。但回环不是把隐式 SLAM 做大的唯一办法——而且本组的这三篇都没有回环。它们各自回答了一个更基础的问题：隐式 SLAM 怎么才能跑得大、跑得久？

路线一：借别人的位姿

NeRF-SLAM：自己不做位姿，直接拿 DROID-SLAM 的位姿和带不确定度的深度，喂给 Instant-NGP 建图。把「难的事」交给成熟前端。

路线二：换到激光上做增量

NeRF-LOAM：用八叉树体素 embedding 当激光隐式地图，逐帧增量更新，不预训练、不带回环，专攻室外大尺度。

路线三：渐进 + 局部到全局 BA

PLGSLAM：动态切分局部 tri-plane 场景，先粗后细；用「局部 BA + 全局 BA」两级消除累积误差。

3. NeRF-SLAM：借别人的位姿（组合式，无回环）

NeRF-SLAM（2023）是这条路线的代表。它是一篇组合式系统 / 管线论文，不是端到端。它把「前沿的稠密单目 SLAM」和「实时的神经辐射场」拼起来：

  • 位姿是谁给的：DROID-SLAM（III-A 节，复用其权重）。它还用 Rosinol 的方法实时算出深度/位姿的边际协方差 $\Sigma_d, \Sigma_T$，连「不确定性」也一并借来了。
  • 建图部分用了什么：Instant-NGP 的多分辨率哈希体积辐射场（纯哈希网格，不是点云），把 DROID 给的位姿和带不确定度的深度当作监督，训练 NeRF。深度不确定度大的地方权重调低，避免「鬼影 / floaters」。
  • 有没有回环：没有。正文从头到尾无 loop closure；GO-SLAM 正文也点名它「absence of online loop closing and full BA」。它的全局一致靠 DROID-SLAM 的稠密 BA在线维持，但不是回环修正。

4. NeRF-LOAM：激光侧的增量式（无回环）

NeRF-LOAM（2023）把隐式表示搬到了激光上做大尺度增量建图。它是 SJTU + 国防科大团队的工作（注意：与 PIN-SLAM 不是同一团队，且 PIN-SLAM 在引言里把它当「为何需要弹性点而非网格」的反面教材）。

  • 地图表示：八叉树稀疏体素 embedding（每顶点 N_e 维）+ 一个共享 MLP 解码器，三线性插值得到 SDF。不是点云、不是规则全网格，是按需开桶的八叉树。
  • 怎么处理大场景（分块/子图）：八叉树天然是「按需开桶」——激光扫到新区域才生成新体素 embedding，不预分配整张全网格，所以能跑大场景。还做了地面分离 SDF 抑制 Z 轴漂移。
  • 增量式的含义：逐帧用射线在 SE(3) 切空间梯度下降优化 6 自由度位姿，前 K 帧后冻结网络、几何存进体素；靠 key-scan buffer 联合精修来缓解「前 K 帧灾难性遗忘」。
  • 有没有回环：没有。所谓「loop」在正文里只是「time-consuming loop queries」（代码循环）和作者名 Charles Loop，不是回环检测。key-scan 精修是「防遗忘」，不是回环。

5. PLGSLAM：渐进式 + 局部到全局 BA（非 ORB-SLAM3）

PLGSLAM（2024）走第三条路：渐进切分局部场景 + 局部到全局 BA。它要解决的问题是——单一固定容量的全局场，装不下大尺度长序列。

★ 诚实标注：位姿不是 ORB-SLAM3 给的

有一个常见误传：PLGSLAM 用 ORB-SLAM3 提供位姿。但正文不支持。它只在引言把 ORB-SLAM 当传统方法举例、在表格当 baseline；它自称「integrate the traditional SLAM system with an end-to-end pose estimation network」，跟踪线程用神经 warping 损失 + SIFT 重投影误差做局部到全局 BA，没有说用 ORB-SLAM3 出位姿。本课的写法以正文为准。

  • 「Progressive」指什么：相机轨迹离开当前局部场边界时，动态新建局部场并冻结旧的；若回到旧边界内则激活旧场继续优化。即「先粗（局部）后细（全局）」的渐进分配，内存由立方降到平方 $O(L^2)$。
  • 局部到全局 BA 两级：① 局部 BA——只选与当前帧视觉重叠的局部关键帧优化几何；② 全局 BA——维护全局关键帧数据库，用神经 warping 损失（把关键帧 I 用相对位姿 warp 到 I' 比颜色/深度）+ SIFT 重投影误差跨全部历史观测量消除累积误差。这是回环/全局一致的替代机制（非严格回环检测）。
  • 位姿从哪来：自己估 + 融合传统 SLAM（神经 warping + SIFT 重投影做 BA），不是 ORB-SLAM3。

7. 收束：没有回环时怎么办

三篇读下来，你会发现它们和前两课的 Loopy / GO / PIN 正好互补：那三篇靠回环把地图拉正，这三篇靠「组合 / 增量 / 渐进」把地图做大，且都没有回环。

本组判断（非原文自评）

三条规模化路线，本质上是「在还没有回环的情况下，先让隐式 SLAM 跑得更大更久」的三种工程智慧：

① 借位姿（NeRF-SLAM）最省力，但放弃了回环这层保险，靠前端 BA 兜底；② 激光增量（NeRF-LOAM）把隐式搬到激光上、按需开桶，但同样靠 key-scan 精修而非回环；③ 渐进 + 局部到全局 BA（PLGSLAM）用分场和两级 BA 直接对抗累积误差，最接近「回环的效果」却仍非严格回环。

它们共同说明：回环不是规模化的唯一解，但「没有回环」总要付出别的代价——要么依赖强力前端（DROID），要么依赖增量精修（key-scan），要么依赖两级 BA（PLGSLAM）。

课后练习

  1. 为什么本课的 NeRF-SLAM 必须按「一篇」处理，而不是路线图里的两行？
    展开查看答案

    因为语料库里「NeRF-SLAM」与「实时稠密单目 NeRF-SLAM」两行是同一篇论文的重复录入：正文词数完全相同，两个图片目录内容也相同。所以合并成一篇处理，避免虚构出两篇不同的工作。这是诚实标注的基本要求。

  2. NeRF-SLAM 的位姿是谁给的？它建图部分用了什么表示？有没有回环？
    展开查看答案

    位姿由 DROID-SLAM 提供（复用其预训练权重），并借来带协方差的深度与位姿不确定度。建图用 Instant-NGP 的多分辨率哈希体积辐射场（纯哈希网格）。没有回环——全局一致靠 DROID 的稠密 BA 在线维持，不是回环修正。

  3. NeRF-LOAM 怎么在激光侧处理大场景？它和 PIN-SLAM 是同一团队吗？
    展开查看答案

    它用八叉树稀疏体素 embedding：激光扫到新区域才生成新体素 embedding，不预分配整张网格，因而能跑大场景；并做地面分离 SDF 抑制 Z 漂移。它是增量式、无回环，靠 key-scan 精修缓解遗忘。

    它和 PIN-SLAM 不是同一团队（NeRF-LOAM 是 SJTU + 国防科大；PIN-SLAM 是 Bonn/Stachniss 组），且 NeRF-LOAM 缺回环。PIN-SLAM 在引言里把它当「为何需要弹性点而非网格」的反面教材。

  4. PLGSLAM 的「Progressive（渐进）」指什么？它的局部到全局 BA 是哪两级？
    展开查看答案

    「渐进」指：相机离开当前局部场边界时动态新建局部场并冻结旧的；回到旧边界内则激活旧场。即先粗（局部）后细（全局）的渐进分配，内存从立方降到平方。

    两级 BA：① 局部 BA——只优化与当前帧视觉重叠的局部关键帧几何；② 全局 BA——用神经 warping 损失 + SIFT 重投影误差跨全部历史观测量消除累积误差。这是回环的替代机制，非严格回环检测。

  5. 关于 PLGSLAM 的位姿来源，常见误传是什么？正文实际怎么说？
    展开查看答案

    误传：PLGSLAM 用 ORB-SLAM3 提供位姿。但正文不支持——它只在引言/表格把 ORB-SLAM 当 baseline，自称「integrate the traditional SLAM system with an end-to-end pose estimation network」，跟踪线程用神经 warping 损失 + SIFT 重投影误差做局部到全局 BA，没有说用 ORB-SLAM3 出位姿。写课时以正文为准。
