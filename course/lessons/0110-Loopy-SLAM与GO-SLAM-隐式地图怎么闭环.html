1. 先立问题意识：地图是权重，回环来了怎么办

我们从一张非常朴素的对比开始。

在传统的稀疏 SLAM 里（比如 ORB-SLAM、LOAM），地图是一堆孤立的点或特征。当机器人走回原点、检测到回环，发现「咦，我之前记的位置偏了」，它只需要把那些点的位置搬一搬，或者更常见的是——只改位姿，地图点跟着位姿一起被重新摆放就行。地图本身不需要「重新学习」。

但到了隐式表示（NeRF、神经点云、哈希网格），情况彻底变了。这里地图不是「一堆点」，而是一个函数的权重。你想知道「这里有没有墙」，不是去翻一个点，而是去问一个网络：把三维坐标喂进去，它吐出颜色和密度。

本组的灵魂问题

如果地图是网络权重（或特征网格），回环来了、位姿要改，这些权重怎么改？

稀疏 SLAM 改位姿就够；隐式表示必须改地图本身——但「改一个神经网络」听起来很吓人：难道每次回环都要把整个网络重训一遍吗？如果那样，在线实时就别想了。

下面两篇就是针对这个问题的两种回答，而真正读进去你会发现：它们其实都没去动那个大 MLP。

2. Loopy-SLAM：点基 submap，能整体搬就别重训

Loopy-SLAM（2024）是 Point-SLAM（上一课 0109）的直系后裔。Point-SLAM 把神经特征挂在一朵朵点云上，渲染时去问这些点；但它没有回环。Loopy-SLAM 干的事，就是给这套点基表示加上在线回环，并且证明：因为点能搬，所以回环修正不需要重训整个网络。

submap 怎么划分和合并

它把连续的轨迹切成一段一段的点云 submap（子地图）。触发规则很朴素：当「当前活跃 submap」相对「全局关键帧」的位移或转角超过阈值（比如 Replica 上平移 0.3 米、转角 20°），就新建一个 submap。每个 submap 的第一帧是一个全局关键帧，定义了一个该 submap 在世界系下的位姿。

这些 submap 里的点，带着几何特征（32 维）和颜色特征（32 维）。关键在于：点和这两份特征是局部锚定的——点被刚体搬动时，特征跟着点走，渲染结果不变。

位姿图：节点是什么

回环用的也是经典套路——位姿图。它的节点是每个全局关键帧的世界系位姿；边有两种：

  • 里程计边：相邻 submap 之间的连续帧约束；
  • 回环边：用 BoW（词袋）做全局重识别，发现「现在这个 submap 和很久以前那个 submap 是同一个地方」时连上。

检测到候选回环后，跑一遍鲁棒位姿图优化（PGO）。优化里有一个 line process 权重，专门用来否决假的回环边——这正是第一季 0014 课「假阳性铁律」所说「一个错回环代价极大」的应对安全阀。

优化出刚性修正后，作用到三处：关键帧的世界位姿、该 submap 所属帧的位姿、以及这个 submap 本身的点。改的只是点的位置（刚性搬动），不是特征重训。

3. GO-SLAM：即时重建与全局优化

GO-SLAM（2023）走的是另一条路。它站在 DROID-SLAM 的肩膀上：前端扩展 DROID-SLAM 来做跟踪和回环，后端用一个独立线程做在线 full BA（全量光束法平差），再把结果喂给一个 Instant-NGP 式的哈希编码 + 浅 MLP 做即时重建。

「Instant Reconstruction」指什么

这个词说的是位姿一改、地图立刻跟着改。它有一个「即时建图」线程，以较高频率用最新的优化位姿/深度去更新隐式表面。它聪明地挑关键帧（最新的两帧、未优化的帧、按位姿差取 Top-10、再加分层采样 10 个），避免每次都全量重算。所以「改完位姿立刻就能看到新地图」。

全局优化怎么做

它有三条并行线程：① 前端跟踪 + 回环检测；② 后端 full BA（同时优化所有历史关键帧的位姿与逐像素逆深度）；③ 即时建图。回环检测比 DROID 更严：要连续 3 个回环候选且均值流小于阈值才接受——又是一个防错回环的安全阀。

与 NeRF-SLAM 的关系

记住一条线：NeRF-SLAM = DROID-SLAM 出位姿 + Instant-NGP 建图（组合式，但没有回环）；GO-SLAM = 在它基础上加了在线回环 + 全 BA。GO-SLAM 自己的正文也点名批评了 NeRF-SLAM 的「absence of online loop closing and full BA」。所以 GO-SLAM 是「组合式无回环 → 加回环」的演化样板。

4. 核心结论：这六篇回环都不直接改 MLP 权重

下面是本组最锋利、也最容易被误解的一句话——它来自精读材料对六篇正文的逐条核对：

★ 必须写清的核心结论

本组六篇（Loopy-SLAM、PIN-SLAM、NeRF-SLAM、NeRF-LOAM、GO-SLAM、PLGSLAM）的地图没有一篇在回环时去改那个 MLP 解码器的权重。

它们的地图都是混合表示：一个显式锚点（神经点 / 特征网格 / tri-plane / 体素 embedding）+ 一个很小的共享 MLP 解码器。回环发生时，改的是显式锚点的位置或特征——Loopy-SLAM、PIN-SLAM 平移/旋转神经点；GO-SLAM、PLGSLAM 改哈希 / tri-plane 特征对应的几何——而那个小 MLP 几乎被冻结。

换句话说：改地图 ≠ 改权重。改的是「权重之上的那层锚点」。

这个结论为什么重要？因为「隐式地图回环要重训网络」是一个流传很广的误解。实际上，这些方法的聪明之处，正是把「难改的权重」和「好搬的锚点」分开：权重一次训好就冻住，后面所有修正都落在轻量的锚点上。代价因此远小于「重训整张图」。

这里还要诚实标注两个例外（同样来自精读材料的纠正）：NeRF-SLAM 与 NeRF-LOAM 其实根本没有回环（已 grep 验证，正文从头到尾没有 loop closure）。所以对本组「回环怎么改地图」这个问题，真正成立的只有 Loopy-SLAM、PIN-SLAM（直接搬点）、GO-SLAM、PLGSLAM（改特征再重渲染）；而 NeRF-SLAM / NeRF-LOAM 是「没有回环、靠别的方式兜底」的代表，下一课再细讲。

把两篇摆在一起，差异一目了然：

6. 把问题收束：回环改的是「地图的哪一层」

回到开头的问题意识。我们问的是：当地图是网络权重，回环来了权重怎么改？两篇读下来，答案出乎意料地统一：

本组给初读者的判断（非原文自评）

隐式表示的回环，不是「改权重」，而是「改权重之上的显式锚点」。稀疏 SLAM 改个位姿就够；隐式表示必须连锚点一起改，才能让整张地图重新摆正——但因为它搬的是轻量的点/特征，而不是重训那个网络，所以代价可控、能在线做。

这是本季反复出现的一条暗线：隐式地图要「会动」，靠的是把可变的部分和不可变的部分解耦。下一课 PIN-SLAM 会把这件事推到极致——它用「弹性的神经点云」做到激光侧首个完整的隐式 SLAM。

课后练习

  1. 为什么说「稀疏 SLAM 改位姿就够、隐式表示必须改地图本身」？请用本组的两层结构解释。
    展开查看答案

    稀疏 SLAM 的地图是一堆孤立点，点的位置由位姿决定；改了位姿，点跟着被重新摆放，地图自然就正了，地图本身不需要变。

    隐式表示的地图是「一个函数 + 显式锚点」。函数值由锚点位置/特征和那个小 MLP 共同决定。如果只改位姿而不动锚点，网络对同一坐标的预测还是旧的——所以必须连锚点一起改（平移/旋转神经点，或改哈希特征），地图才会跟着正过来。区别在于：它改的是锚点，不是 MLP 权重。

  2. Loopy-SLAM 的 submap 是怎么触发「新建」的？回环检出后，它改的是哪一样东西？
    展开查看答案

    触发：当「当前活跃 submap」相对「全局关键帧」的位移或转角超过阈值（Replica 上约平移 0.3 m、转角 20°）时，就新建一个 submap。

    回环检出后跑鲁棒 PGO，优化出的刚性修正作用到三处：关键帧世界位姿、该 submap 所属帧位姿、以及这个 submap 本身的点。改的是点的位置（刚性搬动），不是特征重训，也不是整个 MLP。

  3. GO-SLAM 的「Instant Reconstruction（即时重建）」是什么意思？它和 NeRF-SLAM 是什么关系？
    展开查看答案

    「即时重建」指：位姿一被优化，即时建图线程就用最新位姿/深度去更新隐式表面，改完位姿立刻能看新地图。它靠「只挑关键帧、不全量重算」来维持实时。

    关系：NeRF-SLAM = DROID-SLAM 出位姿 + Instant-NGP 建图（组合式，无回环）；GO-SLAM = 在它之上加在线回环 + 全 BA。GO-SLAM 正文也点名批评 NeRF-SLAM 缺在线回环与全 BA。所以 GO-SLAM 是「组合式无回环 → 加回环」的演化样板。

  4. 本组六篇里，有哪两篇其实根本没有回环？它们靠什么方式「兜底」全局一致？
    展开查看答案

    没有回环的是 NeRF-SLAM 与 NeRF-LOAM（已 grep 验证，正文无 loop closure）。

    兜底方式：NeRF-SLAM 靠 DROID-SLAM 的稠密 BA 在线维持一致性（不是回环修正）；NeRF-LOAM 靠 key-scan buffer 联合精修缓解「前 K 帧遗忘」，也不是回环。它们被用来对照「没有回环时如何靠别的方式尽量保持不崩」。下一课会专门讲这两篇。

  5. 为什么本组强调「回环不直接改 MLP 权重」很重要？如果真的去重训整个网络会怎样？
    展开查看答案

    重要是因为它推翻了「隐式地图回环 = 重训网络」的误解。实际上这些方法把「难改的共享权重」和「好搬的显式锚点」解耦：权重一次训好就冻住。

    如果每次回环都重训整张网络：① 计算量极大，无法在线/实时；② 重训容易破坏已经建好的区域（灾难性遗忘）；③ 网格法（规则特征网格）正是因为这个才难做增量回环——PIN-SLAM 在引言里就点名这是它要解决的问题。所以点基/哈希的方法是「搬点/改特征」，代价远小于重训。
