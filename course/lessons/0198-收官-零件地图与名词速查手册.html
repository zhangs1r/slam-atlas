0. 开场：收官课要结哪四笔账

这一季很特殊。它讲的十一篇论文，没有一篇是 SLAM 论文。它们是计算机视觉与深度学习里的通用零件——骨干网络、检测头、分割头、传感器硬件。它们不产生任何 SLAM 方法，但前八季的论文里到处在引用它们。

所以本季的任务从一开始就不是「讲一个新方法」，而是还一笔旧账：把你在前八季读论文时跳过去的那些词，一个个补上。既然是这样一笔账，收官课要结的也就不是「学到了什么新知识」，而是四件更实际的事：

  1. 把词收成手册——全季出现过的术语，一个词一句大白话，加一句「在哪节课讲过」。
  2. 把零件收成地图——十一个零件分成四个家族，每个家族回答「解决什么 / 代表作品 / 关键数字 / 在 SLAM 里干什么」。
  3. 把方法收成判据——正面回答导览课立的那个问题：看到陌生名词，怎么在三十秒内决定要不要读懂它。
  4. 把话说明白——诚实分区：哪些结论有原文证据、哪些只是我们的判断。这一条是本季最重要的交付。

先说一件容易被忽略的事：这一季里藏着一条暗线，从第一节课一直贯到最后一节。它是——这些零件都很准，但都不够快；而 SLAM 是实时系统。

第八季 0155、0156 那块动态环境处理，用的是 Mask R-CNN 分割「潜在动态」物体，而它的真实耗时是 195 毫秒一张图——大约 5 帧每秒。SLAM 要的是 30 帧每秒。这条张力，才是本季十一篇论文真正的连接点。

把这张表横着读一遍，会发现一个规律：四个家族里，「骨架」和「外围」提供的是能力，「检测头」和「分割头」提供的是语义。而 SLAM 真正缺的是语义——位姿估计那一套几何是成熟的，缺的是「这一片点属于一辆正在动的车」这种知识。所以本季这些零件在 SLAM 里最常见的用法就是：用语义去决定「哪些观测不该参与几何估计」。

而这恰好也解释了为什么这些零件的缺陷会变成 SLAM 的设计约束——因为语义这一路本来就不够准、也不够快，所以几何那一层不能把决定权全交出去。这就是第八季那些「语义 + 几何双保险」设计的由来。

4. 三十秒判断：看到一个陌生名词，该不该读懂它

这是导览课 0186 立下的问题，现在正面回答。

先说一个反直觉的前提：你不需要读懂每一个词。一篇论文里出现的名词，按「对这篇论文结论的贡献」来说，价值差别极大。全都查一遍，等于把读论文变成查词典；全都跳过，又会漏掉承重墙。所以真正要练的是一件事——快速判断它是不是承重墙。

判据背后的两个具体例子（都出自本季）

例一：Mask R-CNN 出现在第八季的一篇 SLAM 论文里

它出现在方法主体里（「我们用 Mask R-CNN 分割潜在动态物体，把这些区域的特征点剔掉」）——判据一过关。它在多篇动态环境论文里出现——判据二过关。把它拿掉，「分割动态物体再剔除」这件事就不成立了——判据三过关。所以它是承重墙，必须读懂。这就是 0192 那一课存在的理由。

例二：某个只在一篇论文的实验设置里出现的训练超参数

它出现在实验设置里（「我们按某某做法用了某某学习率调度」）——判据一直接判「先跳过」；而且你只见过这一次——判据二也支持跳过。即使第三条判据（拿掉就复现不了）有点可疑，但它不是「方法承重墙」，只是「复现细节」。这类词的正确答案是：记下名字，需要复现时再回来查。

顺带说一个本季最实用的副产品：这三条判据也可以用来读本季自己。如果你只想知道「论文里那个词是什么意思」，那么每一节课都可以只读「它在前八季的哪里出现过」和「它不完美在哪」两节；如果你想真的会用它，才需要读公式与形状账。按需要分配注意力这件事，本身就是这一课要教的能力。

5. 诚实分区：哪些有原文证据，哪些只是我们的判断

本季最重要的一条纪律在这里。一门课的可信度，不取决于它讲了多少，而取决于它有没有把「我知道的」和「我猜的」分开。下面把全季的说法分成三区。

A 区：有原文证据（可以直接引用）

  • 所有的公式与数字——例如 $R=\frac{1}{2}c\tau$、$\Omega(\mathrm{W\text{-}MSA})=4hwC^2+2M^2hwC$、$\mathrm{SR}(\mathbf{x})$、3D 框的 8 个参数、$AP$ 的积分式、PointPillars 16 毫秒、Swin-T 29M、PVT-RetinaNet 40.4 AP 等。它们都来自各篇论文正文，且凡是可能被 OCR 弄错的表格，我们都在课里标了警告。
  • 论文作者的自我评价——例如 ResNet 作者承认「退化的原因将在未来研究」、Swin 作者承认「内核没优化，彻底的算子优化超出本文范围」、PVT v1 作者承认「金字塔对分类几乎没有提升」「更适合中等分辨率输入」。
  • 不同论文之间的引用关系——例如 Hybrid CNN-Transformer 那篇确实同时用了 VGG-16 与 Swin-B（第七季 0139）、DynaSLAM 确实分割了 19 类潜在动态物体（第八季 0153）。

★ B 区：三处必须重申的红线（本季查出来的清单与正文不符）

红线一：VGG 是「转引」，不是一手来源

课程清单把 2015_Going_deeper_with_convolutions 标成「VGG（2015）」，但它的正文其实是 GoogLeNet / Inception（一级标题是 Going Deeper with Convolutions，摘要是「一个代号 Inception 的深度卷积网络……提交版本叫 GoogLeNet，22 层」）。而且本语料库里根本没有 VGG 的一手论文。所以 0187 那一课讲的每一句关于 VGG 的话，都必须标「转引」——绝不能写「VGG 论文里说……」这种句式，因为那篇论文不在我们读的语料库里。

但读者仍然会天天撞见它：在 SLAM 语料里，VGG 的被引量远高于 GoogLeNet（96 篇论文提到 VGG，其中 VGG-16 出现在 25 篇里）。所以那一课的做法是「主线讲 GoogLeNet（有一手正文，数字可引用）＋ 开一段前置补丁讲 VGG（全部数字标转引）」。

红线二：PVTv2 不在语料库里

课程清单把这一篇标成 PVTv2，但正文其实是 PVT v1（标题漏了结尾的 without Convolutions）。PVTv2 是本文同作者的后续工作，它的论文不在我们的语料库里。所以 0194 那一课里，PVTv2 的三个核心概念——线性 SRA、卷积前馈、重叠 patch embedding——一个字都没有出现，它们属于另一篇我们没读过的论文。

而且那一课还如实写出了一个「标题张力」：PVT v1 以「免卷积」为招牌，但它的续作 PVTv2 又把卷积要素加回来了——这说明「免卷积」不是终局。这不是报错，而是必须写出来的发展脉络。

红线三：硬件篇没有运动畸变，也没有 TDC

0195 那一课的论文正文里，检索 distortion 命中 0 次、TDC 与 time-to-digital 命中 0 次。所以那一课只讲了两环：「测距＝测时间（$R=\frac{1}{2}c\tau$）」与「所以每个点自带独立时刻戳」。

运动畸变属于第四季（0074 的 LOAM 要先估速度再逐点补偿；0086 干脆不攒帧）。那一课在桥接时明确标注了「这一步原文没讲，是第四季 LOAM 课的开场」，并且标为「我们的分析」。TDC 则要去 2022 年那篇固态雷达与纳米光子学综述里找，不在这一篇。

同一篇里还有三条「原文没给数值、因此不许编」的红线：最大测距范围、扫描频率、功耗都没有具体数字（只有一张定性的阴影图与 power-hungry 这个形容词）；MPE 数值与激光安全等级也没有。

C 区：明确标为「我们的分析」（原文没有说）

  • 「三维检测与 SLAM 是什么关系」——那篇综述全文 0 次出现 SLAM。所以「两者不是上下游，而是并行消费同一路数据、共享同一层表示地基」这个说法，是我们的分析，课里已明确标注。引用时不能说成「该综述指出……」。
  • 「硬件篇的第 ③–⑥ 环」——把「每个点自带时刻戳」一路推到「直墙被扫成斜线」的那条链，前三环有原文支撑，后面几环是把硬件事实接到第四季时的分析。
  • 「PVT → Swin → 地点识别 → 回环检测」这条推断链——0194 里已注明：PVT v1 在本语料库里找不到任何一篇 SLAM 论文实体引用它（检索命中的全是假阳性），所以这条链是推断，不是引用。
  • 零件家族之间的「呼应」与「规律」——例如「骨架和外围给能力、检测头和分割头给语义」「这些缺陷逼出了语义 + 几何双保险」。这些是本季的归纳，不是任何一篇论文的结论。

为什么要在收官课上专门写这一节？因为它和第九季 0180 的态度是同一个：那里是「看到轨迹误差先问真值多准」，这里是「看到结论先问它从哪来」。一门课如果分不清这两件事，它教得越多，你可能被误导得越深。

读完你应该能回答

1. 这一季到底解决了什么问题？

不是教新方法，而是还一笔旧账：把前八季论文里到处出现、却从没人解释过的通用零件（骨干、检测头、分割头、传感器硬件、三维检测）一个个补上。十一篇论文没有一篇是 SLAM 论文。

2. 十一个零件分几个家族？各给什么？

四个家族：骨架（GoogLeNet / ResNet / ResNeXt / Swin / PVT）、检测头（YOLO / Focal Loss）、分割头（FCN / Mask R-CNN）、两端的外围（LiDAR 硬件 / 三维检测综述）。前两者之外的规律是：骨架与外围给能力，两个头给语义。

3. 全季那条暗线是什么？

这些零件都很准，但都不够快，而 SLAM 是实时系统。语义前端 Mask R-CNN 约 195 毫秒一张（≈5 fps）；三维检测这一侧同样明写着快与准的对立（PointPillars 16 毫秒但对精度一般，点基最慢 640 毫秒）。所以 SLAM 必须加几何这一层保险。

4. 看到一个陌生名词，怎么在三十秒内判断？

三条判据：① 它出现在哪一部分（方法主体要读，实验设置与相关工作可以先跳过）；② 它在你读过的东西里反复出现吗（三次以上值得补）；③ 把它拿掉，这个方法还成立吗（不成立就是承重墙）。三条都指向「必须读」才真的动手。

5. 哪三处红线必须记住？

① VGG 是转引（语料库里没有它的一手论文，绝不写「VGG 论文里说」）；② PVTv2 不在语料库里（0194 讲的是 PVT v1，v2 的概念一律不得出现）；③ 硬件篇没有运动畸变与 TDC（distortion 与 TDC 检索均为 0 命中，它们分别属于第四季和另一篇综述）。

6. 为什么要专门留一节讲「证据 vs 判断」？

因为一门课的可信度，取决于它有没有把「我知道的」和「我猜的」分开。这与第九季 0180 的「先问真值多准」是同一种态度——看到结论，先问它从哪来。

课后练习

  1. 你在读第四季的一篇激光 SLAM 论文，正文里出现「我们按 Hdl-64E 的 10 Hz 扫描配置做去畸变」。请用三条判据判断：你需要专门去读懂「去畸变」这件事吗？
    展开查看答案
    判据一（位置）：「去畸变」出现在方法主体里，而且是被当作处理步骤写的——过关。
    判据二（频率）：「运动畸变 / 去畸变」在激光 SLAM 语料里是出现频率最高的硬件相关词之一，你在第四季会反复撞到——过关。
    判据三（后果）：把去畸变拿掉，那么「一帧点云被当成同一时刻的测量」这个假设就崩了，配准精度会直接受影响——它显然是承重墙——过关。
    结论：必须读懂。去哪读？0195 给你物理根源（测距＝测时间 → 每个点自带时刻戳），0074 给你对策（先估速度、再逐点补偿），0086 给你另一条对策（不攒帧）。
  2. 有人告诉你：「某篇论文用 PVTv2 当主干，涨了很多点。」你该怎么回应？
    展开查看答案
    第一件事是确认你手上的那篇论文到底是 v1 还是 v2。本季已经踩过一次这个坑：课程清单标「PVTv2」，正文其实是 PVT v1（标题漏了 without Convolutions），而 PVTv2 根本不在我们的语料库里。
    第二件事是把 v1 和 v2 的概念分开：PVT v1 的核心是金字塔 + SRA（把 K/V 的空间长度压到 $1/R_i^2$）；而 PVTv2 的三个卖点（线性 SRA、卷积前馈、重叠 patch embedding）属于另一篇论文。把两者混着说，就等于在讲一篇你没读过的论文。
    第三件事：顺势记住那条「标题张力」——v1 以「免卷积」为招牌，续作 v2 又把卷积加回来了，说明「免卷积」不是终局。看到「without X」这类标题，先去看它的续作有没有把 X 加回来。
  3. 为什么本课说「三维检测与 SLAM 不是上下游」？这个说法凭什么必须标成「我们的分析」？
    展开查看答案
    为什么不是上下游：两者吃的是同一路传感器数据，但回答的问题不同——SLAM 输出「我在哪」（自车位姿轨迹 + 地图），检测输出「周围有什么、在哪」（一组 3D 框）。它们不是「一个的产物喂给另一个」，而是并行消费同一份观测。所谓「共享地基」指的是更下一层的东西：稀疏、不规则的点云怎么组织成高效结构（体素、点基、BEV 三种容器在两边都出现过）。
    为什么必须标成「我们的分析」：因为那篇综述全文 0 次出现 SLAM。它通篇没有讨论过与 SLAM 的任何关系。把我们的推断安到它头上，就是伪造引用。正确的写法是「就我们所知，两者共享同一层表示地基」这种带出处的表述，而不是「该综述指出三维检测是 SLAM 的上游」。
  4. 本季哪一处「清单与正文不符」你觉得最有教学价值？为什么？
    展开查看答案
    参考答案是第一处（VGG / GoogLeNet），理由是它最直接地印证了本季的主题：连课程清单自己都会把两个经典网络记混。
    具体是这样：清单标「VGG（2015）」，但那篇论文的正文其实是 GoogLeNet / Inception；而更麻烦的是，语料库里根本没有 VGG 的一手论文——你只能从别的论文里转引它的数字。
    这件事的教益有三层：① 不能凭名字猜内容（看到「VGG」就以为是 VGG 论文）；② 要分清「一手」和「转引」（转引的数字必须标出处，不能写成「VGG 论文里说」）；③ 被引量高不等于语料库里有——VGG 在语料库被 96 篇论文提到，但它自己那篇不在库里。
    其余两处（PVTv2 / 综述的 Survey 与 0 次 SLAM）也都很有价值，答这两处同样算对。
  5. 请用一句话总结：这一季学完之后，你读 SLAM 论文的方式发生了什么变化？
    展开查看答案
    参考答案：以前撞到陌生名词只能跳过，现在能判断它值不值得停下来——并且知道去哪里补。
    展开一点说：① 你有了一本手册，撞到词能反查它在哪讲过；② 你有了一张零件地图，知道这个词属于哪个家族、在 SLAM 里干什么；③ 你有三条判据，三十秒内决定要不要深挖；④ 最重要的一点——你知道了这些零件都是有缺陷的，所以论文里那些「语义 + 几何双保险」之类的设计不是繁琐，而是被逼出来的。
    这正是导览课 0186 许诺要还的那笔账。
