1. 先问一个生活问题：一张视频怎么「量」出深度

想象你举着手机拍一段走路的视频。人类一眼就知道「前面那张桌子离我一米半」，但计算机拿到的是一串平面像素——它怎么知道桌子离多远？这就引出了 SLAM / 三维视觉里一个老问题：Structure from Motion（SfM，运动恢复结构）。名字很学术，意思其实朴素：从「相机运动时的多张照片」里，同时把「相机在哪」和「东西离多远」一起算出来。

传统做法是一串手工拼起来的几何步骤；而 2020 年的 DeepV2D 想换一种思路——把这些几何步骤直接塞进一个神经网络里，让整条链路可以端到端训练。这一节我们就拆开看它到底「可微」了什么，以及为什么这件事值得专门写一篇论文。

先记住一句话

DeepV2D 不是「又一个纯黑箱 CNN 深度网络」，而是「把经典几何算法做成了可微积木，再拼成一个可训练网络」。它既保留了几何归纳偏置，又能从数据里学习。这正是它泛化好的根源。

2. 回顾：传统 SfM 是怎么「分步走」的

在讲「可微」之前，得先知道传统 SfM 是怎么干的。它通常是一串离散的、各管各的步骤：

  1. 提特征：在每张图上找出角点、斑点这类可跟踪的点。
  2. 做匹配：判断「左图的第 5 个点和右图的第几号点是同一个世界点」——常用「最近邻」挑最像的那一个。
  3. 估位姿：用对极几何 / PnP 等算相机在哪、朝哪；经常要 RANSAC 反复随机抽样、挑出「内点」丢掉「外点」。
  4. 三角化：用两条视线反推三维点的位置，里面常涉及 SVD 矩阵分解。
  5. BA（Bundle Adjustment，光束法平差）：把「重投影误差」整体最小化，微调所有相机位姿和三维点。

问题来了：这一串步骤里，至少有三处是「离散决策」或「调用现成求解器」——RANSAC 选内点是「挑 / 不挑」的硬决策；最近邻匹配是「取 argmin」的不可微操作；BA / SVD 是直接调一个迭代求解器拿结果。这些步骤对「导数」是封闭的：你算出了结果，却没法把最终误差的梯度顺着它们一路反传回最前面的参数。换句话说，传统流程里「学习」只能发生在某个子模块里，整条链不能一起被数据调优。

3. ★ "Differentiable Structure from Motion" 到底指什么

论文标题里的 Differentiable Structure from Motion 听起来玄乎，但原文的意思非常具体，而且必须按原文如实写，不能猜。它指的是：把 SfM 里两个核心子问题——运动估计（Motion）和深度估计（Depth）——各自做成一个可微模块，再拼进一个端到端可训练的网络。具体哪两件事被做成了可微？

① Motion Module = 可微的 BA

位姿更新被写成一个「最小二乘优化」，并用单次可微 Gauss-Newton（GN）步求位姿增量。注意原文是「single differentiable Gauss-Newton optimization step」——是一次 GN 步的近似，不是反复迭代到收敛的完整 BA。

② Depth Module = 可微立体匹配

多帧之间的深度估计被写成「可微的立体匹配」：把 2D 特征反投影成 cost volume（代价体），用 3D hourglass 网络做特征匹配，最后用可微的 arg-max 取出深度。

★ 如实澄清：可微的是「BA」与「立体匹配」，不是「三角化」

精读材料明确点出：DeepV2D 把 SfM 的可微 BA（单次 GN 步）+ 可微立体匹配这两块做成了可微积木。它没有单独宣称「把三角化做成了可微」——深度来自可微立体匹配，位姿来自可微 BA。写课时不要张冠李戴成「可微三角化」。

所以「Differentiable SfM」的准确含义是：SfM 的两个支柱（算运动、算深度）都被换成了可微操作，使整条视频到深度的链路能用梯度下降一起训练。下面我们把这两块积木拆开看。

$$\text{视频帧} \;\to\; \underbrace{\text{Motion 模块}}_{\text{可微 BA（单次 GN 步）}} \;+\; \underbrace{\text{Depth 模块}}_{\text{可微立体匹配}} \;\to\; \text{每帧深度图} + \text{帧间位姿}$$

4. 两块可微积木：Motion Module 与 Depth Module

原文把「视频到深度」拆成两个子问题，分别交给两个模块。我们来看它们各自长什么样、为什么「可微」。

4.1 Depth Module：多帧立体匹配，用 cost volume 当桥梁

深度怎么从多帧里来？传统立体匹配的思路是：同一场景的不同视角看同一个点，会有「视差」，视差越大离得越近。DeepV2D 把这个思路可微化——先把每张图的 2D 特征反投影成一摞「代价体（cost volume）」，再用 3D hourglass 网络在这些体里做特征匹配，最后用可微的 arg-max 把深度「舀」出来。整条路径都是可微的，所以深度误差能反传回前面的特征网络。

4.2 Motion Module：单次可微 GN 步求位姿增量

位姿怎么来？Motion Module 先预测相邻帧之间的「残差流（residual flow）」，用它定义优化目标，然后解一个最小二乘问题来更新位姿。关键点：位姿增量 $\bar{\xi}$ 是由一次可微 Gauss-Newton 步得到的——也就是说，这一步本身是「反向传播穿过了优化器」，是 DeepV2D 里最反直觉、也最需要具象理解的地方。

★ 抽象点：为什么「反向传播穿过优化器」反直觉

通常我们以为「优化 / 求解」是个「黑盒输出结果」的动作，导数进不去。但 GN 步本质是一串矩阵运算（算雅可比、解线性方程），这些运算本身可微。所以 DeepV2D 把「解一步优化」直接写进计算图——误差能穿过这一步继续往前传。这就是为什么它叫 differentible SfM。

4.3 整体架构：Encoder + Residual Flow 网络

Motion Module 内部还有具体结构：Encoder 给每张输入图提一份 1/4 分辨率的稠密特征图，Residual Flow Network 吃一对特征图，估出残差流和对应权重。这套结构把「位姿更新」彻底落进了网络里。

6. 实验：NYU 单数据集训，零样本泛化三大集

DeepV2D 的实验设计很能说明它的卖点——泛化。它在 NYU 一个数据集上训练，然后零样本（zero-shot）直接用到 ScanNet、SUN3D（图中标 *）、KITTI 上，不需要为每个数据集重新调。这背后靠的就是「几何归纳偏置」：它学的不是某个数据集的像素统计，而是「多视图几何」这个结构本身。

另一个亮点是收敛快、且对视图数 / 迭代数灵活。下面这张图（Fig.5）显示：少量迭代就收敛；加更多视图精度持续上升；而且可以用「可变数量的视图、可变次数的迭代」去跑，不用重新训练。

★ 实验数字要诚实：原文怎么写就怎么引

精读材料给出的实验结论是：NYU 训练、零样本泛化 ScanNet / SUN3D（标 *）/ KITTI；少量迭代收敛（Fig.5）；优于同期纯 CNN 深度法与无监督法。这些都是原文的泛化结论，不是具体百分比——原文未给出可逐字引用的精确百分比时，课里只复述「优于同期方法」这一判断，不编造数字。

7. 衔接全季：它是后面学习式方法的「技术祖先」

把 DeepV2D 放回本季的脉络里，它的位置是「方法论基石」，而不是某篇应用。理解这一点，就能串起上一节的内容：

  • 接第五季 0100 / 0102（可微重建、端到端）：DeepV2D 是「端到端深度 + 位姿」路线里把可微 SfM 真正跑通的代表。
  • 是上一节 DytanVO 的「技术祖先」：0114 课里的 DytanVO 是「学习式 VO + 动态掩码」，它站在「可微几何可行」这个已经被 DeepV2D 证明的前提上——DeepV2D 证明了可微几何这条路走得通，DytanVO 才敢在它上面「加动态掩码」。
  • 和本季隐式地图（NeRF 系）的关系：DeepV2D 输出的是「每帧深度图 + 帧间位姿」，不维护持久地图，和 iMAP / PIN-SLAM 那种「把场景塞进一个函数」的隐式地图不是一回事。但它证明了「经典几何可微化」这一思想，后来被许多隐式 / 学习式 SLAM 借去当底层工具。

★ 诚实标注：DeepV2D 不是动态处理方案

在「鲁棒性与动态」这一组里，DeepV2D 的价值是「端到端 / 可微」的方法论基石，不是动态处理方案。它假设多视图间场景静态（SfM 前提），动态物体只会以「异常残差」形式出现，原文并未设计动态剔除模块。把它和 DytanVO（带动态掩码）对照，恰好看清「可微几何」与「可微几何 + 动态掩码」的层级关系。

课后练习

  1. 用自己的话解释「Differentiable Structure from Motion」指什么？它具体把 SfM 的哪两件事做成了可微？
    展开查看答案
    它指把 SfM 的两个核心子问题——运动估计和深度估计——各自做成一个可微模块，拼进端到端可训练网络。具体两件事是：Motion Module = 可微 BA（用单次可微 Gauss-Newton 步求位姿增量）；Depth Module = 可微立体匹配（cost volume + 可微 arg-max 出深度）。原文没有单独宣称「可微三角化」。
  2. 为什么说传统 SfM 流程里「梯度传不回去」？举出至少两个会阻断梯度的离散步骤。
    展开查看答案
    因为传统流程里有多处「离散决策」或「调用现成求解器」：RANSAC 选内点是「挑 / 不挑」的硬决策；最近邻匹配是取 argmin 的不可微操作；三角化里的 SVD 分解、BA 里的迭代求解器都让误差无法连续反传。任一都会掐断梯度，使整条链不能一起训练。
  3. DeepV2D 的 Motion Module 用的是「完整 BA」还是「单次 GN 步」？这对它意味着什么局限？
    展开查看答案
    是「单次可微 Gauss-Newton 步」的近似，不是反复迭代到收敛的完整 BA。局限在于：它只是一步近似，位姿更新不如完整 BA 精细；同时整篇依赖多视图静态假设，大动态 / 遮挡下几何残差会失效。
  4. DeepV2D 在泛化上有什么特点？它靠什么做到「NYU 训、三大集零样本」？
    展开查看答案
    它在 NYU 上训练，零样本直接用到 ScanNet / SUN3D（标 *）/ KITTI。靠的是「几何归纳偏置」：它学的是多视图几何这个结构本身，而非某个数据集的像素统计，所以换数据集也能泛化。另一特点是可用可变视图数 / 迭代数运行而无需重训。
  5. 把 DeepV2D 和上一节（0114）的 DytanVO 摆在一起，它们是什么关系？DeepV2D 算不算「动态处理方案」？
    展开查看答案
    DeepV2D 是「端到端 / 可微」的方法论基石，证明了可微几何可行；DytanVO 是站在它之上的「学习式 VO + 动态掩码」下游。DeepV2D 不算动态处理方案——它假设场景静态（SfM 前提），动态只以异常残差出现，原文未设计动态剔除模块。是基石，不是动态答案。
