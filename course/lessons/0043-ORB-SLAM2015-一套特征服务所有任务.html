1. 三线程架构：跟踪 / 局部建图 / 回环检测

PTAM（上一课 0042）把系统拆成两条线程。ORB-SLAM 觉得还不够：它要再补一条专门管回环的线程，于是变成三条并行线程，外加四张图（共视图、本质图、生成树、回环边）。论文 Fig.1 把整套系统画得清清楚楚。

$$\text{Tracking（30 Hz）}\;\parallel\;\text{Local Mapping（后台）}\;\parallel\;\text{Loop Closing（后台）}$$
  • Tracking（跟踪线程）：每帧都跑，频率最高。它抽 ORB 特征、用上一帧位姿初始化当前位姿（或触发重定位）、跟踪局部地图、判断要不要插新关键帧。论文实测整段跟踪中位 30.57 ms，约 25–30 Hz。
  • Local Mapping（局部建图线程）：接收新关键帧，做近点剔除、新点三角化、局部 BA、关键帧剔除。它是一道「慢」工序，实测整段中位 383 ms，但只在有新知识时才重活。
  • Loop Closing（回环线程）：用位置识别查数据库、计算 Sim(3)、做回环融合与本质图优化。关键帧越多它越贵，但增长是次线性的。

三条线程的通信靠共享的「地图」——由 MapPoints、KeyFrames、共视图、生成树组成，还有独立的「位置识别」模块（视觉词典 + 识别数据库）。这正是把 PTAM 的「双线程」扩成「三线程 + 四张图」的那一步。

2. 一套 ORB 特征，服务所有任务

ORB-SLAM 的核心卖点之一，是它只用一种特征——ORB，就同时喂饱了跟踪、建图、重定位、闭环四件事。这背后是一套关于「速度 vs 不变性」的精打细算。

论文 §III-A 把候选逐一排除，理由很硬：

SIFT / SURF 太慢

约 300 ms / 帧，A-KAZE 约 100 ms，都远超过「每帧必须 33 ms 内完成」的实时红线，被排除。

纯 BRIEF 缺旋转不变性

BRIEF 描述子没有方向，在宽基线（大视角变化）下无法识别同一地点，被排除。ORB = FAST 角点 + 方向 + 旋转感知 BRIEF，补足了这一环。

FAST 提供角点

用 FAST 检测关键点，并给每个点算一个方向（质心法），让描述子可旋转。

图像金字塔 + 网格均匀化

8 层金字塔（尺度因子 1.2）应对尺度；再把图切成网格，每个格子取前 N 个响应最强的点，保证特征在画面里均匀分布。

★ 为什么「网格化均匀分布」这么重要？如果只按「响应强度」贪心地取特征，画面纹理丰富的区域会被刷屏，而纹理稀少的墙角、天空一带一个点都没有。一旦相机转向稀疏区，就「没特征可跟」。网格均匀化让每一块都保留若干特征，整张图在任何朝向都有「抓手」——这是它比 PTAM 更鲁棒的关键细节之一。论文 §V-A 写明：在 512×384–752×480 的分辨率取约 1000 个特征，KITTI（1241×376）取约 2000 个，每层分格、每格至少 5 个、不够就自适应调高检测阈值。

3. 共视图与本质图：两个长得像但用处不同的图

ORB-SLAM 用「地图」不只是一个点云，而是两套图结构。理解它们，是理解这套系统为何能「局部化」、为何回环能快的原因。

共视图（Covisibility Graph）

节点是关键帧。如果两个关键帧「共同看到」了同一批地图点（至少 15 个），它们之间就连一条边，边权 = 共同观察到的地图点个数。所以它非常稠密——看到同一处场景的帧越多，线越密。

本质图（Essential Graph）

是共视图的「瘦身版」：取生成树（保证连通）+ 强共视边（边权 ≥ 100）+ 回环边。节点还是关键帧，但边稀疏得多。回环优化只在本质图（而不是整张稠密共视图）上做，所以又快又准。

一句话区分：共视图负责「平时谁和谁一起优化」（局部 BA 的邻域）；本质图负责「回环时怎么把整张地图拉正」（位姿图优化）。论文 Table VI 直接证明：在 KITTI 09 上，本质图优化 EG(θ_min=100) 只花 0.48 s、误差 8.36 m，而全局 BA 即便迭代 100 次也要 72 s 还难收敛。

4. 词袋（BoW）位置识别与倒排索引

回环检测和重定位都需要一个能力：给一张新图像，快速找出「我以前是不是来过这里」。暴力比对全地图太慢，ORB-SLAM 用 DBoW2 词袋库解决。

思路分两步：① 离线用大量图像训练一本「视觉词典」，把图像特征聚类成上百万个视觉单词（visual word）；② 每帧的关键点被量化到某个单词，于是每张图就变成一条「单词袋」。数据库维护一个倒排索引——对每个单词，记下「哪些关键帧里出现过它」。

★ 为什么检索是近似 $O(1)$ 而不是遍历全部？查询时，新图像抽出自己的单词列表，只去「这些单词对应的关键帧槽位」里找候选，取并集即可。根本不用逐张比对全地图——只用比较「有共同词」的少数图像。这正是 Table II 里「回环检测耗时随关键帧数次线性增长」的数学原因。

5. 自动初始化、重定位与回环纠正

初始化：H 与 F 并行打分，自动选模型

单目初始化在平面 / 低视差下有二义性。ORB-SLAM 的漂亮做法是：同时用同一批匹配点算两个模型——单应矩阵 $H$（适合平面）和基础矩阵 $F$（适合非平面），各自打分，再比分数决定用谁。

$$\mathbf x_c=\mathbf H_{cr}\mathbf x_r\quad,\quad \mathbf x_c^{\mathsf T}\mathbf F_{cr}\mathbf x_r=0$$

打分公式（对称转移误差）：$S_M=\sum_i(\rho_M(d_{cr}^2)+\rho_M(d_{rc}^2))$，阈值 $T_H=5.99,\ T_F=3.84$。关键判据：

$$R_H=\frac{S_H}{S_H+S_F}\;,\qquad R_H>0.45\ \text{选}\ H\;\text{（平面）},\ \text{否则选}\ F\ \text{（非平面）}$$

如果检测到二义性（twofold ambiguity），系统为安全起见拒绝初始化。下面这张原图把「模型选择」的收益画得很直白：PTAM 与 LSD-SLAM 在低视差下初始化出歪掉的平面解，ORB-SLAM 靠 F 正确初始化。

重定位：BoW 找候选 → PnP → RANSAC

跟踪一旦丢失，系统进入全局重定位：先用 BoW 在 Atlas 里找相似关键帧，对每个候选用 PnP（3D-2D）求解位姿，再用 RANSAC 剔除外点。论文 Table IV：重定位召回率 PTAM 34.9% vs ORB-SLAM 78.4%；跨序列（有行人遮挡）PTAM 0.0% vs ORB-SLAM 77.9%。

回环纠正：sim(3) 与尺度漂移

单目最头疼的毛病是尺度漂移——地图整体被「拉长 / 压短」却无法被图像证据发现。ORB-SLAM 检测到回环后，用带尺度的相似变换 Sim(3) 把两片地图对齐，而不是普通的刚体变换 SE(3)。单目共有 7 个漂移自由度：3 平移 + 3 旋转 + 1 尺度 $s$；用 $\log_{\mathrm{Sim}(3)}$ 把误差变成 $\mathbb R^7$ 向量，并固定闭环关键帧消去这 7 自由度 gauge。

6. 实验数字、sim(3) 与局限

论文在 27 条序列上做了穷尽评测（平台：i7-4700MQ 4 核 2.40 GHz + 8 GB）。挑几个硬数字：

  • NewCollege：跟踪中位 30.57 ms（约 30 Hz）；局部 BA 中位 296 ms；回环总耗时 0.51 s → 4.69 s，且随关键帧数次线性增长。
  • TUM RGB-D（关键帧轨迹 ATE RMSE 中位，cm）：ORB-SLAM 普遍 1–3 cm 级，明显优于 PTAM / LSD-SLAM。如 fr1_xyz 0.90 cm、fr2_desk 0.88 cm、fr3_long_office 3.45 cm。
  • 重定位召回：fr2_xyz 上 PTAM 34.9% vs ORB-SLAM 78.4%；跨序列（行人遮挡）PTAM 0.0% vs ORB-SLAM 77.9%。
  • KITTI 里程计（关键帧轨迹 RMSE，m）：序列 00 为 6.68 m（20 次全局 BA 后 5.33 m）、序列 03 低至 1.59 m；误差约为地图尺寸的 1%。序列 01（高速路）失败。
  • 闭环策略对照（KITTI 09）：无闭环 48.77 m；BA(100) 18.82 m / 72 s；EG(θ_min=100) 8.36 m / 0.48 s——本质图优化又快又准。

★ §IX-B 还给出「特征法为何比直接法更准」的完整论证：直接法需假设表面反射模型、光度一致性限制基线宽度（伤深度精度）、对卷帘/自动增益/自动曝光敏感、计算重而往往退化为只做位姿图；特征法可宽基线匹配，且 BA 同时优化位姿与点。这正好埋下了第三季「直接法线（LSD-SLAM / SVO / DSO）」的岔路口。

论文没有单列 Limitations 小节，但正文明确承认这些边界：① 平面 + 低视差场景若存在 twofold ambiguity 会为安全拒绝初始化（如 fr3_nostructure_texture_far）；② KITTI 序列 01（高速路、缺近处物体）失败；③ 无回环序列（KITTI 08）的漂移无法纠正；④ 纯旋转初始化会失败（需足够视差）；⑤ 单目存在尺度漂移，需 Sim(3) 处理。最后作者点出两条未来方向：加入无穷远点（利于约束旋转）、以稀疏图为骨架建更稠密模型。

课后练习

  1. ORB-SLAM 的三条线程各叫什么？各自大致的频率 / 节奏是怎样的？
    展开查看答案
    Tracking（每帧 30 Hz 左右，约 30.57 ms/帧）、Local Mapping（后台，整段中位约 383 ms，只在有新知识时重活）、Loop Closing（后台，随关键帧数增加但次线性增长）。三者通过共享地图（关键点、关键帧、共视图、生成树）通信。
  2. 为什么 ORB-SLAM 既要网格化、又要「每个格子取前 N 个」的均匀化特征提取？
    展开查看答案
    只按响应强度贪心取点会让纹理丰富区刷屏、稀疏区一个点都没有；一旦相机转向稀疏区就无特征可跟。网格均匀化保证每个区域都保留若干特征，使任何朝向都有可跟踪的抓手，提升鲁棒性。
  3. 共视图与本质图的定义和用途分别是什么？为什么回环优化用本质图而不是共视图？
    展开查看答案
    共视图：节点是关键帧，共视同一批点（≥15 个）就连边，边权＝共同点数，很稠密，用于日常局部 BA 的邻域选择。本质图：生成树 + 强共视边（≥100）+ 回环边，稀疏。回环优化在本质图上做，又快又准（KITTI 09 上 EG 0.48 s vs BA 72 s）。
  4. 初始化时 $R_H>0.45$ 判据在选什么？它对应 0024 VO 教程里的哪个概念？
    展开查看答案
    在「单应 H（平面场景）」与「基础矩阵 F（非平面）」之间自动选择：并行算两模型、对称转移误差打分，$R_H=S_H/(S_H+S_F)$，大于 0.45 选 H。这对应 0024 里「2D-2D 运动估计管线」，是工程系统第一次在运行时自动选模型。
  5. 单目 Sim(3) 比 SE(3) 多出来的那个自由度是什么？它怎么被估出来？
    展开查看答案
    多出来的是尺度因子 $s$（单目共 7 个漂移自由度：3 平移 + 3 旋转 + 1 尺度）。检测到回环后，用 $\log_{\mathrm{Sim}(3)}$ 把对齐误差写成 $\mathbb R^7$ 向量，固定闭环关键帧消去 gauge，优化解出 $s$，把两片地图整体缩放对齐。
