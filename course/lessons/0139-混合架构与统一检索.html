和前面课程怎么接

本篇是 0011「检索被吃掉」 在图像 VPR 的「架构演进」：接 0138 的 CricaVPR / SALAD（都是单阶段），Hybrid 是另一条单阶段路线（CNN-Transformer + 语义），R²Former 则是检索+重排序两阶段的代表。⚠️ 关键对照：SALAD（单阶段）在 MSLS-ch 反超 R²Former（两阶段）——这是「聚合比重排序更关键」的实证，本课要用它收束「单阶段 vs 两阶段」之争。

1. 它到底在做什么：先讲人话

图像地点识别说到底就一句：给一张查询图，从地图库里找出「最像」的那张。怎么造「最像」的向量、怎么比，前面几节各显神通。本节两篇代表两种工程取向：

  • Hybrid：单阶段。把「CNN 的局部细节」和「Transformer 的长程上下文」焊在一起，再叠语义先验，一个向量定终身。
  • R²Former：两阶段。先用 ViT 的 class token 做一次粗检索，再用 patch token 做一次「重排序」精修——一个框架干两件事。

在聊它们之前，先统一评测语言：Recall@1 / Recall@1% 到底在看什么。

2. Recall@1 与 Recall@1%：候选列表的第一位对不对

检索系统对每张查询图，会按相似度排一张候选列表（最像的排最前）。Recall@1 看「正确匹配有没有排在第 1 位」；Recall@1% 看「正确匹配有没有进前 1%（前 N 张，N = 数据库大小的 1%）」。注意第一季 0013 警告过：R@100P 这类指标有坑，Recall@1 只是「最严格的一条」，要配合 PR 曲线看。

3. Hybrid：CNN 局部 + Transformer 上下文 + 语义

Hybrid 的观点：纯 CNN 有局部性、难建模长程空间结构；纯 Transformer 擅空间上下文、但缺局部细节。它把两者焊起来，再叠语义先验。结构：VGG-16 提 Conv1_2/2_2/3_3 特征金字塔 → 与图同切成 N 个 patch 拼接 → 投影进 Swin-B（4 阶段）→ 多尺度 token 融合 → 语义增强 NetVLAD 聚合 → PCA 白化 + L2 得 4096 维描述子。

语义增强 NetVLAD

在 vanilla NetVLAD 残差上乘类内显著性权重 $\beta_k(x_i)$，质心由 DeepLabV3+ 在 Cityscapes 预训练得到（建筑/树等作代表质心，人/车/天空作阴影质心）。消融显示语义增强贡献最大。

自适应 triplet loss

动态 margin $m_a^i=\frac{\varphi(q,n)_{max}-\varphi(q,n_i)+\alpha}{\varphi(q,n)_{max}-\varphi(q,n_{min}}+\beta}$（α=0.15, β=1e-8）。对「相似但异地」的难负给更小 margin，使其继续贡献学习。

数字

Pitts30k R@1 86.3、Tokyo24/7 78.9（比纯 CNN 70.2、纯 Transformer 73.0 都高）。推理 48.4 ms/query，仍是单阶段。

反直觉

低层 token 比高层好（S1 84.95 > S3 83.48 on Pitts30k）——局部细节比高层语义更重要；纯 ViT 输入在 Pitts 上弱于 CNN，但在 Tokyo 上强于 CNN。

注意它是纯单阶段全局检索，未来工作才提到「可加局部特征重排序」。这说明即使不加两阶段，混合架构本身已经很强。

4. R²Former：一个 ViT 框架统一检索与重排序

R²Former 的核心主张：传统流水线用「聚合 CNN 特征检索 + RANSAC 几何验证重排序」，而 RANSAC 只用几何信息。R²Former 用纯 Transformer 把检索和重排序做成两阶段一体：

检索（class token）

ViT-S（12 层，384 维），class token 直接当 256 维全局特征（线性降维 + L2）。平方 L2 做检索，margin triplet 训练。

重排序（patch token）

倒数第二层 patch token 降为 128 维，按 attention 选 Top-500（每特征存 128+3=131 维）。对 top-100 候选构造 500×500×7 关联矩阵（坐标/注意力/余弦相似）送 Transformer 重排。

重排序模块

融合「特征关联 + 注意力值 + xy 坐标」学二分类（同地/异地），比 RANSAC 更快更准。可插到别的 CNN/Transformer backbone。

数字

MSLS-val R@1 89.7、MSLS-ch 73.0；reranking 202.37 ms、显存 4.79 GB（比 Patch-NetVLAD-p 的 908 GB 降约 189×）。

R²Former 是检索 + 重排序两阶段的代表——这恰是和 CricaVPR / SALAD / Hybrid（单阶段）的本质区别。但本季最反直觉的结论是：单阶段的 SALAD 在 MSLS-ch（75.0）超过了两阶段的 R²Former（73.0）。也就是说，「好的聚合」有时比重排序更关键。

  1. 用候选列表解释 Recall@1 与 Recall@1% 的区别，并说明为什么单看 R@1 可能不够。
    展开查看答案

    候选列表按相似度排序，Recall@1 看正确匹配是否排 #1（最严），Recall@1% 看是否落进前 1% 区间（较松）。单看 R@1 可能掩盖「榜首偶尔错、但前几名都对」的情况；且大库里前 1% 已经很大，R@1% 更贴近实际可用召回。呼应第一季 0013：R@100P 等也有坑，应配合 PR 曲线。

  2. Hybrid 为什么要把 CNN 和 Transformer 焊在一起？纯用哪一个会缺什么？
    展开查看答案

    纯 CNN 有局部性、难建模长程空间结构；纯 Transformer 擅空间上下文、但缺局部细节（且低层 token 比高层更有用，说明局部细节关键）。Hybrid 用 VGG 金字塔取局部细节、Swin 取多尺度上下文、语义增强 NetVLAD 聚合，三者互补。实证：纯 CNN 70.2、纯 Transformer 73.0，混合 78.9（Tokyo24/7），混合明显更好。

  3. R²Former 的重排序模块比 RANSAC 几何验证强在哪？它靠什么信息？
    展开查看答案

    RANSAC 只用几何信息（局部特征对）。R²Former 的重排序模块融合「特征关联（余弦相似）+ 注意力值 + xy 坐标」成 500×500×7 关联矩阵，送 Transformer 学二分类（同地/异地）。它不只看几何，还看「哪些 patch 更重要、关联多强」，因此更准且显存骤降（4.79 GB vs Patch-NetVLAD-p 908 GB）。模块还可插到其他 backbone。

  4. 为什么说 SALAD 单阶段反超 R²Former 两阶段是「反直觉」？这说明了什么？
    展开查看答案

    直觉上「检索后再重排序」应该更准，但 SALAD（单阶段，MSLS-ch 75.0）> R²Former（两阶段，73.0），且快 3× 以上。说明当描述子本身聚合得足够好（DINOv2 + OT + dustbin），「重排序」带来的增益有限，「聚合质量」才是瓶颈。这推翻了「两阶段必然更优」的默认假设。但两阶段在难感知混叠下仍有价值，并非绝对输。

  5. 把 0134–0139 的「检索」演进用一句话收束，并点明还欠 0014 什么账。
    展开查看答案

    从 DBoW2（手工视觉词袋，0134）→ Scan Context 系（免训练几何，0135）→ LCDNet/OT/BEVPlace/SeqOT（学习式投影图/序列，0136–0137）→ CricaVPR/SALAD/Hybrid/R²Former（学习式图像 VPR，0138–0139），「检索」被深度学习一步步吃掉，且吃法多元。但本块还没正面回答第一季 0014 的「回环假阳性铁律」：学习式方法把假阳性率压下去了吗？代价是什么？新失效模式是什么？这笔账要等 0140 LCR-Net（完整回环+重定位系统）来结。
