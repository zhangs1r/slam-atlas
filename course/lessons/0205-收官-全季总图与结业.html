2. 你现在能做什么：四条可检验的能力

导览课 0199 在开场时留了一个问题没答：学完这十一季，你到底能做什么？现在来结账。

回答这个问题有一条纪律：不能用「我对 SLAM 有了更深入的理解」这种话 —— 那不可检验。要写成「拿到一样东西，你能做出一件具体的事」。所以下面四条，每一条都配了检验方式：你可以拿一篇没读过的论文当场试。

能力 具体做什么 怎么检验
① 能读论文 拿到一篇没读过的论文，能在半小时内说出：它解决什么问题、用了哪些零件、站在系统链的哪一环、吃进什么吐出什么、不负责什么。 随便挑一篇 2024 年的 SLAM 论文，先只读标题、摘要、图和结论，写出上面的六句话。写完再读全文，看自己错了哪几句。练到错得少，就算过关。
② 能判断方法好坏 看到任何一个精度或速度数字，能立刻问出口径三件套：谁报的、在哪个数据集上、是绝对还是相对 / 什么阈值；能看出「阈值相同也不保证数字可比」。 找一篇带对比表的论文，把表注与正文里关于评测协议的句子全部圈出来，检查有没有互相矛盾。0204 那一节已经给过一次标准答案。
③ 能认零件 看到 RPN、RoI pooling、BEV、TSDF、体素哈希、B 样条、预积分、Cauchy 核这些名词，知道它是干什么的、属于哪一层、该不该停下来精读它。 用第十季 0198 的「三十秒三判据」过一遍一篇新论文的方法节，把每个陌生名词归进「必须懂 / 知道就行 / 直接跳过」三档，写下理由。
④ 能看位置 能画出一条系统链，把一篇论文按上去，说清它的上游是谁、下游给谁、哪几格空着；能看出「SLAM 做好不等于机器能自主」。 拿本季三篇应用论文（0200 横跨六环、0201 一环都不实现、0202 只做两环的算力部署）互相对照，重新画一次覆盖图。能画出来就算过关。

3. 还欠什么：一段诚实结账

一门课如果不肯说自己的缺口，它就在偷偷把「我讲过的」冒充成「全部」。所以这一栏必须写，而且要写具体。

欠条一：建图质量的评测

第九季 0179–0185 把「怎么量轨迹误差」讲透了，但只点名了「建图质量的评测」这件事，没有真正展开。

这件事为什么重要：轨迹对了不代表地图对。位姿可以是准的，点云却可能糊、可能重影、可能把一段墙拼成两层。要评「地图对不对」，需要的是另一套尺子（表面一致性、法向偏差、几何完整度……），而这套尺子本课没给你。

欠条二：多机数据集的真值难题

第八季 0152–0178 的多机块讲了算法，第九季讲了数据集，但两处都没法回答一个尖锐的问题：为什么多机数据集里几乎没有长轨迹的高精度真值？

原因是物理的：动捕场地就那么几十平米，装满摄像机的房间根本容不下几台机器跑几公里。于是真值越贵，能做的场景就越小；能做的场景越大，真值就越粗。这是全领域的难题，不是本课的疏忽 —— 但本课确实没有把它讲透。

欠条三：重要性来自行业共识，不是本语料库证据

第十季有几处，我们说的「这个词很重要」依据的是整个领域的行业共识，而不是本语料库里的引用证据。已经如实标注过的两处是：Focal Loss 零正面引用、PVT 零实引。

也就是说：它们在库外的世界里确实重要，但在这 255 篇里，你找不到足够的引用来支撑「重要」这个判断。我们把依据是哪一类也写出来了，剩下的只能等你自己去补。

欠条四：硬件篇没测的那些项

第十季 0195 讲的是激光雷达硬件，但它只讲了原理，没测具体指标。没测的有：测距范围、扫描频率、功耗、MPE、运动畸变、TDC。

后果是：读完那一节，你懂了「点云怎么来的」，但选型时仍然没有可比的数字。而本季 0200 讲传感器选型时，用的正是这类数字 —— 中间这一段是断的。

还有一条欠账，是本季才浮现的

本季 0201 的运动规划综述只讲了「怎么选型」，0200 的控制部分也只讲了它自己那套实现。也就是说：规划与控制这两环，本课从头到尾没有系统的课。它只被「路过」了三次。这条件我们记在账上。

4. 范围声明：这是 255 篇语料库上的课

最后一件事，必须说清楚：这门课不是「SLAM 全集」，它是「255 篇语料库上的课」。这两句话差别很大。

它的意思是：这十一季里出现的每一个判断、每一张地图、每一次「这个方向只有三篇」，范围都止步于那 255 篇论文。库外的世界是更大的，也是我们没读过的。所以下面这几条要写明白：

语料库里有什么

md/ 目录下共 255 个论文文件（另有 2 个非论文文件 _compact.md 与 _digest.md）。这 255 篇就是本课的全部依据，每一节的每一句技术判断都应该能追溯到其中一篇。

语料库里没有什么

有几样东西，你在这门课里找不到：VGG 的一手论文、PVTv2、AlexNet、MobileNet、EfficientNet。它们都会在别人的论文里被引用，但本课没有它们的原文 —— 所以我们只能告诉你「它们存在」，不能给你「它们讲了什么」。

骨架线上还有缺口

第十季的骨干网络那条线（0187–0189、0194）本身就不完整：AlexNet、MobileNet、EfficientNet 都不在库内。也就是说，「骨干网络的演进」这条线在这门课里是断着几段的，你补的时候要自己接。

数量口径要带上下文

「255 篇」这个数字也有它的口径：各季清单相加是 252 篇，md/ 目录下是 255 个论文文件。差的 3 篇来自跨季重复使用与个别录入问题。写数字时请带上口径 —— 这是第九季教过的第一课。

为什么要专门写这一栏？因为这正是这门课一直在教的那件事：任何一个说法都要能指回依据，也要说清依据的边界。我们要求论文作者写清「作者自报、在哪个数据集上、什么阈值」，那么这门课自己也该写清「在哪个语料库上、覆盖了哪些、漏掉了哪些」。对别人用的尺子，也要对自己用一遍。

顺带说一句：边界之外不是空白，只是不在本课里。你要是想把 AlexNet 那一段接上，去找那篇原始论文读一遍就行 —— 你现在已经有能力判断它值不值得读了（这正是第 2 节第 ③ 条能力）。

5. 从全景出发，回到全景

最后说一句这十一个阶段的意义。

这门课的第一季第一节课是 0001，它做的第一件事是画一张 255 篇论文的阅读地图；紧跟着的第二节课 0002 立了一张全景纲领 —— 它回答的是「SLAM 这个词到底指什么」以及「整个领域分成哪几块」。

然后我们走了很久：第二季往下打地基，第三到七季在视觉、激光、融合、空间表示、学习方法五条主干上纵向走，第八到十季换了三种切法（支线、尺子、零件），第十一季换了第四种切法（位置）。

走到最后一节，你回头会发现：这一季画的那些图，和第一季 0002 那张全景纲领，说的是同一件事。第一季告诉你「这个领域有哪几块」，第十一季告诉你「这几块在一台真机器上分别对应哪一格」—— 一个是地图，一个是坐标系；合起来，全景才算真的立起来。

整个项目的闭环

从第一季的全景纲领出发，走了十个季节的内容，最后在这一节回到全景。这不是重复 —— 出发时你有的是别人画好的地图，回来时你有的是自己长出来的坐标系。同一张全景，看它的眼睛换了。

如果只能从这十一季带走一句话，那就带这一句：先看清一篇论文站在哪、吃什么、吐什么、不负责什么，再去讨论它好不好。前 198 节课在打磨零件，最后这 7 节课在告诉你零件装在哪台机器上、装完之后要给谁用 —— 把它合起来，你才真正读懂了 SLAM 论文里那句最常见的结尾：「我们的位姿输出可以供下游模块使用。」

读完你应该能回答

① 全十一季总图是什么形状？

一座七层的楼 + 四条从旁边穿过的横切面。主干七层是 A 综述与全景 → B 打地基 → C 视觉主干 → D 激光主干 → E 多传感器融合 → F 神经隐式与 3D 高斯 → G 学习式方法；四个横切面是 H 支线、I 尺子、J 零件、K 位置。

② 为什么这样编排？

因为主干是一条纵向的技术演进（每一层建立在前一层之上），而横切面是四种不同的切法：换场景、换尺子、换颗粒度、换视角。它们不属于某一层，所以只能横着切过去。

③ 十一季一共多少篇、多少节？

各季篇数相加是 252 篇；项目口径的语料库是 255 篇（md/ 下 255 个论文文件）。节数相加是 205 节，与课程目录下的文件数一致。数字差 3 篇的地方是计数口径，已如实说明。

④ 你现在能做什么？

四条可检验的能力：能读论文（半小时说出六件事）、能判断方法好坏（对任何数字问口径三件套）、能认零件（知道哪些该停下来读）、能看位置（把一篇论文按到系统链上说清上下游）。

⑤ 还欠什么？

四笔账：建图质量的评测（第九季只点名）、多机数据集的真值难题（动捕空间装不下多机长轨迹）、几处重要性来自行业共识而非本语料库证据（Focal Loss 零正面引用、PVT 零实引）、0195 没测测距范围 / 扫描频率 / 功耗 / MPE / 运动畸变 / TDC。另外规划与控制两环全程没有系统的课。

⑥ 这门课的边界在哪？

它是 255 篇语料库上的课，不是 SLAM 全集。库外的东西（VGG 一手论文、PVTv2、AlexNet、MobileNet、EfficientNet）要如实说「不在库内」；骨架线上还断着几段，得自己接。

    因为两者量的东西不同：轨迹误差量的是位姿序列跟真值轨迹差多远，地图质量量的是点云 / 面元 / 体素这些几何元素拼得对不对。一个具体场景：机器人在一条长走廊里来回走，回环把两端对齐了，位姿序列的 APE 很小 —— 但两次走过的点云在墙面上错开了 10 厘米，地图上那面墙就是两层薄片（重影）。位姿看起来是对的，地图是糊的。要评后者，需要表面一致性、法向偏差、几何完整度这类尺子，而不是位姿误差。这正是本课欠的第一笔账。
  4. 请用「可检验」的方式，给你自己写三条能力清单（要求：每条都必须有明确的输入和明确的动作）。
    展开查看答案
    参考答案（你自己的可以不同，但必须满足「有明确输入 + 有明确动作」）：
    ① 给定一篇没读过的 SLAM 论文，在半小时内写出：解决的问题、用到的零件、所在系统链的环、输入、输出、不负责什么 —— 六句话。
    ② 给定一张带对比表的论文，圈出所有关于评测协议的句子，列出互相矛盾之处，并写清这张表的数字能不能横向比较。
    ③ 给定一个陌生名词，用三十秒判断它属于「必须懂 / 知道就行 / 直接跳过」哪一档，并写出理由。
    不合格的写法如「我对 SLAM 的理解更系统了」「我能看懂大部分论文了」—— 没有明确的输入，也没有可观察的动作，别人无法检验，你自己也无法。这也是第 2 节「可检验」那条纪律的现场练习。
  5. 本课说「从全景出发，最后回到全景」。请说清第一季 0002 的全景和这一节的全景，区别在哪，为什么这不叫重复。
    展开查看答案
    区别在两张全景的性质不同。0002 那张是别人画好的地图：它告诉你这个领域分成哪几块、每一块叫什么名字、彼此什么关系 —— 你是拿着它上路的。这一节这张是你自己长出来的坐标系：同一条系统链、同样的七环，但现在每一格下面都能写出「哪几季讲过、哪几篇论文、它的输入输出是什么」。
    所以不是重复，而是看同一张全景的眼睛换了：出发时你能认出那些名字，回来时你能说清它们在真机器上是哪一格、由谁供数据、交给谁用。这也解释了为什么最后一季要选「看位置」这个切法 —— 它把前十个季节的所有内容，全部钉回了一个坐标系上。
