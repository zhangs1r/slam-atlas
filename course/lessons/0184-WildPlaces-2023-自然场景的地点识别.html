Wild-Places（2023）：亚米级真值也能评地点识别

它是一把什么样的尺子？——首个面向非结构化自然环境的 LiDAR 地点识别数据集，真值由 SLAM 自己建图得到，精度只有约 0.3–0.95 m（亚米级）。🌲 这一课点明全季最重要的洞见：任务不同，对真值精度的要求就不同——它评的是「检索」，亚米级真值完全够用，不能和 TUM/Hilti 放在同一精度梯队。

1. 一句话定位：一把「亚米级」的尺子（先纠正一个常见误判）

先看一个必须纠正的认知：清单把 5 篇并列，容易让人以为它们的真值精度差不多。实际不符——Wild-Places 的真值只有亚米级，原文写明 Wildcat 平均误差 0.3 m，机间 ICP 配准「95% 对应点误差 < 0.95 m」，地点识别成功判据是「检索结果落在 3 米内」。它评的是地点识别（检索），不是轨迹精度，不能与 TUM（毫米级）、Hilti（毫米级）放在同一精度梯队。

这恰恰是全季最重要的洞见：任务不同 → 对真值精度的要求就不同。「真值越准越好」是外行话，够用才是工程标准。Wild-Places 评的是「这段激光子图是不是之前来过的地方」，判据本来就是米级，所以亚米级真值完全够用。

生活类比：你要考的不是「这个人每步走得准不准到毫米」，而是「他有没有回到昨天那条小径」——只要知道他大概在 3 米内，就判对了。用毫米级卷尺去量这个，是杀鸡用牛刀。

2. 它长什么样：手持载荷与传感器

平台是人背着的传感器载荷（handheld payload），在澳大利亚布里斯班两个国家公园（Venman、Karawatha）的密林小径上走。传感器：Velodyne VLP-16（16 线，20 Hz，120 m）；4 相机 e-CAM130A（15 Hz）；IMU Microstrain 3DM-CV5-25（100 Hz）；一个无刷电机以 0.5 Hz 把激光倾斜 45° 旋转，把原 VLP-16 仅 30° 的垂直视场扩展到 120°；Nvidia Jetson AGX Xavier；PPS 时间同步。

激光

VLP-16，16 线，20 Hz；靠 0.5 Hz 倾斜旋转得 120° 垂直 FOV（原仅 30°）。

平台

人背手持载荷，走自然非结构化小径；PPS 硬同步。

规模

32.87 km、8 h 51 m、63 319 个子图（平均 >300 K 点/子图）。

3. ★ 真值是怎么来的：SLAM 自举（不是外部设备）

它不依赖动捕、不依赖测绘扫描仪——在密林里这俩都用不了。真值来自 Wildcat SLAM 自举：① 用 Wildcat（连续时间轨迹表示 + 因子图 + 回环）为每条序列生成全局一致地图与轨迹；② 序列间用 ICP + MSAC 把各全局地图互相对齐，得到跨序列变换。真值即这些 6-DoF 位姿（每 0.5 s 采一个 60 m 直径子图 + 位姿）。

这意味着真值天花板由 SLAM 本身决定——所以它是亚米级，不是厘米/毫米级。这种「用 SLAM 评 SLAM」存在循环论证风险：你拿方法来造真值，又拿这真值去评方法。作者用与外部测量交叉比对来缓解（论文说明其误差与独立测绘吻合在 0.3 m 量级）。

4. ★ 真值精度是多少：亚米级（显式纠正，不能同梯队）

必须如实写：它不是厘米/毫米级。具体数字（原文）：Wildcat 对比测绘真值报告平均误差 0.3 m（用于序列内）；序列间 ICP 配准 >95% 对应点误差 < 0.95 m（用于序列间）。整体亚米到米级（约 0.3–0.95 m）。原文称「accurate 6DoF ground truth」是相对地点识别任务而言；对精确轨迹误差评测来说太粗。

❌ 错误认知

「Wild-Places 和 TUM/Hilti 一样是毫米/厘米级真值，可以横向比轨迹精度。」

✅ 正确认知

它是亚米级（0.3–0.95 m），评的是地点识别，不与 TUM/Hilti 同精度梯队。

全季核心洞见：任务不同 → 对真值精度的要求就不同。城市地点识别（Oxford/KITTI）R@1 已被刷到 >99%，而自然域（Wild-Places）R@1 仅约 70–80% 且长期退化严重。这里「真值准到亚米」已经绰绰有余，因为成功判据是「检索结果落在 3 米内」——「真值越准越好」是外行话，「够用」才是工程标准。

下面这张原文图就是「亚米级」这三个字的直接证据：它画的是两条序列的全局地图配准之后，每一对对应点之间还差多远。如果真值是毫米级，这张图应该几乎全黑；而它实际呈现出明显的颜色梯度，正说明对应点之间有几十厘米到接近 1 米的距离。

5. ★ 覆盖哪些场景：自然密林与长期重访

两个国家公园（Venman、Karawatha），纯自然非结构化——密林小径、垂枝、不规则地形、偶有水体/泥地（无 LiDAR 回波）。8 条序列跨越 14 个月，含序列内正/反向重访与序列间短期/长期（>1 年）重访。规模 32.87 km、8 h 51 m、63 319 子图。它是 Table I 中唯一同时满足「自然环境 + 含序列内/间 + 长期(>1 年)重访」的数据集。

长期退化显著：以 02 为 query 对比 01/03/04（同日/6 月/14 月），R@1 因时间差最大下降 45.1%(Venman) / 24%(Karawatha)。V-03 因反向重访最多而最难；Karawatha 整体比 Venman 难。

6. 评测协议：R@1 / MRR / F1 与「成功判据半径」

任务 = LiDAR 地点识别（回环 + 重定位），分两类：

  • 序列间（重定位）：query 取自 withholding 区，database 为同环境其他序列子图；成功 = 检索子图在 3 m 内；指标 top-1 Recall (R1) 与 MRR。
  • 序列内（回环）：子图匹配同序列历史，排除时间差 < 600 s 的邻近项；成功同样 3 m 内；报 max F1 与 R1。

定义式（务必记住成功判据半径这个前提）：

$$\mathrm{R1}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[\,\text{rank}_i=1\ \text{且距离}<3\,\text{m}\,]\qquad \mathrm{MRR}=\frac{1}{N}\sum_{i=1}^{N}\frac{1}{\mathrm{rank}_i}\qquad \mathrm{F1}=2\frac{\mathrm{P}\cdot\mathrm{R}}{\mathrm{P}+\mathrm{R}}$$

这句话在说什么：R1（top-1 Recall）数的是「检索第一名是否落在 3 米内」的比例——没有「3 米」这个判据半径，R1 毫无意义。MRR（平均倒数排名）把第一名的排名取倒数再平均，越靠前越高。F1 是准确率 P 和召回率 R 的调和平均，max-F1 是扫不同距离阈值后的最佳值。这三个指标都建立在「成功 = 3 米内」之上。

回链第七季：0134–0140 讲场景识别时反复用到 Recall@1，但当时没强调「判据半径」。这里补上关键前提：召回率如果没有前缀（R@1 / R@1% / 判据半径），是没有意义的——城市数据集 R@1>99% 和自然域 R@1≈70% 不能直接比，因为判据、场景、时间跨度都不同。

7. 共享点泄漏与「1 秒时间窗」

地点识别有个隐蔽陷阱——共享点泄漏：如果两段序列共享了同一批点云（比如同一条小径正反向各走一遍），检索时相当于「用自己的一部分去认自己」，结果虚高、作弊。Wild-Places 用「1 秒时间窗」把共享点切开：排除时间差 < 600 s（序列内）或 withholding 橙色区（序列间），确保查询和数据库不共享同一批点。

8. 什么时候该用 / 不该用

✅ 该用

评自然非结构化环境下的 LiDAR 地点识别 / 回环 / 重定位；想测长期（>1 年）重访退化；不需要精确轨迹真值，只需「认不认得出地方」。

❌ 不该用

评精确 SLAM 轨迹误差（真值仅亚米级，太粗）；评城市/结构化场景（它有城市数据集可刷 >99%）；当「金标准真值」去和 TUM/Hilti 横比。

9. 作者自述的局限

论文自己点了三条，每一条都正好落在这个数据集的定位上：

  1. 真值来自 Wildcat SLAM 自举，不是独立测绘——精度只有亚米级，所以它不适合做精确 SLAM 轨迹误差评测。这一条最关键：它等于作者亲自承认「我这不是一把毫米级的尺」。
  2. 序列间配准误差 < 0.95 m——跨序列那部分真值的精度上限就在这里，用它做序列间（重定位）评测时，判据半径不可能比这更细。
  3. 只覆盖自然环境，人造结构尽量少——这是它的卖点（城市域已被刷到 > 99% R@1），也是它的边界：想评结构化场景就得换数据集。

把这三条和前面几节的数字放在一起看，结论很清楚：Wild-Places 的「准」是相对于「检索任务」而言的准。原文用「accurate 6DoF ground truth」这个词，放在地点识别的上下文里完全站得住；但如果有人把它抄进「精确轨迹误差评测」的段落，就错了。这正是第一季 0013 那句「注意评测口径」在今天的又一次兑现。

课后练习

  1. Wild-Places 的真值来源和精度是多少？为什么说它「不能与 TUM/Hilti 同梯队」？
    展开查看答案
    真值由 Wildcat SLAM 自举（建全局地图 + ICP/MSAC 跨序列配准）得到，平均误差约 0.3 m，序列间 95% 对应点 <0.95 m，属亚米级。它评的是地点识别而非轨迹精度，而 TUM/Hilti 是毫米级轨迹真值，精度档和任务都不同，故不能同梯队横比。
  2. 「用 SLAM 评 SLAM」有哪些风险？Wild-Places 如何缓解循环论证？
    展开查看答案
    风险：方法既是被测对象又是真值来源，误差会被自我印证（循环论证），真值天花板被钉在 SLAM 自身精度。缓解：与外部测量做交叉比对，确认误差约 0.3 m；用 ICP+MSAC 做序列间配准；承认它只能评检索、不能评精确轨迹。
  3. 解释共享点泄漏，并说明「1 秒时间窗」如何防止它。
    展开查看答案
    正反向走同一条小径时两段共享同一批点云，若一段当查询、另一段当数据库，等于「自己认自己」，R@1 虚高。他们用「1 秒时间窗」排除时间差 <600 s 的邻近项（序列内），并 withholding 橙色区域（序列间），把共享点隔开。
  4. 如果某论文报告「Wild-Places 上 R@1 = 75%」，这个数字单独看有意义吗？需要哪些前缀才完整？
    展开查看答案
    单独看不完整。必须说明：① 成功判据半径（这里是 3 m）；② 是序列内还是序列间；③ 时间跨度（同日/6 月/14 月，长期退化会让数字掉到约 45%）。没有这些前缀，R@1 无法与城市数据集的 >99% 比较。
