和前面课程怎么接

本篇是 0011「检索被吃掉」 在图像 VPR 侧的高潮：从 DBoW2（0134）的视觉词袋，到本节用 DINOv2 基础模型 当骨干。⚠️ 最关键区分：SALAD 用最优传输做「描述子聚合」，而 0129 SuperGlue 用最优传输解「匹配指派」——同名词不同用，本季反复强调学习者最易混，本节用一张图彻底分清。

1. 它到底在做什么：先讲人话

图像地点识别的本质是：把一张图压成一个向量，再拿向量去最近邻检索。压向量的「聚合」方式，本节看两种：

  • CricaVPR：让一批图「互相看一眼」——同一地点不同角度/天气的图在 batch 里互相当正则，逼出更鲁棒的特征。
  • SALAD：把 NetVLAD 的「软分配」重写成最优传输（Sinkhorn），并加 dustbin 丢掉天空/路面这类无信息特征。

两者都是单阶段全局检索（一张图一个向量，直接最近邻），不需要 RANSAC 几何校验、也不需要重排序。但 SALAD 单阶段却在 MSLS Challenge 上反超了带重排序的两阶段方法——这是本块最反直觉的结论。

3. CricaVPR：让一批图互相看一眼

CricaVPR 的巧思在特征提取阶段就引入「批内跨图像关联」：backbone 用冻结（仅 adapter）的 DINOv2（ViT-B/14），224×224 输入。先用 spatial pyramid 把 patch token 分成 1×1 / 2×2 / 3×3 三级（1×1 级直接用 class token），共 14 个区域特征。关键是——

$$f_i=\{f_i^1,f_i^2,\dots,f_i^B\}\quad\text{（batch 内所有图的第 i 个区域特征组成序列）}$$

这句话在说什么：把「同一地点不同角度/天气、甚至异地」的图放进同一个 batch，取出每张图的第 i 个区域特征，串成一条序列送进 cross-image encoder（2 层 transformer）。于是每个区域特征在生成时，顺带借了同批其他图的信息——同地异况的图互相强化视角/条件不变性，异地的图互相强化判别力，从而抗感知混叠。

14 个输出区域特征拼接 + L2 归一化得全局描述子（原 14×768=10752 维，PCA 到 4096 / 512）。它仍是单阶段全局检索——跨图关联发生在「特征提取」里，不是检索后重排序。数字：Pitts30k R@1 94.9、Nordland 90.7；训练仅 3.5 小时（2×RTX3090）。MulConv adapter 在 ViT 每个 block 并行插 1×1/3×3/5×5 卷积，把基础模型适配到 VPR 的局部多尺度先验。

4. SALAD：把 NetVLAD 重写成最优传输

SALAD（Sinkhorn Algorithm for Locally Aggregated Dcriptors）把 NetVLAD 的「逐行 softmax 软分配」重述为一个最优传输问题。骨干用 DINOv2-B（仅微调最后 4 层，4 epoch 即收敛）。流程：

score 矩阵

两层 FC 从零学（不初始化 k-means 质心，减归纳偏置/局部极小），加 dustbin 列吸收无信息特征。沿用 SuperGlue 的 dustbin 设计。

Sinkhorn 分配

特征质量 $\mu=\mathbf 1_n$ 在 m 个簇 + dustbin 间分配，簇容量 $\kappa=[\mathbf 1_m^\top,\,n-m]^\top$；Sinkhorn 求 $\bar P$，丢 dustbin 列得 $P\in\mathbb R^{n\times m}$。

聚合（不做残差减法）

$V_{j,k}=\sum_i P_{i,k}f_{i,k}$（f 经 FC 从 768 降到 128）。拼上 global token（256 维）→ flatten + L2 得最终描述子（m=64 → 8192+256）。

反直觉结果

单阶段 MSLS-ch R@1 75.0，超两阶段 R²Former 73.0、TransVPR 63.9；latency 2.41 ms、显存 0.63 GB。训练 <1 小时。

5. 和前面课程怎么接

0011「检索被吃掉」的图像兑现

从 DBoW2（0134）的视觉词袋，到本节用 DINOv2 基础模型 + 更聪明的聚合（跨图关联 / OT），图像 VPR 已被深度学习吃得相当透。基础模型当「零件」也呼应第六季 0121 WildGS-SLAM 用 DINOv2 做动态剔除。

与 0129 SuperGlue 的 OT 区分

本季硬要求：SuperGlue 的 OT 是「匹配指派」（middle-end），SALAD 的 OT 是「描述子聚合」。本课用一张「螺丝-螺丝孔」图彻底分清——这是学习者最容易混、也最该分清的一处。

为 0139 埋伏笔

SALAD 单阶段反超两阶段 R²Former，是「聚合比重排序更关键」的最强证据；下一节 0139 会系统比较「单阶段检索 vs 检索+重排序」。

  1. 用「螺丝-螺丝孔」类比，说清 SALAD 的 OT 聚合与 SuperGlue 的 OT 匹配有何本质不同。
    展开查看答案

    SuperGlue：两张图的关键点（螺丝）去配另一张图的螺丝孔（点），代价矩阵是 N×M，目标是「谁配谁」，配不上的进垃圾桶（无匹配）——是跨图匹配。SALAD：一张图的局部特征（螺丝）软分配到 K 个视觉词簇（孔），代价矩阵是 n×(m+1)，目标是「分进哪类地标、压成一个向量」，无信息的进垃圾桶——是聚合。同叫 Sinkhorn+dustbin，但一个是 feature↔feature、一个是 feature→cluster，目标根本不同。

  2. CricaVPR 的「跨图像关联」发生在流程的哪一步？它和「检索后重排序」是一回事吗？
    展开查看答案

    发生在特征提取阶段：把 batch 内所有图的「第 i 个区域特征」串成序列送 cross-image encoder，让每个区域特征生成时借同批其他图的信息。它不是检索后的重排序——检索阶段仍是单图全局特征最近邻。所以它仍是单阶段全局检索，只是特征本身被「批内互看」增强了。

  3. 为什么 SALAD 单阶段能反超两阶段 R²Former？给出关键数字。
    展开查看答案

    MSLS Challenge R@1：SALAD（单阶段）75.0，R²Former（检索+重排序）73.0，TransVPR 63.9。SALAD 用「DINOv2 微调末 4 层 + OT 聚合 + dustbin 丢无信息特征」把描述子本身做得极好，使得「好的聚合」比「检索后再重排序」更关键；且它 latency 仅 2.41 ms、显存 0.63 GB，远轻于 R²Former 的 8.88 ms / 202 ms。说明 2024 年聚合质量压过了重排序。

  4. SALAD 相比 NetVLAD，除了「换成 OT」还有哪两处改动？
    展开查看答案

    ① 引入 dustbin 列吸收无信息特征（天空/路面/动态物），NetVLAD 没有；② 不做残差减法——NetVLAD 聚合的是「特征减簇中心」的加权和，SALAD 直接求和 $\sum_i P_{i,k}f_{i,k}$。此外 score 矩阵从零学、不初始化 k-means 质心，也减少了归纳偏置。

  5. 为什么 SALAD 用 DINOv2 但「只微调最后 4 层」？全微调会怎样？
    展开查看答案

    作者实测（Table 6）：训 2/4 层最佳（92.2/92.0），训 6 层 91.6，全训反而 89.2（过拟合/灾难性遗忘）。用参数高效微调（PETL adapter 思路）保留 DINOv2 预训练学到的通用视觉先验，只适配 VPR 任务，既好又快（4 epoch 收敛）。这也和 CricaVPR「冻结 DINOv2 + adapter」殊途同归。
