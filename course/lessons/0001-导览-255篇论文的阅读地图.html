本节目标

不做知识的输入，只做坐标系的建立。读完你应该能回答：SLAM 有哪几条主干？为什么必须先读综述再读方法？我这周该读哪几篇？

这门课的原材料从哪来

本课程全部内容来自本地 255 篇论文全文（PDF 已转成 Markdown 并保留了原文插图）。每一句技术判断都能回溯到原文，不做标题推断——这是本课程的硬规矩。

1. 这是一个什么规模的领域

先把体量说清楚。本地语料库按年份分布是这样的：

年份区间篇数说明
2000–201626古典时期：BA、滤波、特征法、最初的开源系统
2017–201934VIO 与激光 SLAM 爆发，ORB-SLAM2 / VINS-Mono / LOAM 系
2020–202129工程成熟期 + 神经隐式表示登场（NeRF / iMAP）
202259数量高峰：激光惯性、学习式方法、隐式建图三线并发
2023463D 高斯泼溅元年，SLAM 与高斯迅速合流

你会发现一个规律：篇数越多，说明这个方向越"卷"；但真正定义领域骨架的，永远是那些被你反复引用的少数工作。所以这套课不打算按年份平推，而是按"认知依赖关系"组织。

为什么要先读综述，而不是直接冲 ORB-SLAM

因为一篇方法论文只会告诉你"我怎么做"，不会告诉你"为什么不那样做"。而综述/教程的价值恰恰在于它替你扫过了整个战场，告诉你哪些路已经堵死、哪些坑反复有人踩。先花一周读综述，后面读方法时你会省下几十个小时。

2. 255 篇的地形图：11 个阶段

整份路线图把语料库切成 11 个阶段。它们不是按论文主题硬分的，而是按你什么时候读它最有效排的：

阶段名称篇数读完能干什么
A先建立坐标系（综述与全景）20说出主要方法家族，以及它们各自的失效场景
B打地基（数学、后端与地图表示）19手推 BA 的稀疏结构，说清预积分在解决什么
C视觉主干（特征法 / 直接法 / VIO）42理解特征法与直接法的根本分歧，以及 VIO 为什么必须存在
D激光主干（从 LOAM 到 Point-LIO）32讲清 ikd-Tree 与普通 k-d 树的区别，说清"不提特征"为什么是进步
E多传感器融合（激光 + 视觉 + 惯性）9理解"统一场景表示"这个趋势，说出紧耦合与松耦合的取舍
F前沿：神经隐式与 3D 高斯39讲清"隐式 vs 显式"的根本差别，以及高斯为什么快、又卡在哪
G学习式方法（匹配 / 检索 / 端到端）31知道深度学习在 SLAM 里能做什么、不能做什么
H专题支线（动态 / 语义 / 多机 / 事件）42在你选的那条线上知道 SOTA 是谁、瓶颈在哪
I数据集与评测5知道每个数据集测什么、真值精度到什么级别
J基础零件（非 SLAM，但论文里反复出现）11看到 ResNet / Mask R-CNN 这些名词不陌生
K应用与相邻领域5知道 SLAM 在整个机器人系统里的位置

三个阶段之间的关系，可以用一句话串起来：

$$ \underbrace{\text{A 建立坐标系}}_{\text{知道有什么}} \rightarrow \underbrace{\text{B 打地基}}_{\text{知道怎么算}} \rightarrow \underbrace{\text{C / D 两条主干}}_{\text{知道怎么做}} \rightarrow \underbrace{\text{E 融合 + F 前沿}}_{\text{知道往哪走}} $$

而 G / H / I / J / K 是横切面：它们不属于某一条主干，而是会反复出现在你读主干论文的过程中。所以它们的正确读法是"遇到再回来补"，而不是从头背一遍。

难度与重要性，分别代表什么

难度 ★ ~ ★★★

衡量的是对读者预备知识的要求，不是论文质量。★ = 看懂概念即可；★★ = 需要一点几何/优化基础；★★★ = 建议先读完"打地基"那部分。

重要性 ● ~ ●●●

● = 扩展（知道有这么个东西就行）；●● = 推荐（该方向入门的代表作）；●●● = 必读（不理解它，后面会一直卡）。

为什么这么设

因为"难"和"重要"是两个独立维度。很多必读论文（如 KISS-ICP）其实很浅显；而一些 ★★★ 的论文（如连续时间建模）只是特定场景才需要。

3. 三种读法：按你能投入的时间选

同一份路线图，投入不同小时数，读法完全不同。请对号入座：

读法选择器

速览读法 · 2 小时

只读 2016 年那篇《Past, Present, and Future of SLAM》的引言与结论，加一篇你所在方向的综述的"分类图"。目标是建立名词地图——听到 SLAM / VO / VIO / LIO / 回环 / BA 时不慌。不要在细节上停留。

系统入门读法 · 2 周

阶段 A 全读（约 3 天）→ 阶段 B 挑 ●●● 读（BA、图优化、预积分、KinectFusion，约 4 天）→ 选一条主干读（视觉选 C，激光选 D，约 5 天）→ 回头看你自己课题相关的专题（约 2 天）。

研究型读法 · 长期

阶段 A + B 打底 → 主干按年份顺序精读，每篇都问"它解决了上一篇的什么问题" → 阶段 F（隐式与高斯）当作课题前沿侦察 → 用阶段 H 选一条支线深挖到 SOTA。此时要开始动笔写综述式笔记。

一条贯穿全课的方法论

每读完一篇，请在笔记里写三行：① 它要解决谁的痛点？② 它的核心机制一句话是什么？③ 它的失效边界在哪？第三行最容易漏，但恰恰是决定你能不能做创新的那一行。

4. 路线图勘误：有两篇被归错了类

在逐篇核对正文标题时，我们发现了路线图里的两处错误。按本课程的规矩，不掩饰、按事实修正，并在这里公开记录：

路线图原标注实际正文标题处理方式
"LiDAR SLAM 综述（2022）· 激光方向的权威综述" Lidar-based Simultaneous Localization and Mapping in Dynamic Environments（Feng, Fu, Liao，重庆大学） 它不是综述，而是一篇讲动态环境激光 SLAM 的方法论文。本课按真实内容处理，不再充当"激光综述"。
"地下环境感知逻辑综述（2022）" Beyond Dents and Scratches: Logical Constraints in Unsupervised Anomaly Detection and Localization 这是工业图像异常检测论文（MVTec LOCO AD 数据集），与 SLAM、机器人、点云均无关。属于误下载，本课不予采用。

这件事本身值得学一句

连"论文库里的一篇"都可能被文件名骗到——文件名写 Survey 不代表它是综述。这就是为什么本课程宁可多花时间逐篇开正文，也不肯凭标题写一句结论。做文献调研时，把"核实"当成默认动作，而不是补救动作。

还有三处元数据不一致，一并提醒

  • 2024_DeepSLAM-Survey 的文件名写 2024，但正文是 2023 年 IEEE Access 的《Deep Learning Techniques for Visual SLAM: A Survey》。本课按正文标 2023。
  • 2020_EventSLAM-Survey 的文件名写 2020，但正文投稿时间 2024、出版 2026，参考文献最新到 2025。本课按正文标"2024 投稿"，并注明文件名冲突。
  • 2024_Recent_advances_in_3D_Gaussian_splatting 这个 Markdown 文件里混入了一个空字节，部分工具会把它判为二进制而读不出内容——需要先过滤 \0 再读。

课后练习

  1. 为什么本课强调"要先读综述再读方法论文"？请用"失效边界"这个角度解释。
    展开查看答案
    方法论文的写作目的是证明"我的方法更好"，因此它天然只呈现自己能赢的场景。而综述/教程会横向对比多个方法家族，明确指出每一类的适用条件与失效场景。先拿到这张"边界地图"，你在读方法论文时才能立刻定位：它是在哪个赛道上赢的？换到别的场景还成立吗？
  2. 路线图把"难度"和"重要性"分成两个独立维度。请各举一篇"高难度但非必读"和"低难度但必读"可能的论文类型。
    展开查看答案
    高难度但非必读：例如连续时间建模类论文（2022 连续时间 vs 离散时间、2022 连续时间弹性估计）——数学门槛高（★★★），但只有高速运动、卷帘快门等特定场景才必须用。低难度但必读：例如 KISS-ICP（2023，★）——它几乎是"反工程化"的极简方案，但重新定义了"激光里程计最少需要什么"，属于改变认知的必读。
  3. 如果你发现某篇论文的文件名与正文内容不一致，正确的处理流程是什么？
    展开查看答案
    ① 打开正文核实真实标题与主题，不做任何标题推断；② 判断它是"命名错误"（内容对、名字错）还是"误下载"（内容与专题无关）；③ 命名错误则按正文修正标注，并在勘误表记录；④ 误下载则从该专题的素材池中剔除，并标注原因，避免以后又被误用。核心原则：以正文为准，且把修正过程显式记录下来。
