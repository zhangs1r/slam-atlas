1. 题眼：动态物体在稠密地图里长出整块幽灵

先立一个必须讲透的观点——它是本节的灵魂：

★ 本节题眼

在稀疏特征 SLAM 里，一个移动的人只会污染「落在他身上的那几个特征点」——代价是局部的、有限的。但在稠密 / 隐式表示里，动态物体造成的不是「几个坏特征」，而是整块「幽灵几何」：因为地图是连续场，动的人会在他走过的每一处都留下一串半透明的残影，最终糊成一大片虚假结构。

第三季 0068 课讲的「动态环境五篇」还停留在稀疏特征被污染；本季进入稠密隐式，代价升级了——从「几个点不可信」变成「一整片几何在撒谎」。这正是为什么下面三篇要专门对付它。

2. DytanVO：纯学习式 VO，动态 = 掩码

DytanVO（2023，IROS）是三篇里最「激进」的一个：它是纯学习式 VO，没有显式地图。三个网络——匹配网络（PWC-Net 光流）、位姿网络（ResNet50）、运动分割网络（U-Net）——迭代联合精化，3 次迭代就够。

★ 诚实标注

DytanVO 是纯学习式、没有显式地图。它输出的是位姿序列 + 运动掩码，不是一张持久地图。所以它对付动态的方式是「根本不建那块地图」——直接把动态区域从位姿解算里屏蔽掉。

用 0068 的三层框架套：

环节 DytanVO 怎么做的
判定依据运动分割网络给出的「动态性概率掩码」
处理方式掩码加权位姿（在「无动态运动」的光流上估位姿）+ 三者联合精化迭代
代价分割 / 位姿联合损失；当前景运动占约 80% 且背景无纹理时会发散

亮点：zero-shot 直接泛化到 KITTI / AirDOS-Shibuya（不微调），ATE 平均比次优 VO 提升 27.7%；RTX 2080 上 3 次迭代约 160 ms。它是「唯一在拥挤行人场景保持追踪的学习式 VO」。

3. RoDyn-SLAM：RGB-D NeRF 上的动态掩码闸门

RoDyn-SLAM（2024，ICRA）是三篇里唯一在隐式场层面去动态的。它用 RGB-D 输入 + NeRF 隐式地图（多分辨率哈希网格）做稠密动态 SLAM。鲁棒性来自一道「动态掩码闸门」：让移动物体既不污染地图、也不拖垮位姿。

用 0068 框架套：

环节 RoDyn-SLAM 怎么做的
判定依据光流掩码 + 语义掩码融合成运动掩码（迭代优化光流掩码去噪）
处理方式只对在静态区域的光线采样 / 反向传播（动态光线被过滤）+ 分治位姿优化（关键帧 / 非关键帧分开）
代价多损失加权（SDF/深度/颜色/edge warp）；语义掩码仅覆盖预定义类别，未定义类别动态漏检

它在 BONN / TUM RGB-D 动态序列上优于基线，重建网格无 floaters（漂浮物）。这是本季模块「隐式 + 动态」的正面答案之一——和上一课 Orbeez（静态世界）正好对照：Orbeez 不处理动态，RoDyn 专门处理。

4. OVD-SLAM：特征点层面的语义加权（标题 OVD 实为 YOLOv5）

OVD-SLAM（2023，IEEE Access）走的是第三条路：在经典 ORB-SLAM3 之上做动态鲁棒。它的地图是显式稀疏点云（不是隐式），给每个点加一个动态权重。

★ 必须如实写：标题 OVD，正文只用 YOLOv5

OVD 这个缩写通常暗示 Open-Vocabulary Detection（开放词汇检测），但正文实际只用 YOLOv5 固定类别检测器（Fig.1/Fig.2 明确写「bounding boxes obtained by YOLOv5」）。全篇未使用开放词汇检测。标题有误导，讲解时必须向学生点明「名不副实」。

用 0068 框架套：

环节 OVD-SLAM 怎么做的
判定依据YOLOv5（语义）+ 深度聚类 + 光流，判定哪些框含动态物体
处理方式对每点优化权重降动态影响 + 恢复移动物体上的静态点（用平均重投影误差筛选）
代价重投影误差；依赖 YOLOv5 预定义类别，未知类别动态漏检

它在 TUM RGB-D、Bonn 动态序列上优于 ORB-SLAM3；真实高动态环境（Fig.7）ORB-SLAM3 明显漂移，本文贴近真值。和 RoDyn 形成「同目标两条技术路线」对照：RoDyn 在隐式场层面去动态，OVD 在特征点层面去动态。

三篇恰恰印证了 0012——它们分别占据「无地图学习式 / 隐式场 / 显式点云」三种表示，没有谁在所有场景通吃。DytanVO 快且泛化好但无地图、依赖训练域；RoDyn 在隐式场去动态最干净但受 RGB-D 与预定义语义限制；OVD 工程实用但受 YOLOv5 类别束缚。所以 0012 的判断在稠密 / 隐式时代依然成立：动态鲁棒仍无单一最优解，选哪条路取决于传感器与场景。

课后练习

  1. 本节题眼说「动态物体在稠密地图里长出整块幽灵」。这和第三季 0068 讲的「稀疏特征被污染」有什么本质区别？
    展开查看答案

    0068 是稀疏特征时代：移动的人只污染落在他身上的几个特征点，代价是局部、有限的。本季进入稠密 / 隐式表示：地图是连续场，动态物体会在他走过的每一处都留下半透明残影，最终糊成一大片虚假结构——代价从「几个点不可信」升级成「整块几何在撒谎」。这就是题眼的核心。

  2. DytanVO 是哪种类型的方法？它有没有显式地图？动态怎么处理？
    展开查看答案

    它是纯学习式 VO，没有显式地图。输出位姿序列 + 运动掩码，不维护持久地图。动态处理：运动分割网络给出动态性概率掩码，位姿网络在「无动态运动」的光流上估位姿，三者联合精化迭代。本质是「根本不建那块动态地图」。

  3. RoDyn-SLAM 在隐式场层面怎么去动态？它的掩码由什么融合而来？
    展开查看答案

    它只在静态区域的光线上采样 / 反传，动态光线被「闸门」过滤；位姿用分治策略（关键帧 / 非关键帧分开优化）。运动掩码由光流掩码 + 语义掩码融合而来（迭代优化光流掩码去噪）。结果重建网格无 floaters。代价：语义掩码仅覆盖预定义类别。

  4. OVD-SLAM 标题写「OVD」，但正文实际用了什么？为什么必须如实点明？
    展开查看答案

    正文实际只用 YOLOv5 固定类别检测器（Fig.1/Fig.2 写明 bounding boxes obtained by YOLOv5），全篇未使用开放词汇检测。OVD 通常暗示 Open-Vocabulary Detection，标题有误导。必须点明，是为了诚实——不能让学生被标题骗去以为它做了开放词汇检测。

  5. 第一季 0012 说「没有任何单一方法被证明普遍更优」。本季这三篇是否推翻了它？给出你的判断。
    展开查看答案

    我们的判断（非原文自评）：没有推翻，反而印证了。三篇分占「无地图学习式 / 隐式场 / 显式点云」三种表示，各有边界——DytanVO 受训练域限制、RoDyn 受 RGB-D 与预定义语义限制、OVD 受 YOLOv5 类别束缚。没有谁通吃所有场景，所以 0012 的判断在稠密 / 隐式时代依然成立：动态鲁棒仍无单一最优解，选择取决于传感器与场景。
