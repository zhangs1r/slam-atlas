1. 一句话定位：让层学「差」，而不是学「答案」

先给结论，一句话：ResNet 只改了一件事——给网络加一条「恒等短路」（identity shortcut），把「直接学目标映射 H(x)」改成「学残差 F(x) = H(x) − x」。就这一条改动，让网络可以从 34 层一路堆到 152 层，并且越深越好。

为什么这么改有用？先用一个生活类比。假设你要预测某个人今年的体重。直接猜一个绝对数字（比如 70 公斤）很难——你得知道他的身高、饮食、运动量。但如果改成猜「比去年多了多少」，事情立刻简单了：答案通常在 0 附近，最多 ±3。而如果根本没变化，答案就是 0——「什么都不做」是一个极容易命中的答案。

ResNet 干的就是这件事：它不让层去拟合「最终答案」，而是让层去拟合「答案与输入的差」。当「什么都不做」（也就是恒等映射）才是最优解时，网络只需要把这几层的权重推向 0 就行——原文的说法是「the solvers may simply drive the weights of the multiple nonlinear layers toward zero」，这比让一堆非线性层去辛辛苦苦凑出一个恒等映射容易得多。

这一句话就是全课的核心。下面我们分三步把它讲透：前人卡在哪（§2）→ 它改了什么（§3）→ 怎么算（§4）。

2. 它之前的人怎么做、卡在哪：加深为什么不管用了

上一课我们看到，2014 年之后的主流思路是「堆」：VGG 把 3×3 小卷积一层层往下堆，GoogLeNet 把 Inception 模块一层层往下堆。这条路有大量证据支持——原文开头就说，ImageNet 上的领先结果全部是「very deep」模型，深度从 16 层到 30 层不等。于是问题自然变成：那就继续往上堆啊，堆到 100 层、200 层不行吗？

第一步：先排除一个老嫌疑犯——梯度

历史上，加深的第一道坎是梯度消失 / 梯度爆炸（vanishing / exploding gradients）：梯度在反向传播时一层层衰减或放大，网络从一开始就训不动。但原文明确说，这个问题「到 2015 年已经基本被解决了」：原文用的词是「has been largely addressed by normalized initialization and intermediate normalization layers」——也就是好的初始化 + 中间的归一化层（BN，Batch Normalization），它们让几十层的网络能正常收敛。

这一条极其重要，别记错

ResNet 要解决的问题不是梯度消失。梯度问题已经被 BN 与初始化基本解决了。ResNet 面对的是一个更新的、更诡异的问题——退化。

第二步：真正的敌人——退化（degradation）

原文的原话是：「with the network depth increasing, accuracy gets saturated ... and then degrades rapidly」——精度先饱和，然后急速下降。而真正反直觉的是它的判据：

Unexpectedly, such degradation is not caused by overfitting, and adding more layers to a suitably deep model leads to higher training error.

这句话在说什么：① 这个句子在说「退化不是过拟合」——过拟合的症状是训练误差低、测试误差高；而退化是连训练误差都变高了；② 为什么这一点致命——如果只是过拟合，加数据、加正则就能救；但训练集本身都学不好，说明问题出在优化上，数据再多也没用；③ 具体数字：原文 Figure 1 给出 CIFAR-10 上 56 层 plain 网络的训练误差比 20 层更高；Figure 4 给出 ImageNet 上 34 层 plain 网络的训练误差全程高于 18 层。也就是说：网络变深了，它连「把训练集记住」这件事都做得更差了。

下面这张原图就是那个判据本身。请特别注意：它画的是「训练误差」，不是测试误差——这正是「不是过拟合」的证据。

第三步：作者是怎么论证「深层不该更差」的

原文有一个非常漂亮的论证，值得单独讲。它说：考虑一个浅层网络，再考虑一个在它后面又加了几层的深层网络。这个深层网络天然存在一个解——新增的那几层学成恒等映射，其余层直接照抄那个浅层网络。所以「the solution space of the 18-layer plain network is a subspace of that of the 34-layer one」——18 层的解空间是 34 层解空间的一个子集。

结论就很硬了：既然深层网络的解空间更大、而且包含了浅层的最优解，那么它的训练误差理论上不可能更高。可实验偏偏显示更高——所以唯一的解释是：现有的求解器（SGD）找不到那个解。

这三步走完，问题的形状就清楚了：不是梯度的问题（已被 BN 解决），不是容量的问题（深层容量更大），也不是过拟合（训练误差都高），而是「优化难」的问题。ResNet 的整个设计，就是冲着「让那个恒等解变得容易找」去的。

原文在相关工作里还把这件事的思想源头拉到了很远的领域——multigrid 偏微分方程求解与 hierarchical basis 预处理，并总结成一句极凝练的话：「a good reformulation or preconditioning can simplify the optimization」（一个好的重述或预处理可以简化优化）。残差连接就是一种「重述」。

3. 核心机制：一条抄近道的箭头

知道了问题，解法就一句话：加一条恒等短路（identity shortcut）。

原来的目标是让几层去拟合目标映射 H(x)。现在改成：让这几层去拟合残差映射 F(x) := H(x) − x，于是原来的映射被重写成 F(x) + x。原文对这一步的动机说得非常直白：

We hypothesize that it is easier to optimize the residual mapping than to optimize the original, unreferenced mapping.

这句话在说什么：① 这个句子在说「学差值比学绝对值容易」——和我们上面那个体重的类比是同一件事；② 为什么——因为当恒等映射才是最优解时，残差形式只需要把权重推向 0（原文：drive the weights of the multiple nonlinear layers toward zero），而原始形式需要让一堆非线性层精确地凑出恒等映射，这几乎不可能；③ 具体到数：假设某一层的理想输出就是输入（恒等），那么残差形式的目标是让 F(x) 的输出接近 0，也就是损失函数的目标值从「一个几千维的任意向量」变成「全零向量」——目标从「随便一个点」变成「原点」，这是优化难度上的本质差别。

还有一件必须强调的事：这条短路是「免费」的。原文原话：「Identity shortcut connections add neither extra parameter nor computational complexity」——不加参数、不加计算量。这也是为什么它能被那么广泛地复用：你几乎可以在任何网络里插一条，不会变慢、不会变大。整个网络仍然可以用 SGD 端到端训练，而且「can be easily implemented using common libraries without modifying the solvers」。

几个实现细节，都来自原文：

  • 相加是逐通道的。原文说这个加法「performed on two feature maps, channel by channel」——注意这里和上一课 GoogLeNet 的「通道维拼接」完全不同：拼接会让通道数变多，相加不会。这个区别是区分 Inception 与 ResNet 的唯一门槛。
  • 非线性在加法之后。原文写作 σ(y)，也就是「加完再 ReLU」。这个位置反了效果就不同。
  • BN 的位置不在公式里。Eqn.(1)(2) 里没有写 ReLU 与 BN，BN 的位置在正文 §3.4 的文字里：「right after each convolution and before activation」——每个卷积之后、激活之前。
  • 维度不匹配时用投影。如果输入输出通道数变了（原文里通常是每换一个 stage 通道数翻倍），就要用 W_s 做线性投影，一般用 1×1 卷积实现。

4. 公式与形状账：y = F(x) + x 到底在算什么

原文给了两个式子。第一个是同维度的标准形式，第二个是维度不匹配时的形式。

$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x} \tag{1}$$
$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + W_s\,\mathbf{x} \tag{2}$$

这句话在说什么：① 这两个式子在算「一个残差块的输出」——把「堆叠层的输出 F」和「输入本身 x」加在一起；② 为什么这么算——因为要让网络在「什么都不用做」的时候能轻松输出 x（F 置零即可），从而保证深层网络的训练误差不会比浅层更差；③ 逐符号说明：x 是这个块的输入特征图，y 是输出，F(x, {W_i}) 是那几层堆叠要学的残差映射（{W_i} 是它们的权重），+x 由短路实现，W_s 只在输入输出维度不一致时才用（原文：「W_s is only used when matching dimensions」），一般用 1×1 卷积实现；④ 别忘了：Eqn.(1)(2) 里都没写 ReLU 与 BN，BN 的位置在正文文字里。

原文还给了 F 的最简形态：以两层为例，F = W₂σ(W₁x)，其中 σ 是 ReLU，而且偏置项被省略了——原文的说法是「the biases are omitted for simplifying notations」。这只是为了写法干净，不代表实际实现里没有偏置。

形状账一：两个 3×3 的基本块

先看最基础的形态。假设我们处在某个 stage 里，特征图是 56×56×64（高 56、宽 56、64 个通道）：

  • 第一个 3×3 卷积：输入 64 通道、输出 64 通道 → 参数量 3×3×64×64 = 36864；空间尺寸不变，仍是 56×56×64。
  • 第二个 3×3 卷积：同样 3×3×64×64 = 36864；输出仍是 56×56×64。
  • 短路这条路的参数量：0。它的输入是 56×56×64，输出也是 56×56×64，形状完全一致，所以直接相加即可。

于是这个块一共学 73728 个权重，形状从 56×56×64 进、56×56×64 出。如果短路要换成投影呢？那就得多学一个 1×1×64×64 = 4096 的矩阵——虽然不多，但这正说明：形状一致时短路才是真正免费的。

形状账二：瓶颈（bottleneck）结构为什么更省

ResNet-50/101/152 用的不是上面那个两层块，而是一个三层块：1×1 → 3×3 → 1×1。原文说它的由来是算力，不是精度——原话是「Because of concerns on the training time that we can afford, we modify the building block as a bottleneck design」。人话：这样改是为了能在可承受的时间里训完，不是因为这样更准。它的账是这样的（以 ResNet-50 的一个块为例）：

  • 1×1 卷积把通道从 256 压到 64：参数量 1×1×256×64 = 16384；空间尺寸不变。
  • 3×3 卷积在 64 通道上做：参数量 3×3×64×64 = 36864；空间尺寸不变。
  • 1×1 卷积把通道从 64 升回 256：参数量 1×1×64×256 = 16384。
  • 合计 69632，约 70k——而块的整体形状仍然是 256 通道进、256 通道出。

对比一下：如果不用瓶颈，直接在 256 通道上放两个 3×3，参数量是 2×3×3×256×256 = 1179648，约 1.18M——是瓶颈结构的约 17 倍。这就是「先变窄、算完再变宽」的全部价值。（顺带说明：这三个数 16384 / 36864 / 16384 与本课算出的 70k，和 ResNeXt 那篇论文用来做复杂度对齐的算式完全一致，下一课 0189 会直接复用这个数。）

还有一条原文单独强调过的账：在瓶颈结构里，如果那条恒等短路被换成投影，代价会翻倍——因为短路要接在两个高维端（256 与 256）上。原文原话是「the time complexity and model size are doubled」。这也解释了为什么作者宁可接受「用补零 + 恒等」或「只在必要时才投影」，也不愿到处加投影。

6. 它在前八季的哪些课、哪些方法里出现过

这一节是本季的硬要求。结论先给：在这五篇骨架论文里，ResNet 是本语料库中被引用密度最高的一个，而且用法几乎全是「当主干 / 当位姿网络」这种工程角色。也就是说，读者最常撞见的不是「ResNet 论文」，而是「ResNet-50 backbone」这句话。下面是逐条原句。

① CNN-SLAM（2017）：把 ResNet-50 拆开当前半段

这是 SLAM 里最典型的一处。原文说：深度预测架构「based on the extension of the Residual Network (ResNet) architecture [9] to a Fully Convolutional network」，其中「the first part of the architecture is based on ResNet-50 [9] and initialized with pre-trained weights on ImageNet」，而「The second part ... replaces the last pooling and fully connected layers originally presented in ResNet-50 with a sequence of residual up-sampling blocks」，最后输出一张单通道的深度图。这就是「骨干被当积木拆用」的范本：前半段照抄，后半段整个换掉。

② TartanVO（2021）：ResNet-50 直接当位姿网络

原文：「We utilize the pre-trained PWC-Net [40] as the matching network, and a modified ResNet50 [41] as the pose network. We remove the batch normalization layers from the ResNet, and add two output heads for the translation and rotation, respectively.」推理时间 40 ms（NVIDIA GTX 1080）。注意它改了两处：去掉 BN、加两个输出头——这就是「把分类骨干改造成位姿回归器」的标准动作。

③ LoFTR（2021）：ResNet-18 当特征主干

「The local feature CNN uses a modified version of ResNet-18 [12] as the backbone.」整个模型端到端训练、随机初始化，640×480 的图像对在 RTX 2080Ti 上跑 116 ms。这是「小号残差网络当特征提取器」的典型，也说明了为什么 ResNet 家族要提供 18 / 34 / 50 / 101 / 152 这一串不同档位。

④ DytanVO 与 BEVPlace

DytanVO 的位姿网络「with ResNet50 [33] as the backbone」；BEVPlace 做 LiDAR 地点识别时「implemented two NetVLAD networks with ResNet34 and ResNet18 as backbones」。注意 BEVPlace 这一条：点云先投成 BEV 图，再交给残差网络——残差网络不挑输入是图像还是「压扁的点云」。

⑤ PanopticFusion（2019）：两个残差主干并排

它同时用了两个：「We employed ResNet-50 for the backbone of PSPNet」（语义分支，用 ADE20K 预训练权重）与「We leveraged ResNet-101-FPN for the Mask R-CNN's backbone」（实例分支，用 MS COCO 预训练权重）。一个系统里并排放两个不同规格的残差主干——这正是「骨干是可替换零件」的最强证据。

⑥ Mask R-CNN（2017）：连命名规则都是它定的

原文：「We denote the backbone architecture using the nomenclature network-depth-features. We evaluate ResNet [15] and ResNeXt [35] networks of depth 50 or 101 layers. This backbone with ResNet-50, for example, is denoted by ResNet-50-C4.」「骨干-深度-特征层级」这个命名法一直用到今天，而它同时把 ResNet 与 ResNeXt 并列成可选件——这正是下一课 0189 的引子。

还有一个用法很特别：它被当成「教师」。2022 年一篇论文把「a ResNet-18 classifier trained on ImageNet」的知识蒸馏到一个稠密描述子网络里。也就是说残差网络在这个语料库里既当学生、当主干、也当老师。

归纳一句：读者在 SLAM 论文里见到 ResNet 的场合，绝大多数不是「它提出了什么新结构」，而是「我把骨干换成了 ResNet-XX」或者「我用 ResNet-XX 当位姿/特征网络」。而这句话里最关键的信息其实不是 ResNet，是「XX」那个数字——18 / 34 / 50 / 101 决定了速度与精度的档位，也决定了它能不能塞进 33 ms 的预算里。

7. 它不完美在哪：所以 SLAM 要加几何约束

本季的第二个硬要求：每个零件都要讲它的毛病。ResNet 的毛病里，最值得讲的一条是「作者自己也没搞清楚」。

毛病一：退化的真正原因没查清

原文第 137 行原话：「We argue that this optimization difficulty is unlikely to be caused by vanishing gradients ... We conjecture that the deep plain nets may have exponentially low convergence rates ... The reason for such optimization difficulties will be studied in the future.」人话：他们只是提出了一个猜想（收敛率指数级偏低），并明确说原因留待将来研究。残差连接是一个有效的解法，但它当时并没有被给出完整的理论解释。

毛病二：深过头就反转

110 层 CIFAR-10 错误 6.43%，1202 层反而 7.93%——训练误差低到 0.1% 以下，测试误差却更差。作者归因于过拟合，并承认仍是「open problems on such aggressively deep models」。所以「越深越好」是有上限的，不是无限的。

毛病三：那个投影短路其实并不必需

原文比较了三种短路方案（A 补零恒等 / B 投影 / C 全投影），结论是 C 只是「marginally better」，而且这点增益来自额外参数，于是为了省内存干脆不用 C。原文还坦言：「投影 shortcut 对解决退化并非必需」。换句话说，整套方法的核心就是那条零参数的恒等短路。

毛病四：CIFAR 上的结论有自我限定

原文说 CIFAR 实验「we use no maxout/dropout and just simply impose regularization via deep and thin architectures by design, without distracting from the focus on the difficulties of optimization」——他们是故意不做最强正则的，为的是不干扰对优化问题的观察。所以 CIFAR 那组数字不代表这套结构能打到的上限，别拿它当性能排名。

现在把这些毛病接回 SLAM。有三条链路非常直接。

  • 第一，它是为分类设计的，「位置」这件事并不是它的强项。ResNet 的 stage 一步一步把空间尺寸降下去（典型的输出 stride 是 32），也就是特征图上一个像素对应原图的 32×32 区域。这对「这张图是什么」够用，对「物体的边界在哪」就太粗了。所以 SLAM 用它当骨干时，边界精度天生是短板——这正好呼应第八季 MaskFusion 抱怨 Mask R-CNN「边界不精」，那条抱怨的物理根源就在这里。
  • 第二，它的输出是特征，不是几何。CNN-SLAM 之所以要把 ResNet-50 的后半段整个换成上采样，就是为了把「分类特征」重新变回「逐像素的深度」；TartanVO 之所以要拆掉 BN、加两个输出头，就是为了把「分类器」改造成「位姿回归器」。这些改造不是优化，是必需的翻译。
  • 第三，即使改造成功，它给出的仍然是统计预测。网络预测的深度或位姿，没有几何一致性保证——它可能在纹理弱的地方糊掉、可能尺度漂移、可能被动态物体带偏。所以 SLAM 必须把几何约束加回来：多视图的对极几何、光束法平差（BA）、点云配准（ICP）。ResNet 提供的是「先验」，几何提供的是「硬约束」，两者缺一不可。

更具体一点：TartanVO 的位姿网络推理要 40 ms——已经吃掉了一整帧的预算（30 Hz 是 33 ms，见导览课那张时间预算尺）。在一个必须实时的系统里，一个 40 ms 的零件意味着别的部分几乎没有余量。这是所有「把学习式方法塞进 SLAM」的论文都要面对的真实摩擦。

「ResNet 是为了解决梯度消失才提出来的。」这句话错在哪？

8. 和前面课程怎么接

按规则点名课号。本课接的是三条线。

接 0187（上一课）

VGG 靠「堆层」变强、GoogLeNet 靠「堆模块」变强，两条路都在加东西；本课问的是：堆到一定程度堆不动了怎么办？答案不是加，是留一条退路。对照点还有一处：GoogLeNet 的多路输出是「拼接」，ResNet 是「相加」——这是 CNN 里两种最基础的多路径设计，本课把它们分清了。

接第三季 0043–0045 与 0048

ORB-SLAM 用 ORB 特征、DSO 用光度误差，都是手工设计的几何前端。本课的学习式骨干是第二条路：特征由网络学出来。两条路的对照点在于「谁来定义什么是好特征」——人，还是数据。

接第三季/第七季的 CNN-SLAM 与 TartanVO 语境

CNN-SLAM 把 ResNet-50 拆成编码器、后半段换上采样出深度图；TartanVO 用「a modified ResNet50 as the pose network」。这两条是本课最硬的落地证据——它们证明「骨干是被当积木拆用的」。

接第八季 0153–0159 动态环境块

那一块抱怨 Mask R-CNN「边界不精、跑不到帧率」。本课给出了这条抱怨的物理根源：残差网络为了分类把空间分辨率一路降到 stride 32，边界精度天生吃亏；而 40 ms / 116 ms 这类耗时说明帧率也不是它的强项。所以第八季才要发明「语义当慢变量、几何当快变量」。

接第八季 0160–0167 语义建图块

语义先验进地图的那条流水线，主干正是这一类残差网络（例如 PanopticFusion 同时用 ResNet-50 与 ResNet-101-FPN）。它当时出的毛病是：只有语义没有几何，边界与尺度都不可靠——所以地图必须靠几何约束兜底。

接本季 0189（下一课）

ResNeXt 会把残差块拆掉短路做对照实验：ResNet-50 去掉残差从 23.9 掉到 31.2（+7.3），ResNeXt-50 去掉从 22.2 掉到 26.1（+3.9）。结论是「残差帮优化，聚合变换才是更强的表示」——也就是说，本课这条短路从此变成了所有后续网络的公共零件。

最后一句提醒：残差连接不是 ResNet 的专属发明，它已经变成了通用零件。下一课的 ResNeXt 直接继承它；本季 0194 的 Swin 与 PVT，每个 block 里也都有两条残差连接。读者应当把它理解为「可训练深网络的前提条件」，而不是某一篇论文的技巧。

  • 「退化」是什么现象？它的判据为什么能排除过拟合？
  • ResNet 要解决的问题是梯度消失吗？原文是怎么说梯度问题的？
  • 「18 层的解空间是 34 层的子集」这个论证，为什么能推出「深层不该更差」？
  • 写出 y = F(x) + x 并解释每一项；W_s 什么时候才用？
  • 残差连接为什么是「免费」的？它加了多少参数和计算量？
  • ResNet 的短路是「相加」，GoogLeNet 的多路是「拼接」——这个区别带来什么后果？
  • 瓶颈结构的三层是什么？参数量为什么是约 70k 而不是约 1.18M？
  • 为什么说瓶颈结构的由来是算力而不是精度？

课后练习

  1. 用本课的形状账算一算：ResNet-50 里通道数从 512 升到 1024 的那个 stage，瓶颈块的参数量是多少？如果换成两个直接在 1024 通道上的 3×3，又是多少？
    展开查看答案
    瓶颈块（1×1 → 3×3 → 1×1，中间 256 通道）：1×1×512×256 = 131072；3×3×256×256 = 589824；1×1×256×1024 = 262144；合计 983040，约 0.98M。直接两个 3×3 在 1024 通道上：2×3×3×1024×1024 = 18874368，约 18.9M——是瓶颈块的约 19 倍。结论不变：先压瘦再算，块的两端形状不动，但参数量差一个数量级。提醒：这是按卷积参数公式算的算例，不是原文表格数字。
  2. 为什么原文说「Identity shortcut connections add neither extra parameter nor computational complexity」，但 Figure 4 的图注又说「no extra parameter」这件事需要限定范围？
    展开查看答案
    因为「零参数」这个说法只对方案 A（补零恒等）成立，而 ResNet-50/101/152 用的是方案 B（投影），投影是用 1×1 卷积实现的，是有参数的。Figure 4 的对比只涉及 18 层与 34 层那一组（它们用方案 A），所以那句话在那个范围内成立。原文自己在 §3.3 给了三种方案（A 补零 / B 投影 / C 全投影）并做了实验：C 只是「marginally better」，增益来自额外参数，因此为省内存不用 C。教训：引用「无额外参数」时必须限定到 18/34 层那一组，否则会读错。
  3. 如果一篇 SLAM 论文说「我们用 ResNet-50 做特征提取，效果很好」，你会追问哪三个问题？
    展开查看答案
    ① 用到了哪一段？ResNet-50 有四个 stage，输出 stride 分别是 4/8/16/32——用 stride 32 的特征，边界精度会很粗（Mask R-CNN 用的是 C4，也就是 stride 16 那一级）；② 改了哪里？TartanVO 拆了 BN 并加双头，CNN-SLAM 把后半段换成上采样——不改的话它输出的还是分类特征，不是几何；③ 多少毫秒？在 30 Hz（33 ms/帧）的预算下，一个零件占多少是硬约束（TartanVO 是 40 ms、LoFTR 是 116 ms）。三个问题分别对应「空间分辨率 / 输出内容 / 时间预算」，正是本课讲的那三条短板。
  4. 请解释：「1202 层测试误差更差」与「56 层训练误差更高」是两件不同的事。
    展开查看答案
    前者（1202 层，CIFAR-10，测试误差 7.93% 差于 110 层的 6.43%，而训练误差低于 0.1%）是典型的过拟合：训练集学得极好、泛化变差。后者（56 层 plain 网络的训练误差高于 20 层）是退化：连训练集都学不好，所以不可能用「泛化差」解释，只能归因于优化困难。原文对两者的处理也不同：退化用残差连接解决；1202 层那一例被明确留作开放问题，作者建议「combining with stronger regularization may improve results」。混用这两个概念，就会把 ResNet 的贡献说错。
