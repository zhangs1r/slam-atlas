1. 它想解决的，是一个「通用」的难题

先讲人话。很多激光 SLAM 方法提特征的方式，是绑死在某一类雷达上的。比如有的方法先按「扫描线号」把点排成一张距离图像，再在图像上找边缘；有的方法假设雷达一圈一圈均匀扫过去。这些做法在原来的雷达上很好用，但换一台雷达就可能直接废掉——固态激光雷达视场角小、扫描线不是一圈圈的；不同线束的机械雷达，扫描模式也天差地别。

MULLS 的作者想做的，是一个跟雷达型号无关、也跟场景无关的通用前端。它的做法是：绕开「扫描线」这种依赖硬件的结构，直接从原始三维点云的几何本身下手。先把点按几何形状分成六类，再让每一类用最合身的那种「距离」去配准，三种距离一起写进同一个线性最小二乘，一次解出位姿。后端再用子图位姿图（PGO）+ TEASER 回环把长时的漂移压住。

2. ★ 多度量（multi-metric）到底指什么

「多度量」是这篇论文名字的来源，也是它最核心的一招。要理解它，先要接受一个很朴素的事实：场景里的几何不是只有一种。

想一想你站在一个街角看到的东西：脚下是一整片地面，左边是一整面墙，前面立着一根电线杆。这三样东西的「形状」完全不同——地面和墙是面，电线杆是线。传统 ICP 的做法是：用同一种距离标准去衡量所有点，比如一律算「点到点的距离」。那么结果一定是：在面上表现还行，在杆子上就吃亏。

MULLS 的观点是：既然几何有好几类，就让每一类用它最合身的那把尺子。它同时用了三把尺子：

点-点（point-to-point）

直接量「一个点和另一个点」之间的距离。原文说它用在顶点 V 上——那些高曲率、孤零零的角点，周围既没有稳定的面、也没有稳定的线，只能和最近的另一个点直接比。

原文式：$d_i^{\text{po}\to\text{po}}=\|r_i\|$。

点-面（point-to-plane）

把一个点垂直投到一个平面上，量「点到平面的距离」。原文说它用在地面 G、立面 F、屋顶 R 上——这些大片平坦的地方，用「面」来描述比用「点」稳得多。

原文式：$d_j^{\text{po}\to\text{pl}}=r_j\cdot n_j$。

点-线（point-to-line）

把一个点投到一条直线的垂足上，量「点到直线的距离」。原文说它用在柱 P、梁 B 上——细长结构用一条线来描述最自然。

原文式：$d_k^{\text{po}\to\text{li}}=\|r_k\times v_k\|$。

然后关键的一步来了：这三把尺子不是分开用三次，而是拼在一起、一次解。原文把它们写进同一个最小化目标（Eq.5），每一项带上自己的权重：

$$\{R^{*},t^{*}\}=\arg\min\sum_{\text{顶点}} w\,(d^{\text{po}\to\text{po}})^2+\sum_{\text{面}} w\,(d^{\text{po}\to\text{pl}})^2+\sum_{\text{线}} w\,(d^{\text{po}\to\text{li}})^2$$

这里要接一下第二季 0022 课：那一课讲的「点到面残差」正是上面第二项；再往上追，第二季 0019 课讲过，把残差累加成平方和、再用迭代方法求解，就是最小二乘的标准套路。MULLS 的新意不在残差形式，而在「按几何类型分配不同的残差形式，然后一次联合求解」。

最后还有一个「便宜」的好处，值得单独说，因为它解释了为什么 MULLS 快：三种残差拼好之后，可以用一次线性最小二乘直接解出位姿。秘诀是一个小角度近似——把旋转矩阵近似写成 $R\approx I+[\alpha\ \beta\ \gamma]_\times$（原文 Eq.6），其中 $\alpha,\beta,\gamma$ 都被看成小量。这样一来，残差对位姿就变成了线性的，于是设计矩阵 $A$ 和观测向量 $b$ 按三类度量拼起来（Eq.7–8），位姿就能用高斯-马尔可夫公式闭式解出：

$$\hat{\xi}=(A^{T}PA)^{-1}A^{T}Pb$$

说得直白一点：别人要反复迭代好几次非线性优化，MULLS 一次线性解就出结果。原文 Table V 里，每一次变换估计只花 0.2 ms。当然代价也是明显的——小角度近似只在「两帧之间姿态变化不大」时成立，所以它必须要有一个还算靠谱的初值。这就引出了下一节。

3. ★ 一根点云怎么被分成六类特征

要用「三种尺子」，前提是你得先知道每个点属于哪一类。MULLS 分类的方式，完全不看雷达的扫描线，只看局部点云的形状。

第一步，先把地面摘出来。原文用的是双阈值地面滤波（Eq.2）+ RANSAC：对每个点算它和所在局部区域最低点的相对高度 $h_k-h_{\min}^{(i)}$，如果这个差超过阈值 $\delta h_1$，或者它相对邻域的高度差超过 $\delta h_2$，就判为非地面。剩下的就是 地面 G。

第二步，对剩下的非地面点，取它的邻域做 PCA（主成分分析）——也就是算出这堆邻居点的协方差矩阵，再求它的三个特征值 $\lambda_1>\lambda_2>\lambda_3$。不知道 PCA 也没关系，一句话说清：

特征值在看什么

把一小撮点想象成一把撒开的沙子。特征值就是「这些点在哪个方向上铺得最开」。
① 只在一个方向铺得开、另外两个方向都很薄 → 这些点挤在一条线上 → 这是线；
② 在两个方向铺得开、第三个方向很薄 → 这些点摊在一个平面上 → 这是面；
③ 三个方向都差不多散 → 乱糟糟一团 → 这是散点（原文归为顶点一类）。

基于这三个特征值，原文定义了三个量来量化上面的直觉：

$$\sigma_{1D}=\frac{\lambda_1-\lambda_2}{\lambda_1}\quad(\text{线度}),\qquad \sigma_{2D}=\frac{\lambda_2-\lambda_3}{\lambda_1}\quad(\text{面度}),\qquad \sigma_c=\frac{\lambda_3}{\lambda_1+\lambda_2+\lambda_3}\quad(\text{曲率})$$

于是整帧点云被分成六类：

类别 中文 真实世界里是什么 配准用哪种度量
G 地面 路面、广场（由双阈值 + RANSAC 单独分出） 点-面
F 立面 墙面、围栏面 点-面
R 屋顶 房顶、雨棚一类的水平面 点-面
P 柱 电线杆、路灯杆、树干 点-线
B 梁 护栏、路缘、门框横梁 点-线
V 顶点 屋角、墙与墙交汇的尖角（高曲率、孤立） 点-点

分类完之后还有两个收尾动作：一是做 NMS（非极大抑制），二是等向下采样——目的是别让特征全挤在某一面墙上。另外还有一个细节很关键：顶点还会额外编码一个 NCC 描述子（Eq.3），这个描述子不是给前端配准用的，而是留给后端回环做候选筛选用的（见第 5 节）。

4. ★ 粗到细：两级配准，一次线性解

上一节说到，线性最小二乘只在「姿态变化不大」时成立。为了让这个近似站得住，MULLS 的前端是两级（coarse-to-fine，粗到细）的。

具体是哪两级？原文 Fig. 5(a) 写得明确：

第一级：scan-to-scan（帧对帧）

拿当前帧的稀疏特征点配上一帧的稠密特征点，只跑很少几次迭代。它的任务不是求准，而是给出一个「大概在哪」的初值——就像你出门前先看一眼大致方向。

第二级：scan-to-map（帧对局部地图）

把局部地图里的特征点当目标点云，拿第一级的估计结果当起点，一直迭代到收敛。这一级才是真正出精度的。

这里必须诚实地补一句原文的消融结论，因为它容易让人误解：原文并没有说 scan-to-scan 这一级是必需的。它在 Table II 里对比了几种配置，其中 (s1) 表示「只跑 1 次迭代的 scan-to-scan」，ATE 明显变差（平均 2.57%）；而 (s5m5)「先扫对扫 5 次、再扫对图 5 次」和 (m5)「只扫对图 5 次」表现接近。原文的原话大意是：一旦局部地图建起来了，scan-to-map 之前再做 scan-to-scan 就不必要了。所以 MULLS 最终采用的配置是「scan-to-map 迭代到收敛」。

那为什么还要保留「粗到细」这个说法？因为它描述的是整个系统层面的层级结构：前端用（可选的）帧对帧给初值、帧对图收敛；后端用 TEASER 给回环的初值、再用 map-to-map 精修。两层都是「先给个大概、再抠细节」——这才是「层级」的完整含义。

5. ★ 回环：TEASER 把重访的子图重新对齐

前端只管相邻帧，跑久了必然会漂。MULLS 的后端用分层位姿图优化（PGO）兜底。这里「分层」的意思是：子图内部先各自配准好，子图之间再连边——原文 Fig. 6 画的就是这两个层次（inter-submap 与 inner-submap）。

当机器人重访某地，后端要判断「这两个子图是不是同一个地方」，然后把它对齐。原文的流程是三步：

① 初选候选：用顶点特征编码的 NCC 描述子，算余弦相似度，挑出可能的子图对
↓
② TEASER 全局配准：对候选子图做鲁棒的全局配准，得到一个初值
↓
③ map-to-map 精修：拿 TEASER 的结果当初值，再用 MULLS-ICP 把这条子图间边精修到位，最后 PGO 把整张图拉直

这里要专门澄清一个高频误解点：经常有人以为「MULLS 的配准靠 TEASER」。不是。原文 Fig. 1(e) 和 Fig. 5(b) 都把 TEASER 放在子图与子图之间这一环，也就是后端回环；前端 scan-to-scan / scan-to-map 用的始终是多度量线性最小二乘 ICP。TEASER 在这里的角色是「鲁棒的粗配准」——原文说它用截断最小二乘估计加半定松弛，比基于 RANSAC 或分支定界的方法更高效、更抗离群点。

这也接上了第一季 0014 课（回环检测综述）。视觉 SLAM 里找回环常用词袋（BoW）——把图像描述成「词」再比对；而 MULLS 走的是另一条路：几何描述子初选 + 几何全局配准验证，不做词袋。两条路的目的一样（找到「我是不是来过」），但判据完全不同。

6. 实验数字：跨雷达、跨场景、快不快

MULLS 最大的卖点是通用。原文在 KITTI（Velodyne HDL-64E，22 个序列、4.3 万帧以上）、MIMAP 室内数据集（VLP32C 与 HDL32E）、以及 HESAI 数据集（Pandar128 / 64 / XT / QT Lite 等 4 种雷达，约 3 万帧）上做了验证，加起来是 7 类雷达、超过 10 万帧。几个关键数字如下。

还有一组消融值得记：原文 Table IV 逐项拆掉三种权重（残差伪-Huber 权重、类别间平衡权重、强度权重），ATE 都会变差；其中强度权重的影响在高速场景上尤其明显（KITTI 01 从 0.62% 掉到 0.83%）。这说明「反射强度」在这里也被当成了一种可靠度信号——把强度当额外信息的这条线，本季后面还有专门的一课。

7. 局限与诚实边界

原文自己承认的失败边界有这几条，逐条照抄，不替它遮掩：

① 结构化特征稀少时会出问题

消融实验显示：一旦缺了线性点（柱 / 梁），在高速路这类场景就会退化——因为这套方法正是靠线特征来补约束的。原文把这一点写在 Table III 的注里。

② 顶点（高曲率点）不可靠

顶点大多落在植被上，用它做配准反而会伤精度。所以原文只把顶点当作后端的关键点点（用于 NCC 描述子初选候选），不让它进前端配准。

③ ATE 指标本身有盲区

ATE 与 ARE 只在 800 m 内局部测量，体现不出回环带来的全局定位增益。这就是为什么带上回环之后 ATE 看起来「反而变差」。

④ 没有 IMU，靠匀速假设兜底

运动补偿在 IMU 不可用时退化成匀速假设（Eq.1 的 slerp 插值）。剧烈运动时，这个假设自然会不准。

一句话收束：MULLS 是「激光-only 的通用前端」——它用「六类几何特征 + 三种度量 + 一次线性最小二乘」换来了跨雷达、跨场景的通用性与速度，再用 TEASER 回环 + 分层 PGO 兜住长时漂移。它和下一节的 DLO（不提特征的直接法）、再下一节的 SuMa++（面片地图 + 语义）一起，恰好构成激光 SLAM 前端的三条不同思路。

课后练习

  1. 点-点、点-面、点-线三种度量，分别用在 MULLS 的哪几类特征上？为什么顶点只能用点-点？
    展开查看答案

    点-点 用于顶点 V；点-面 用于地面 G、立面 F、屋顶 R；点-线 用于柱 P、梁 B。

    顶点之所以只能用点-点，是因为它是高曲率、孤立的点——周围既没有稳定的平面可以投影，也没有稳定的直线可以投影，所以只能和最邻近的点直接比距离。原文 Table III 的消融还发现：顶点用在配准里反而会伤精度（它大多落在植被上），所以最终只把顶点留给后端的 NCC 描述子做候选初选。

  2. MULLS 为什么能用一次线性最小二乘解出六自由度位姿，而不是反复做非线性迭代？这个做法付出了什么代价？
    展开查看答案

    因为它用了一个小角度近似：$R\approx I+[\alpha\ \beta\ \gamma]_\times$（Eq.6），把旋转矩阵近似成「单位矩阵 + 三个小量的反对称矩阵」。这样一来，旋转就不再是三角函数，残差对位姿变成了线性的，三类度量的设计矩阵 $A$ 与观测 $b$ 可以拼在一起（Eq.7–8），位姿用高斯-马尔可夫公式 $(A^{T}PA)^{-1}A^{T}Pb$ 一次解出。

    代价是：这个近似只在「姿态变化不大」时成立。所以它必须靠一个还算靠谱的初值——这就是 scan-to-scan（给初值）与 scan-to-map（收敛）这套「粗到细」结构存在的理由。原文 Table V 显示，每一次变换估计只花 0.2 ms，省下来的时间正是靠这个近似。

  3. MULLS 里「粗到细」具体指哪两级？原文的消融实验对其中一级给出了什么结论？
    展开查看答案

    在原文 Fig. 5(a) 的描述里，前端是：先用 scan-to-scan（当前帧的稀疏特征点 ↔ 上一帧的稠密特征点，只跑少数几次迭代）给出一个初值，再把它交给 scan-to-map（当前帧 ↔ 局部地图，迭代到收敛）。

    但原文 Table II 的消融给出了一个容易被忽略的结论：一旦局部地图已经建起来，scan-to-map 之前再做 scan-to-scan 就不是必需的。证据是 (s5m5) 与 (m5) 表现接近，而只用 1 次 scan-to-scan 的 (s1) 明显变差（ATE 均值 2.57%）。因此 MULLS 最终采用的配置是「scan-to-map 迭代到收敛」。

    放到整个系统看，「粗到细」还有第二层含义：后端回环里，TEASER 当粗配准、map-to-map 的 MULLS-ICP 当精修。

  4. TEASER 在 MULLS 里出现在哪一步？在它之前还要靠什么先挑出候选？
    展开查看答案

    TEASER 出现在后端回环这一环，具体是「重访子图之间的全局配准」（对应原文 Fig. 1(e) 与 Fig. 5(b)）。

    在它之前，系统会先用顶点特征编码出的 NCC 描述子（Eq.3）做余弦相似度比较，挑出可能的子图对作为候选；然后 TEASER 对这些候选做全局配准、给出初值；最后用 map-to-map 的 MULLS-ICP 把这条子图间边精修到位，并算出信息矩阵，配上阈值筛掉质量差的边，最后交给 PGO。原文特别说明：TEASER 用截断最小二乘估计 + 半定松弛，比基于 RANSAC 或分支定界的方法更高效、更鲁棒。

  5. 把 MULLS 和第二季 0023 课的 PCL 对比，「多度量」到底「多」在哪里？
    展开查看答案

    PCL 里的 ICP / GICP / NDT，是对整片点云使用同一种度量：ICP 用点-点，GICP 用平面-平面的分布匹配，NDT 用网格内的概率分布。

    MULLS 的升级有两层：① 先把点按几何形状分成六类（地面 / 立面 / 屋顶 / 柱 / 梁 / 顶点）；② 再给每一类分配最合身的度量（点-面 / 点-线 / 点-点），三类带权重联合最小化。所以「多」体现在两点上——度量本身的多样性，以及度量与几何类型之间的分配关系。这也是它在不同雷达、不同场景下都能用的原因。
