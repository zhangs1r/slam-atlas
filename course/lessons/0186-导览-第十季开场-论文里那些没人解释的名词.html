1. 开场：你是不是也跳过了一堆词？

先说实话。前十季我们读了两百多篇 SLAM 论文，其中绝大多数你都跳过了一些词。不是你没认真读——是作者根本没打算解释。下面这些话，你几乎一定见过，而且几乎一定跳过了：

  • 「我们用 ResNet-18 当 backbone 提取特征。」——backbone 是什么？为什么是 18？
  • 「Mask R-CNN 用来分割动态物体。」——R-CNN 是什么？前面的 Mask 加的是什么？
  • 「检测精度达到 mAP 42.5。」——mAP 是平均了什么？IoU 阈值取多少？
  • 「我们用 focal loss 缓解正负样本不平衡。」——为什么会有不平衡？换掉它会怎样？
  • 「RoIAlign 相比 RoIPool 提升了掩码精度。」——这两个词差在哪？

关键在于：这些词没有一个是 SLAM 概念。它们是计算机视觉与深度学习里的通用零件，SLAM 论文只是把它们拿来用。但正因为是通用零件，作者默认读者已经会了，于是正文里一个字都不解释——你就这么跳过了一年。

这一季就是来还这笔账的。本季 11 篇论文里没有一篇是 SLAM 论文，全是 CV / DL 的通用零件（骨干网络、检测头、分割头、硬件）。它们不产生任何 SLAM 方法，但前八季的论文里到处在引用它们。所以我们把这一季的性质讲清楚：

不是续接季

不讲「一条技术演进的下一站」。本季没有一条 SLAM 主线，只有一堆零件。

不是支线季

不讲「横切在哪、拆掉了什么假设」。零件不拆假设，零件只是被人拿来用。

是补名词季

先承认「这些词你早就在论文里见过、但没人解释过」，再一个一个补上。

还债的两条纪律

① 每个零件都要说清「在前八季哪节课、哪个方法里出现过」；② 每个零件都要讲它的毛病。

3. 零件地图：四个家族

本季 11 篇零件，按它们在流水线上干的活分成四个家族。分家族不是为了好看，而是因为同一家族里的零件是要横向比较的——比如三节骨架课，讲的都是「怎么把网络做深做强」，你必须放在一起看才知道谁解决了谁的问题。

家族一 · 骨架（5 篇 / 3 节）

网络的躯干，负责「把图像变成特征」。0187 GoogLeNet、0188 ResNet、0189 ResNeXt、0194 Swin 与 PVT。一句话概括它们的十年：怎么在算力不涨的前提下，把网络做深做强。

家族二 · 检测头（2 篇 / 2 节）

负责「把物体框出来」。0191 YOLO（一步到位）、0193 Focal Loss（一步到位为什么难训）。第八季动态块里剔除动态物体的第一步，就是这一家族干的活。

家族三 · 分割头（2 篇 / 2 节）

负责「把像素涂上类别」。0190 FCN（逐像素预测的开山之作）、0192 Mask R-CNN（从涂色到给每个个体编号）。第八季语义建图块的燃料。

家族四 · 两端的外围（2 篇 / 2 节）

一头一尾：0195 LiDAR 硬件（点云是怎么从硬件里出来的）、0196 / 0197 3D 检测综述（点云里的框长什么样）。它们不参与「图像 → 特征」，但决定了你有没有数据、以及数据最终要被谁吃。

4. 暗线：精度 vs 实时性

本季有一条贯穿 13 节课的暗线，第二张总图就讲它。先把两个数放在一起看：第八季动态环境块里，DynaSLAM 引用 Mask R-CNN 的真实耗时是 195 ms / 图——换算过来约 5 fps。而 SLAM 的工程惯例是跑满 30 Hz，也就是每帧只有 33 ms。

这意味着什么？语义前端跑一次，SLAM 已经过去了六帧。于是所有「语义 + SLAM」的论文都必须回答同一个问题：这六帧里发生了什么？答案通常是两条路——要么语义前端降频跑（每隔若干帧分割一次，中间靠几何跟踪撑住），要么把语义结果当作慢变量去约束地图，而不是逐帧驱动位姿。

记住这条暗线，本季很多设计就自动读通了：为什么 YOLO 要强调「one-stage」、为什么 Focal Loss 要解决「正负样本不平衡」、为什么 Mask R-CNN 会被 SLAM 论文抱怨「跑不到帧率」、为什么 0194 的 Swin 与 PVT 整篇都在谈「线性复杂度」。它们不在同一条技术线上，却在同一个预算表里打架。

可用帧率 = 1 ÷ 单次处理耗时；语义前端的帧率 = 1 ÷ 0.195 s ≈ 5.1 fps

这句话在说什么：① 这个式子在算「一秒钟能处理几次」——把单次耗时取倒数；② 为什么这么算——因为每一帧都必须完整跑一遍这个零件，跑得慢就直接拉低帧率，没有中间地带；③ 具体走一遍数：Mask R-CNN 一次 195 ms = 0.195 s，1 ÷ 0.195 ≈ 5.1，也就是每秒只有约 5 帧；而 SLAM 要 30 Hz，即每帧 33 ms = 0.033 s。两个数字相差 195 ÷ 33 ≈ 5.9 倍。这就是本季所有「精度 vs 实时性」争论的算术根据。

6. 收官课要回答什么

本季最后一节（0198）会正面回答一个问题，这个问题也是这一季真正的目的：

0198 要回答的问题

看到论文里一个陌生的词，怎么在三十秒内判断「我需不需要读懂它」？

为什么要问这个？因为把 11 篇零件全部读懂，并不等于你会读论文了。真实的读论文场景是：你手里有一篇 SLAM 论文、一个下午，和一个你从没见过的名词。你需要的是一个能在三十秒内做完的判断，而不是再去补一整季课。

这一节先给一个预告版的判据（完整版在 0198）：看这个词出现在论文的哪个位置。

它出现在「方法主体」里

比如「我们的骨干换成 ResNet-18，特征维度 512」。必须读懂——它决定了方法怎么工作，读不懂就看不懂贡献。

它只出现在「实验设置」里

比如「训练用 AdamW、300 epoch、batch 1024」。知道它是超参就够了——不影响你理解方法，复现时才需要精确。

它只出现在「相关工作」里

比如「[43] 提出的 GoogLeNet 在分类上取得…」。知道有这么个东西即可——它不是你这条路线的关键节点。

顺着这条判据回头看，你会发现本季 11 篇零件里有几篇对你可能真的不必细读——比如那个全文 0 次提到 SLAM 的 3D 检测综述，以及本季唯一一个在 SLAM 语料里找不到任何实际引用的骨干。但你必须先知道它是什么，才能做出「不必细读」这个判断。这就是本季存在的理由：补名词的目的不是让你都读懂，而是让你有能力决定要不要读懂。

课后练习

  1. 有人对你说：「第十季讲的 ResNet 又不是 SLAM，为什么放在 SLAM 课里？」你怎么回答？
    展开查看答案
    因为前八季的 SLAM 论文一直在用它们，但从没解释过。比如 2017 年的 CNN-SLAM 把 ResNet-50 拆开当前半段编码器、后半段换上采样出深度图；2021 年的 TartanVO 用「a modified ResNet50 as the pose network」直接估位姿。这些是真实发生在 SLAM 系统里的用法。本季不产生 SLAM 方法，而是把前八季论文里被随手调用、却从没解释过的通用零件补上——不补，读者对那几节课的理解就永远停在「大概是个神经网络」。
  2. 语义前端 195 ms/图，SLAM 要 30 Hz。除了「降频跑语义」，你还能想到哪些工程出路？（提示：想想 0198 会讲的判据）
    展开查看答案
    至少四条：① 把语义结果当慢变量——地图上的语义标签每 N 帧更新一次，位姿仍由几何逐帧跟踪；② 换更快的检测/分割零件，例如从两阶段换成一步到位的方案（0191 YOLO 的思路）；③ 只在关键帧上跑语义，中间帧用几何外推；④ 减小输入分辨率或降采样，用精度换时间。这四条的共同点都是「承认零件跑不满帧率，然后让几何去补」——也就是本季与第八季最重要的连接点。
  3. 本季有一篇论文在 SLAM 语料库里的实际引用数为 0，另有一篇全文 0 次提到 SLAM。既然这样，为什么还要给它们各开课？
    展开查看答案
    因为「判断它对你没用」这件事，本身建立在你已经知道它是什么。ZERO 引用的那一篇（0194 里的 PVT）是理解 Swin 那套「金字塔搬进 Transformer」叙事的镜像对照——同一年、同一目标、完全相反的路径；而全文不提 SLAM 的那篇（0196/0197 的 3D 检测综述）是「点云里的框」这个问题的系统性地图，第四季的激光 SLAM 与它用的是同一批表示（点 / 体素 / BEV）。所以本季补名词的目的，不是让你把 11 篇都读懂，而是让你有能力决定要不要读懂。
  4. 回到第八季 0153–0159 或 0160–0167 里任意一节，找出一个你当年跳过的名词，写下它在什么句子里、以及你现在猜测它是什么意思。
    展开查看答案
    没有标准答案，但请对照本节的「欠账现场」表检查你的猜测落在哪一类。常见的三类：① 支干网络类（backbone / ResNet-18 / VGG-16）——本季 0187–0189、0194 会补；② 检测与分割类（Mask R-CNN / YOLO / 语义分割 / 实例分割 / RoIAlign）——本季 0190–0193 会补；③ 度量和评测类（IoU / AP / mAP / top-5）——0196–0198 会补。如果你当年猜的意思和这三类都不沾边，那正是「凭名字猜内容」的典型后果，也正是本季要纠正的习惯。
