1. 先立两条线：轻量实时 vs 不确定性

这一课把两篇「看起来都和隐式重建有关、但其实要解决完全不同问题」的论文放一起，是因为它们正好覆盖隐式 SLAM 的两个软肋：太慢，以及不知道自己建得对不对。

左线：Orbeez-SLAM（轻量实时）

隐式地图（NeRF）本来就慢得没法实时。Orbeez 用一套「老派特征法 + 新派 NeRF」的混合路线，把速度拉到 19–22 FPS。它假设静态世界，不处理动态。

右线：NeurAR（不确定性）

重建时怎么知道「哪块建得靠谱、哪块是蒙的」？NeurAR 给每个像素配一个可学习的方差，用它来主动决定下一步去哪拍。它假设位姿已知，做的是主动重建。

★ 先打两个预防针（来自精读材料的纠正）

① Orbeez-SLAM 是「静态世界」的实时隐式 SLAM，不是动态方法。它从头到尾假设场景静止，没有运动分割、没有动态掩码。把它放进「隐式碰动态」框架是误配——它回答的是「隐式地图本身怎么做到实时」，不是「碰上动态怎么办」。

② NeurAR 假设位姿已知，它做的是主动重建（next-best-view），不是完整的 SLAM 本身。它的「不确定性」来自「观测不足 / 视角少」，不是运动物体。

2. Orbeez-SLAM：ORB 管位姿，NeRF 管地图

Orbeez-SLAM（2023，ICRA）是一条很工程、也很聪明的混合路线。它不追求端到端，而是把两代技术拼起来：

前端：ORB-SLAM2 跑位姿

用成熟的 ORB 特征法（第三季 0043–0045 课讲过的那套）做跟踪，输出相机位姿。位姿估计这个「脏活累活」交给已被验证可靠的特征法。

后端：Instant-NGP 当 NeRF 地图

拿到位姿后，用 Instant-NGP 的多分辨率哈希网格（第五季隐式建图基础）去建模场景的几何与颜色。建图这一环交给神经辐射场。

分工的精髓是：「谁擅长什么就干什么」。特征法擅长从图像里稳定地估位姿，NeRF 擅长从位姿 + 图像里建出稠密漂亮的地图。两者用一个明确的接口（相机位姿）连起来——这正是后面第 4 节要接的那句论断。

3. Orbeez 为什么能实时：Instant-NGP 的功劳

隐式建图慢是出了名的（上一季很多方法慢到没法实时）。Orbeez 把速度拉起来的关键，是用了 Instant-NGP 的哈希编码 加两个工程技巧：

  • 多分辨率哈希网格：把 3D 坐标映射到一个紧凑的哈希表，查询快、显存省；
  • Skip voxel（跳过体素）：沿射线采样时，未占用的体素直接跳过，只采样与表面相交的体素——相当于「踩着露出水面的石头过河」，省掉大量无效计算；
  • 射线三角化：把 NeRF 反解成可用点云（统计每个密度体素的采样数，超阈值的作为稠密地图点）。

速度数字很硬：在 TUM RGB-D 上达到 19–22 FPS，而 NICE-SLAM 只有 0.028–0.056 FPS——快了约 360–800 倍。这让它第一次把「隐式稠密 SLAM 实时跑」从设想变成工程现实。

4. 接 0011：深度学习先吃掉匹配与检索

第一季 0011 课（深度学习视觉 SLAM）有一个著名论断：「深度学习先吃掉匹配与检索」——意思是，传统 SLAM 里最依赖手工设计的两块（特征匹配、重识别检索），会最先被学习模型接管。

Orbeez-SLAM 恰好是这句话在隐式时代的具体化：

★ 把论断落到地上

0011 说「深度学习先吃掉匹配与检索」。但在这里，「匹配」这一块并没有被深度学习吃掉——Orbeez 反而是把成熟的 ORB 特征法原封不动当后端，只用 NeRF 接管「建图」。这恰恰说明：当隐式建图本身还慢、还脆时，最稳妥的做法是「让老派特征法守住所擅长的位姿，让新派网络只管它最擅长的稠密地图」。

换句话说，0011 的论断在「检索 / 重识别」层面成立，但 Orbeez 这一支告诉我们：在隐式 SLAM 里，「匹配」这块暂时还由经典方法牢牢把持，因为把位姿交给尚不鲁棒的学习模型风险太高。

这也是为什么它在上一课「组合式」思路之外，又给了我们一种更朴素也更可靠的工程范式——不急着端到端，先把成熟模块拼起来跑通。

5. NeurAR：把不确定性变成可学习的方差

NeurAR（2023，ICRA）关心的是另一个问题：重建出来的地方，哪些靠谱、哪些是在「蒙」？

它给每个像素的颜色配一个高斯不确定性 $\sigma^2$——也就是说，渲染出来的不是一个固定颜色，而是一个「颜色的分布」。做法是在 NeRF 式网络上多接一个 128 维的全连接分支，专门预测每个视角的不确定性（原文 Fig.4 说「唯一区别就是多了一个分支」）。

这个方差不是随便给的，它用一个异方差（heteroscedastic）损失来训练：

$$L=\sum\left[\frac{(C_{obs}-\hat C)^2}{2\sigma_I^2}+\frac12\log\sigma_I^2\right]+L_{ratio}$$

直观讲：观测和预测差得越远，网络就越「心虚」，方差就调得越大；同时逼着网络别无脑把方差调小来作弊（第二项 $\frac12\log\sigma_I^2$ 是防止方差坍缩的正则）。训练完，$\log\sigma_I^2$ 与 PSNR 呈强负相关（PCC 在线 0.96 / 离线 0.92）——也就是说，方差确实能当「这块建得好不好」的代理指标。

6. 不确定性用来干什么：主动重建（并接 0011 的置信度环节）

算出不确定的目的是用。NeurAR 用它做主动重建（next-best-view, NBV）：机器人自己决定下一步去哪个视角拍，专门挑「不确定性最高」的地方。原文里它用 RRT* 路径规划，让机器人朝红字区域走。

这里要诚实标注两点（来自精读材料的纠正）：

  • 它不是动态处理方法。它的不确定性来自「观测不足 / 视角少」，不是运动物体。它不分割、不剔除动态。
  • 它假设位姿已知。位姿由外部提供，它做的是「重建质量主动评估」，不是 SLAM 全栈。它是主动重建，不是完整的 SLAM 本身。

接第一季 0011 课：0011 在「六个不成熟环节」里点名了「置信度 / 概率化」这一条尚未成熟。NeurAR 正是这一条在隐式重建里的具体化——它把「地图里哪些地方不可信」用一个可学习的方差显式建模，并直接拿来驱动决策。从「滤波器层面的 NEES 一致性检验（第一季 0022）」到「渲染层面的不确定性预测（NeurAR）」，置信度建模正在从理论走向可用。

课后练习

  1. Orbeez-SLAM 的「混合路线」具体怎么分工？谁管位姿、谁管地图？
    展开查看答案

    前端用 ORB-SLAM2（成熟特征法）估计相机位姿；后端用 Instant-NGP 的多分辨率哈希网格当 NeRF 地图，建模场景几何与颜色。两者只通过「相机位姿」这一个接口耦合。

    注意：它是静态世界假设，不处理动态；也不是端到端学习，是两套模块拼接。

  2. Orbeez 把 NeRF 的建图速度拉到实时的关键是什么？给一个速度数字。
    展开查看答案

    关键是 Instant-NGP 哈希编码 + Skip voxel（沿射线跳过未占用体素，只采样表面相交体素）+ 射线三角化（把 NeRF 反解成点云）。

    速度：TUM RGB-D 上 19–22 FPS，而 NICE-SLAM 仅 0.028–0.056 FPS，快约 360–800 倍。免预训练、边跑边建。

  3. 第一季 0011 说「深度学习先吃掉匹配与检索」。Orbeez-SLAM 是印证还是反例？
    展开查看答案

    在「检索 / 重识别」层面，0011 的论断成立；但 Orbeez 这一支是反例式的具体化——它反而把成熟的 ORB 特征法原封不动当后端管位姿，只用 NeRF 接管建图。

    这说明：在隐式 SLAM 里，「匹配（位姿）」这块暂时仍由经典方法把持，因为把位姿交给尚不鲁棒的学习模型风险太高。「先吃掉」不是「全吃掉」。

  4. NeurAR 的不确定性是对哪个量求方差？它被用来干什么？
    展开查看答案

    它对每个像素的颜色预测一个高斯方差 $\sigma_I^2$（网络多接一个 128 维分支）。训练用异方差损失，使 $\log\sigma_I^2$ 与 PSNR 强负相关，方差能当「建得好不好」的代理。

    用途：做主动重建（next-best-view）——规划器挑不确定性最高的视角去拍，主动补全盲区。它不处理动态、假设位姿已知。

  5. NeurAR 能不能算作「隐式碰动态」的方法？它和「完整 SLAM」差在哪？
    展开查看答案

    不能。它的不确定性来自「观测不足 / 视角少」，不是运动物体；它不分割、不剔除动态。而且它假设位姿已知，做的是「重建质量主动评估」，不是 SLAM 全栈，而是主动重建（NBV）。

    所以它和「隐式碰动态」是两条线；动态三篇留到下一课。
