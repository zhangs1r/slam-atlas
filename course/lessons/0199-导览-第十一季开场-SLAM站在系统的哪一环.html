本节目标

读完你应该能：① 说出这条七环系统链是哪七环，并把「规划」「控制」「执行器」这三个陌生词翻译成大白话；② 说清前十季一直在打磨链上的哪几环，又有哪些环几乎没碰过；③ 看懂三篇应用论文在链上的覆盖图，理解「覆盖深度极不均匀」这句话是什么意思；④ 提前知道本季要纠正的两处说法；⑤ 拿到全季七节课的课表，知道收官课要结什么账。

和前面课程怎么接

这是第十一季的导览课，所以「怎么接」要接整条线。往回看：第一季 0002 立了全景纲领；第二至七季在链的第 ③ 环（SLAM / 里程计）里越挖越深；第八季 0160–0167 补了语义、0168–0174 补了多机；第九季 0184 讲了「真值从哪来」；第十季 0186–0198 把通用零件齐了一遍。这一季要做的是：把这些零件钉到同一条系统链上，看它们各自站在哪一格。

0. 它在系统链的哪一环

先直接回答问题。这一季不是某一个环节的课，它是「看位置」的一季——导览课看的是整条链。

0.1 七环，每环一句话（先讲人话，再上术语）

零基础读者最容易卡住的是后面三环。因为它们不像「相机」「点云」那样能一眼看见。所以我们先用一个生活场景把它们讲清楚。

把机器人想成一个人出门寄快递。眼睛和耳朵是传感器；眼睛看到的东西要经过脑子理解（那是树、那是马路），这是感知；他边走边偷偷记住「我从家门口出来往左拐，走了大概两百米」，这是里程计，而一边记位置一边把沿途画成一张走法图，就是SLAM；画出来的图是地图；出门前先想好「先走大路到邮局再拐进小巷」，这叫规划；真正迈腿时腿抬多高、步子迈多大，这叫控制；而腿和脚，就是执行器。

环节（术语） 一句大白话 吃进什么，吐出什么 前十季讲过吗
① 传感器机器人的眼睛和耳朵：相机看颜色、激光雷达量距离、IMU 感觉晃不晃光、激光回波、加速度 → 一堆原始读数第十季 0195 讲过 LiDAR 硬件本身
② 感知 / 前端把原始读数变成「这里有什么」：分出树、地面、人、车原始读数 → 带标签的物体和特征第三季视觉主干、第八季 0160–0167
③ SLAM / 里程计一边走一边算「我在哪」，同时把走过的地方拼成一张图帧与帧的对应关系 → 连续位姿 + 逐渐成形的地图第二至七季的主战场
④ 地图把「哪里有什么」存下来，给后面几环用位姿 + 观测 → 点云 / 体素 / 语义模型第六季空间表示、第八季语义地图
⑤ 规划决定「该往哪走」：先想大方向，再躲开眼前的东西地图 + 目标点 → 一条路线（一串路点）几乎没碰过（只在本季 0200、0201）
⑥ 控制把路线变成每秒几百次的小指令：油门大一点、舵量小一点路线 + 当前状态 → 推力 / 姿态 / 舵量几乎没碰过（只在本季 0200）
⑦ 执行器真正会动的东西：电机、螺旋桨、车轮指令 → 转速、转角 → 机器真的动了几乎没碰过（只在本季 0200）

这里要补一句诚实的说明：「几乎没碰过」不等于「一次都没出现」。SLAM 论文的结尾经常写一句「我们的位姿输出交给下游规划器使用」，但规划器本身长什么样、它怎么用这张地图、它要优化什么，前十季一次都没拆开讲过。这一季补的就是这块。

互动判断

这条七环系统链上，关于 SLAM 的位置，下面哪一种说法更准确？

1. 前十季站在这条链的哪几环

现在可以给前十季定位置了。一句话：前十季几乎全部力气，都花在链的第 ②③④ 三环上。

具体说：第三季（视觉主干）、第四季（激光主干）、第五季（多传感器融合）、第六季（神经隐式与 3D 高斯）、第七季（学习式方法），这五季都在反复回答同一个问题——第 ③ 环的 SLAM 怎么做得更准、更稳、更省。第八季的语义建图块 0160–0167 落在了第 ② 环（感知）和第 ④ 环（地图）的交界上：语义既是感知的产物，也是地图的内容。而第十季 0186–0198 补的是零件——骨干网络、检测头、分割头、传感器硬件，它们散落在第 ①② 环里。

于是问题就来了：第 ⑤⑥⑦ 环呢？

规划、控制、执行器——这三环在前十季里的出场方式是「被提一句」。比如某篇激光里程计论文的结尾写「我们的位姿输出可以供下游导航模块使用」，然后就没有然后了。导航模块内部怎么想、怎么选路、怎么把一条路线变成油门和舵量，前十季没有一节课讲过。第十季 0195 讲了 LiDAR 硬件本身怎么工作，但那讲的是「这一环的器件原理」，不是「怎么选传感器」这种系统决策。

还有一件事更彻底：前十季从没画过一条横向的轴线——「这些计算到底跑在哪儿」。跑在机器人身上？跑在旁边一台服务器上？跑在云上？这个问题在前十季里根本不存在，因为所有论文都默认「算法跑在机器人自己身上」。而这一季的第 0202 节会把这条轴第一次摆上台面。

2. 第十季留下的处境：零件齐了，机器呢

第十季 0186 的导览课承认了一件事：你在前八季读论文时一定跳过很多词——这不是你的问题，是论文从来不解释。于是第十季花了十三节课把通用零件补齐：骨干网络（0187–0189、0194）、检测头（0191、0193）、分割头（0190、0192）、传感器硬件（0195），最后收成 0198 的一本名词手册和一张零件地图。

第十季的收官课很诚实地留了一个口子。它说清了每个零件是什么，但没有回答三个更基本的问题：

问题一：装在哪台机器上

分割网络跑在什么算力上？一台无人机能带多少电脑、多少电？装了之后续航还有几分钟？第十季只讲零件本身，不讲零件装在哪儿。

问题二：装完给谁用

SLAM 算出来的位姿，到底交到谁手里？交出去之后怎么被消费？前十季的答案永远是一句「交给下游」。

问题三：谁给它目标

机器怎么知道「该去哪儿」？任务是怎么从人这里变成一条可执行路线的？这个问题在前十季里根本不存在。

这一季换一种问法，不再问「这个方法好不好」，而是问「这个东西站在哪一格，它上一格是谁、下一格给谁」。而回答这个问题的办法，就是去找真正把 SLAM 装进一台机器的论文——本季选的这三篇应用论文，恰好是三台很不一样的机器。

顺便记下这一季的口号：看位置之前，先看清这篇到底是什么。这句话和第十季 0198 收官课给的「三十秒三判据」（看到一个陌生名词，该不该停下来读懂它）是同一族能力——只不过这一次要判断的不是名词，而是整篇论文的定位。

这里还有一组本季最值得期待的正面冲突：面对「机器人算力不够」这件事，0200 和 0202 走的方向正好相反。0200 的做法是把算力往机上堆——换更强的机载电脑、坚持所有计算都在机上做；0202 的做法是把算力往机外送——把原始数据打包发到旁边的边缘服务器上算。同一个问题，两条相反的路，这本身就是系统设计最核心的一组张力，等两节课讲完再回头对照看。

4. 两处提前纠正

在讲正文之前，先把两处流传中的说法纠正清楚。为什么导览课就要纠？因为这一季的口号就是「看位置之前，先看清这篇到底是什么」——如果连题目和内容都记错了，后面所有的讨论都会歪。这也是前几季留下的习惯：文献清单里的描述和论文正文不一致，我们以正文为准，并且把不一致的地方明写出来。

纠正一：不是「仿真」

有一份清单把 0202 那篇写成「边缘计算加速多机器人仿真」。这是一个误读。

它的真实一级标题是 Edge Robotics: Edge-Computing-Accelerated Multirobot Simultaneous Localization and Mapping。文件名末尾那个 _Sim 是文件名被截断时切到的 `Simultaneous` 的前三个字母，不是 simulation。而且它不是纯仿真论文：它有真机原型（3 台 TurtleBot3 + 1 个边缘节点，机器人端用的是 Jetson TX2），是真机加仿真的双验证。

我们会在 0202 开课就把这件事讲清，并且把它当成一个教学点：一次文件名截断，能让一整篇论文的重点被读错。这正好是全季的口号。

纠正二：没有 SE(2)

另一份说明里写，0203 那篇用 SE(2) 相对位姿做稠密重建。

这是清单的说法，不是论文写的。正文里 SE(2) 出现 0 次（SE(3) 出现 2 次），而且全文没有「稠密重建」这个说法；它全程用的是 SE(3) / SO(3)，产物是 surfel + submap。

我们的处理方式是：明写「这是清单的说法」，然后讲清 SE(2) 与 SE(3) 的区别，以及为什么这篇不需要 SE(2)。不为了圆清单而替论文补话——这是本项目的硬纪律。

还有两处不算「说错内容」，但同样值得提前知道：有两篇的标题在文件名里被截断了。0200 那篇漏掉了副标题 Under Dense Forest Canopy——「树冠下」才是它的题眼，因为密林树冠正是「为什么必须用激光雷达而不是纯视觉」的论证起点；0201 那篇漏掉了 using machine learning: a survey——它是一篇综述，而且清单把它归成「系统类、偏工程」也不对。这两处我们都会在对应课里补全。

第一，画全十一季的总图。它会把主干七层（综述与全景 → 打地基 → 视觉主干 → 激光主干 → 多传感器融合 → 神经隐式与 3D 高斯 → 学习式方法）和四个横切面（H 支线 / I 尺子 / J 零件 / K 位置）画在一起，说明为什么这样编排——主干是一条纵向的技术演进，横切面是四种不同的切法。

顺便说一句这件事的意义：这门课是从第一季 0002 的那张全景纲领出发的，走了十个季节的内容，最后又在 0205 回到全景——从全景出发，最后回到全景。这是整个项目的闭环，也是第十一季存在的原因。

读完你应该能回答

① 七环系统链是哪七环？

传感器 → 感知 / 前端 → SLAM / 里程计 → 地图 → 规划 → 控制 → 执行器。

② SLAM 站在哪一环，上游下游是谁？

第 ③ 环。上游是感知 / 前端（把原始读数变成带标签的物体和特征）；下游是地图（存下来）与规划（拿去做路线）。

③ 「规划」「控制」「执行器」分别是什么？

规划决定走哪条路；控制把路线变成每秒几百次的小指令（油门 / 舵量）；执行器是真正会动的电机和螺旋桨。

④ 前十季在哪几环上挖得最深？

感知、SLAM / 里程计、地图三环。规划、控制、执行器几乎没拆过；「算力放哪」这条横轴一条都没画。

⑤ 三篇应用论文各盖了几格？

0200 六环全覆盖（唯一到执行器）；0201 一环都不实现（导航栈解剖图）；0202 只盖 SLAM 与地图两环的算力部署与融合方式。

⑥ 本季要纠正哪两处？

① 0202 不是「仿真」，标题是 Multirobot Simultaneous Localization and Mapping，且有真机原型；② 0203 的正文里 SE(2) 出现 0 次，那是清单的说法。

课后练习

  1. 有人说：「这篇论文的 SLAM 很准，所以这台机器肯定能自主完成任务。」请用系统链的说法指出这句话缺了什么。
    展开查看答案
    缺了两件事。第一，定位准只是第 ③ 环做对了——机器要自主完成任务，还需要第 ⑤ 环（规划：该走哪条路）、第 ⑥ 环（控制：怎么把路线变成指令）、第 ⑦ 环（执行器：真的动起来）。第二，SLAM 的输出还得有人消费：如果规划器拿到的位姿不平滑、或者地图的精度不够它用，定位再准也走不起来。0200 那一节的整场戏就是这个矛盾。
  2. 为什么说 0201 那篇「横跨所有环却一环都不实现」？这两句话不矛盾吗？
    展开查看答案
    不矛盾，因为「横跨」说的是它的讨论范围，「实现」说的是它有没有造出东西。它拿经典导航流水线当坐标系，把所有相关工作按「学习占流水线的多大一块」分类（整条栈 / 子系统 / 单个组件），于是它讨论的范围覆盖了从感知一直到运动指令的每一格；但它自己不提出方法、不做实验、不造系统，所以一格都不实现。它是导航栈的解剖图，不是导航栈。
  3. 「看位置之前，先看清这篇到底是什么」——请用 0202 那处「仿真」误读，说明这句话为什么重要。
    展开查看答案
    因为如果按「仿真加速」去理解那篇论文，你会把注意力放在「仿真环境里跑得快不快、逼不逼真」上；而它真正讲的是卸载粒度（传地图还是传原始帧）、层次化地图融合、以及机器人–边缘之间的调度算法，而且它有真机原型（3 台 TurtleBot3 + 1 个边缘节点）。一次文件名截断就让重点整个偏掉。先确认这篇是什么，再讨论它好不好，这就是这句话的意思。
  4. 本季是「看位置」季。请说出「看位置」和前十季「看方法」在提问方式上的区别。
    展开查看答案
    「看方法」问的是：这个方法的精度、鲁棒性、速度比前人好在哪，核心贡献是什么。「看位置」问的是：它站在系统链的哪一环、吃什么、吐什么、上游是谁、下游给谁、不负责哪些环。后者不评价方法好坏，只定位。两者不冲突——但只有先看清位置，你才知道「它的精度提升」对整台机器到底意味着什么。
