2. ★ 三条运动估计管线

原文把「怎么从数据算运动」分成三类，取决于你手上是 2D 像素点还是 3D 空间点。下面这张系统框图正好把那一格「Motion Estimation」展开成三路，是本节的头号配图。

管线输入数据用什么解最小解集原文评价
2D-to-2D 两帧的 2D 像素对应 本质矩阵 $E$ 五点法 / 八点法 单目下它「avoids point triangulation」（免去三角化），但实践中不如 3D-to-2D 常用，原因是 3D-to-2D 的数据关联更快（五点 vs 三点最小集）。
3D-to-3D 双目三角化后的两组 3D 点 刚体配准（两点集对齐） — 对两组三维点做刚体配准。原文评价它不如 3D-to-2D 准（见下）。
3D-to-2D 已知 3D 点 + 它在新帧的 2D 投影 PnP / P3P 三点 最小化重投影误差，原文认为它最准、最常用。

2.1 3D-to-2D 为什么最准：原文的关键比较

3D-to-2D 的核心是 PnP（Perspective-n-Point）：已知地图点（3D）和它在当前图像上的投影（2D），求相机位姿。它最小化的是重投影误差——即「按估计位姿把 3D 点投回图像，和真实观测差多少」：

$$\arg\min_{T_k}\sum_i\big\|p_k^i-\hat p_{k-1}^i\big\|^2$$

原文那句必须引用的比较是：3D-to-2D 比 3D-to-3D「more accurate than from 3-D-to-3-D … because it minimizes the image reprojection error (10) instead of the 3-D-to-3-D feature position error (9)」。

★ 用大白话说

在图像平面上最小化误差，比在三维空间里最小化更准。为什么？因为测量噪声发生在图像上（像素有噪声），3D 点本身是「算出来的、也带噪声」，在带噪声的 3D 上做最小二乘等于「在噪声上再拟合噪声」。而重投影误差直接对齐「图像观测」，误差来源更干净。这句直接呼应 0018 课 BA 的残差定义——BA 优化的就是重投影误差。

3. ★ 单目 vs 双目：优缺点对照

同样三条管线，喂进去的数据来自单目还是双目，差别很大。原文把双目的优点原话列了三条，单目则有它存在的理由，下面照抄成表。

双目（stereo）优点原文原话
① 直接得到绝对尺度「3-D features are computed directly in the absolute scale」——左右眼有基线，三角化直接出真实距离，没有上节的尺度歧义。
② 只需在两视图间算匹配「matches need to be computed only between two views instead of three」——单目常要借助第三帧，双目自带深度。
③ 小运动时漂移更小「exhibits less drift than the monocular one in case of small motions」。

★ 那单目为什么还存在

原文说：当「distance to the scene is much larger than the stereo baseline」（场景距离远大于双目基线）时，立体视觉会退化——基线太短、距离太远，视差小到量不出，双目等于废了。这时候只能用单目。简单说：看近处用双目爽，看远处双目变近视，单目上。

4. 特征怎么用：三分法

除了「用不用深度」，原文还按「怎么用特征」把方法分成三类：

feature-based（基于特征）

提关键点、算描述子、做匹配。原文说它「faster and more accurate」——又快又准，是主流。

appearance-based / global（基于表观/全局）

拿整块图像算相似度。原文说它「less accurate than feature-based methods and computationally more expensive」，且「not robust to occlusions」——不如特征法准、更贵、还怕遮挡。

hybrid（混合）

两者结合，取长补短。

★ 一句话记住

特征法又快又准、怕弱纹理；表观法不怕弱纹理但慢且怕遮挡。绝大多数实战 VO 走 feature-based，这也是 0024 系统框图里「Feature Detection → Matching」那一路。

5. V-SLAM 的两支与 VO 的取舍

VO 往「建图 + 闭环」走一步，就是 V-SLAM（视觉 SLAM）。原文把 V-SLAM 分成两支：

filtering（滤波法）

用概率分布（如 EKF）把位姿和地图点融合起来，边走边更新。

nonfiltering / keyframe（关键帧法）

只挑少量关键帧，在关键帧上做批量优化（BA）。这是后来 ORB-SLAM 那一路。

原文的诚实评价很关键：V-SLAM 比纯 VO 更精确，但「not necessarily more robust … more complex and computationally expensive」——不一定更鲁棒，只是更复杂、更贵。而 VO 的哲学是「trades off consistency for real-time performance」：用一致性（闭环、全局一致）换实时性。这正好呼应 0024 说的「VO 只管走、不负责纠偏」。

6. 历史两支与精度数字

原文把 VO 的演进按传感器分成两支，读起来很提气，也帮你建立时间线。

★ Stereo VO 一支

Moravec 滑动立体起步 → Matthies & Shafer 引入误差协方差 → Olson 加绝对方位传感器 → Lacroix 用相关函数曲率定协方差 → Nistér 2004 首次实时长距离 + RANSAC → Comport 用四焦张量免三角化。

★ Monocular VO 一支

Nistér 首次实时大尺度、五点解算 → Corke 全向相机 + 光流 → Lhuillier / Mouragnon 局部窗口 BA → Tardif 2.5 km 无 BA、旋转平移解耦。

精度数字原文也给得很具体（请抄准）：VO 相对位置误差「ranging from 0.1 to 2%」；Matthies 在 5.5 m 路径上达到「2% relative error」；Olson 在 20 m 路径上「1–2%」；Konolige 用 windowed BA 跑 10 km 实验，把最终位置误差「decrease the final position error by a factor of 2–5」（降低 2–5 倍）。

7. 两条实践结论与边界

原文在结论部分给了两条务必引用的实践建议：

① 局部 BA 总该做

「should always be performed」——局部光束法平差应当总是执行。对应 0018/0019 的 BA，是抑制漂移的刚需。

② 关键帧选择很重要

「very important … should always be done before updating the motion」——在更新运动之前，关键帧选择应当总先做。挑好关键帧，优化才稳。

7.1 本教程的边界（再次声明）

和 0024 一样，必须诚实：RANSAC、误差建模、位置识别/回环、BA 的正式推导都在 Part II，本教程（Part I）不含。本节只讲了「稀疏特征 + 运动估计」这一支。

7.2 收尾：下一节换一条路

本节讲的都是「先提特征、再估运动」的稀疏特征路线。下一节 0026 我们换一条完全不同的路：不提取特征的稠密双目匹配——直接对整张图的每个像素算视差，得到稠密深度。那是 SGM 的故事。

课后练习

展开查看答案 · 练习 1：写出三条运动估计管线各自的输入与解法

① 2D-2D：两帧 2D 像素对应 → 本质矩阵 $E$（五点/八点法），单目下免去三角化；② 3D-3D：双目三角化后的两组 3D 点 → 刚体配准；③ 3D-2D：已知 3D 点 + 新帧 2D 投影 → PnP/P3P，最小化重投影误差。

展开查看答案 · 练习 2：背出原文那句「3D-to-2D 更准」的关键比较

原文：3D-to-2D「more accurate than from 3-D-to-3-D … because it minimizes the image reprojection error (10) instead of the 3-D-to-3-D feature position error (9)」。即在图像平面最小化重投影误差，比在带噪声的三维空间最小化更准，且直接呼应 0018 的 BA 残差。

展开查看答案 · 练习 3：双目三条优点 + 单目为何仍有存在理由

双目优点：① 3D 特征直接在绝对尺度下算出；② 匹配只需两视图；③ 小运动时漂移更小。单目存在理由：当「场景距离远大于双目基线」时立体视觉退化、视差量不出，只能用单目。

展开查看答案 · 练习 4：feature-based 与 appearance-based 的取舍

feature-based「faster and more accurate」，是主流；appearance-based「less accurate … computationally more expensive」且「not robust to occlusions」，慢、不准、怕遮挡。实战多走特征法。

展开查看答案 · 练习 5：两条实践结论，并说清 VO 与 V-SLAM 的取舍

两条结论：局部 BA「should always be performed」；关键帧选择「very important … should always be done before updating the motion」。VO 与 V-SLAM：V-SLAM 更精确但更复杂更贵、未必更鲁棒；VO「trades off consistency for real-time performance」，用一致性换实时性，不负责闭环纠偏。
